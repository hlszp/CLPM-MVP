## 2. 需改造的文件（保留模块中的诊断/整定交叉引用）

### 2.1 核心页面改造

#### `src/views/loop/workbench.vue`（回路工作台）⚠️核心改造

当前状态：使用 `MVP_DISABLE_DIAGNOSIS_TUNING = true` 开关条件隐藏。

需彻底删除的内容：
- 诊断区（③）：诊断卡、诊断触发按钮、`loadDiagnosis()` 函数
- 整定区（④）：整定卡、整定触发按钮、`loadTuning()` 函数
- 验证区：验证前后对比条（R6）、`loadVerification()` 函数
- 闭环时间线：Tracker 节点
- 4 个弹窗组件：DiagnosisTriggerModal / TuningTriggerModal / TuneParamModal / SimulateResultModal
- 阶段数组中的 `DIAGNOSE` / `TUNE` / `VERIFY` 阶段
- 相关 import 和 API 调用

保留的内容：
- 评估流程区（R5 中的评估卡）
- 活跃关注列表
- KPI 指标条、雷达图、趋势图等评估相关组件
- 回路基本信息、实时数据

#### `src/views/monitor/attention.vue`（关注队列）⚠️已过滤

当前状态：客户端过滤 `TRACKER` 和 `VERIFICATION` 来源项。

需彻底删除的内容：
- `DIAGNOSIS_SOURCES` 过滤逻辑（改为后端不返回这些来源）
- `SOURCE_ORDER` 数组中的 TRACKER 和 VERIFICATION 条目
- 相关的类型定义和文案

#### `src/views/dashboard/workbench.vue`（系统概览）

需排查并删除的内容：
- 诊断建议分布统计（diagnosisDistribution）
- Tracker 计数（trackerCount/pendingCount）
- 闭环状态相关统计
