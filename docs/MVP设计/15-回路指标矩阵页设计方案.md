## 实施备注（v1.1）

- 指标组切换用 `Segmented` 而非 Tabs（切换仅变列不变数据，Segmented 更贴合
  Calm UI 且避免 4 份表格实例挂载）；语义与"Tab 切换即列组切换"一致。
- metric-series 接口未实现 granularity 参数：数据源 kpi_snapshot_hourly 固定
  小时粒度，raw 无数据源支撑，避免死参数。
- 列筛选（漏斗）为当前页前端过滤（设计口径），Tooltip 已注明"当前页"。
- 文件落点：后端 `app/services/performance.py::get_loop_metric_series` +
  `app/api/v1/endpoints/performance.py`（GET /performance/loops/metric-series）；
  前端 `views/metric/matrix.vue` + `api/metric.ts::getLoopMetricSeriesApi` +
  `router/routes/modules/assess.ts`（AssessMatrix）。

## 1. 背景与目标

### 1.1 问题

- 指标散落：各指标值分布在回路性能（详情抽屉）、评估记录（表格）、回路监视（性能 Modal）等处，无"全回路 × 全指标"单屏集中视图。
- Phase 1 新增指标（仪表故障率、pv/sp/op 统计、阀门指标、时间常数等）无任何列表页出口。
- "按指标定位薄弱回路"缺交互支撑：现有表格纯数字呈现，无色阶、无列级筛选，无法一眼看出哪条回路哪个指标异常。
- 历史值查看只有"单回路 × 多指标"一个方向（回路性能页历史 Modal），缺"单指标 × 多回路"对比。

### 1.2 目标

1. 单屏矩阵：行=回路、列=指标，按指标分档着色，一眼定位薄弱回路。
2. 全指标覆盖：核心 9 项 + 诊断扩展 + Phase 1 统计/阀门指标全部可见。
3. 下钻闭环：单元格 → 该回路该指标历史趋势；列头 → 该指标 TOP N 薄弱回路历史对比。
4. 复用现有数据链路：后端零新增模型，仅 1 个轻量接口扩展。

### 1.3 非目标

- 不做指标算法/阈值配置（已有配置管理 → 指标配置 → KPI 算法参数）。
- 不做矩阵导出（评估记录页已有 CSV/Excel 导出，避免重复）。
- 不做实时刷新（快照为小时粒度，手动刷新即可）。

## 3. 页面设计

### 3.1 布局结构

```
┌─────────────────────────────────────────────────────┐
│ ClpmPageToolbar（标题 + 刷新按钮，右侧对齐）          │
├─────────────────────────────────────────────────────┤
│ 筛选区（一行，flex-wrap）：                          │
│ [装置 TreeSelect] [回路 Select] [指标组 Tabs]        │
│ [时间窗 Segmented] [列筛选开关] [查询]               │
├─────────────────────────────────────────────────────┤
│ ClpmDataCanvas（loading/error/empty 三态）           │
│ ┌─ 回路列(fixed) ─┬─ 指标列组（可折叠）──────────┐   │
│ │  L101-汽提塔...  │ 98.2 │ 95.1 │ ... │ 0.62 │   │   │
│ │  L102-...       │ [单元格按分档着色]          │   │   │
│ │  ...            │                              │   │
│ └─────────────────┴──────────────────────────────┘   │
│ 底部：色阶图例 + 分页                                  │
├─────────────────────────────────────────────────────┤
│ 抽屉：单元格点击 → 单回路单指标历史趋势                 │
│ 弹层：列头趋势入口 → 多回路指标对比                     │
└─────────────────────────────────────────────────────┘
```

### 3.2 筛选区

| 控件 | 说明 |
|---|---|
| 装置筛选 | TreeSelect，`getPlantNodeTreeApi`，多选（逗号拼接传 `plantNodeId`），变更联动回路选项 |
| 回路筛选 | Select show-search，`getLoopListApi` 分页拉全量，多选 |
| 指标组切换 | Tabs（见 3.3），Tab 与列组二选一呈现：**Tab 切换即列组切换**（单组显示，避免横向滚动；"全部"Tab 可选） |
| 时间窗 | Segmented：最新（latestOnly=true，默认）/ 8h / 24h / 72h / 168h（latestOnly=false 时取窗口内每回路最新一条——后端现有语义即如此） |
| 列筛选开关 | 点击列头漏斗图标 → "只看该指标低于分档阈值的回路"（前端过滤） |
| 查询 | Button primary |

筛选状态同步到 URL query（`plantNodeId/loopId/window/tab`），支持深链与刷新保持（参照指标分析页 `fullPathKey: false` 模式）。

### 3.3 指标列分组

| 组名 | 指标（camelCase 返回体字段） |
|---|---|
| 核心 | score, goodValueRate, autoModeRate, effectiveAutoRate, steadyRate, accuracyRate, fastRate, oscillationRate, saturationRate |
| 诊断 | instrumentFaultRate, stictionIndex, settlingTime, idealSettlingTime, outputTravelIndex, timeConstant |
| 统计 | pvMean, pvStd, spMean, spStd, opMean, opStd |
| 阀门 | valveLinearity, valveNonlinearity, valveOpMin, valveOpMax, oscillationAmplitude, setpointCrossingCount |

- 默认 Tab=核心；统计/阀门组为 DISPLAY_ONLY 指标，着色规则用中性色（见 3.4）。
- 每列列头含：中文标题 + 单位 + 排序点击区 + 漏斗（列筛选）+ 迷你趋势入口（折线 icon）。

### 3.4 单元格着色规则

复用 `useScoreColor`（`composables/use-score-color.ts`）的语义色体系，**仅对参与定级的率类指标着色**：

| 指标类 | 着色 | 说明 |
|---|---|---|
| score | 4 级色阶（动态定级阈值优先，降级 90/80/60/40 默认） | 与全系统评分色一致 |
| 率类（6 项核心 + instrumentFaultRate） | 同上 4 级 | 其中 instrumentFaultRate、oscillationRate、saturationRate 为**反向指标**（低=好），阈值方向取反 |
| 诊断数值类（settlingTime、stictionIndex 等） | 不着色，`ClpmNumeric` 常规呈现 | 无行业统一分档标准 |
| 统计/阀门组 | 不着色 | DISPLAY_ONLY |
| NULL（INCONCLUSIVE） | 中性斜纹底（参照 EvalHeatMatrix 的 N/A 样式） | 严禁红色 |

反向指标阈值参考（可后续迁入配置）：oscillationRate/saturationRate：<5 优 / <15 良 / <30 中 / ≥30 差；instrumentFaultRate：<1.5 优 / <3 良 / <5 中 / ≥5 差（与工作台热力矩阵口径一致）。

### 3.5 交互设计

| 交互 | 行为 |
|---|---|
| 列头排序 | 服务端排序：`sortBy/sortOrder`（现有白名单 7 指标直接支持；矩阵页核心 Tab 内 score/accuracyRate/autoModeRate/effectiveAutoRate/fastRate/steadyRate/goodValueRate 可排序，其余指标点击排序时前端排序当前页） |
| 列筛选 | 漏斗开关：开后仅显示该指标低于"中"档阈值的回路（前端过滤当前数据集；开启状态列头标记） |
| 单元格 hover | Tooltip：指标名 + 值 + 可信度等级 + 时间窗 |
| 单元格点击 | 抽屉（width 480）：该回路该指标的时间序列趋势线（复用 EchartsUI；时间范围=当前筛选窗或默认 24h；数据走 `getLoopSnapshotsApi` latestOnly=false 单回路分页拉取） |
| 列头"趋势"icon | 弹层（width 900）：该指标 TOP N（默认 10）最差回路的历史折线叠加（N 条线，图例=回路标签；数据走新批量接口，见 4） |
| 行点击 | 不做整行下钻（避免与单元格点击冲突）；行尾"详情"按钮跳转回路性能详情抽屉的深链 |
| 刷新 | 工具栏手动刷新按钮 |

### 3.6 视觉规范

- 表格 `size="small"`，行高 36px，回路列 fixed left（宽 160px，ellipsis + Tooltip 全名）。
- 单元格着色用弱色底 + 深色字（Calm UI：底色透明度 ≤0.35，避免大面积高饱和）。
- 色阶图例固定在表格底部左侧，与工作台 EvalHeatMatrix 图例样式一致。
- 微型柱状图/色块无动画；主题切换（isDark）重渲（watch 模式与现有页面一致）。
- 列宽：核心组每列 88px；诊断/统计/阀门组 96px（含单位）。

## 4. 后端接口扩展（1 项）

### 4.1 批量回路指标序列接口（新增）

**目的**：支撑"列头趋势 → TOP N 回路历史对比"，避免前端 N 次分页拉取。

```
GET /performance/loops/metric-series
```

| 参数 | 类型 | 说明 |
|---|---|---|
| loopIds | string | 逗号分隔回路 ID（≤10 个，超限 400） |
| metricKey | string | 指标键（白名单校验，snake_case，同 SNAPSHOT_SORT_COLUMNS 扩展集） |
| startTime / endTime | ISO 8601 | 时间范围 |
| granularity | enum | raw / hour（默认 hour；raw 用于短窗细看） |

返回：

```json
{
  "metricKey": "steady_rate",
  "series": [
    { "loopId": "...", "loopTagName": "L101-汽提塔顶温", "points": [{"ts": "...", "v": 92.1}, ...] },
    ...
  ]
}
```

实现要点：

- service 挂 `app/services/performance.py`（与 `list_loop_snapshots` 同文件），endpoint 挂 `api/v1/endpoints/performance.py`。
- 查询 `kpi_snapshot_hourly`：`loop_id IN (...) AND ts_start BETWEEN ... AND {metric_key} IS NOT NULL`，按 loop_id, ts_start 排序。
- metricKey 白名单 = SNAPSHOT_SORT_COLUMNS ∪ {oscillation_rate, saturation_rate, instrument_fault_rate, stiction_index, settling_time, output_trip_index}（数值列且语义为"单值时间序列"的指标；DISPLAY_ONLY 统计/阀门指标暂不进白名单）。
- SQL 单次查询全量返回（10 回路 × 168h 小时快照 ≈ 1680 行，无分页压力）。
- 权限与 `/performance/loops/snapshots` 一致。

### 4.2 现有接口零改动确认

- `GET /performance/loops/snapshots`：latestOnly=true 已满足矩阵主体数据（多回路 × 全指标一次返回）。
- 排序白名单 7 指标已覆盖核心 Tab 的可排序列。
- 不修改返回体、不改分页上限。

## 5. 数据流

```
矩阵主体：
  筛选变更/查询 → getLoopSnapshotsApi({
      plantNodeId?, loopId?, latestOnly: true(或窗口),
      startTime/endTime?, page, pageSize: 50
    }) → KpiSnapshotItem[] → 按 3.3 分组渲染列 → 3.4 着色

单元格下钻（单回路单指标趋势）：
  单元格点击 → 抽屉 → getLoopSnapshotsApi({
      loopId, latestOnly: false, startTime/endTime, pageSize: 100
    } 分页拉取) → 提取 {metricKey} 序列 → EchartsUI 折线

列头趋势（多回路对比）：
  列头趋势 icon → 当前列指标 + 当前列筛选/排序得到的 TOP N 回路 ID →
    getLoopMetricSeriesApi(loopIds, metricKey, startTime/endTime) →
    N 条折线叠加 + 图例
```

## 7. 风险与约束

| 风险 | 缓解 |
|---|---|
| 回路数多时矩阵纵向过长 | 服务端分页 50/页；后续可加"仅异常回路"快捷筛选 |
| 统计/阀门组 DISPLAY_ONLY 指标 INCONCLUSIVE 比例高 | 该组默认不着色 + 斜纹 N/A，视觉降噪；Tab 非默认 |
| metric-series 白名单遗漏指标 | 白名单配置化到 PARAM_META 同源定义（可选优化，初版硬编码） |
| 与工作台 EvalHeatMatrix 视觉口径不一 | 单元格色值/斜纹样式对齐 EvalHeatMatrix 常量，必要时抽公共样式 |

## 8. 决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 独立菜单 vs 嵌入回路性能页 | **独立菜单**（用户 2026-08-27 决策） | 定位为"全回路指标集中查看"专用页，与列表页职责分离 |
| 矩阵实现形态 | ant Table + 分组列 + bodyCell 着色 | 复用 history-snapshots 页成熟模式，不引入 CSS Grid 自绘（EvalHeatMatrix 为固定 6 列小矩阵，回路级动态列用 Table 更稳） |
| 单元格历史趋势数据 | 单回路走现有分页接口；多回路对比走新批量接口 | 平衡改动量与性能（N 次分页拉取仅多回路场景不可接受） |
| 着色范围 | 仅率类定级指标，诊断数值类不着色 | 避免无标准阈值指标误导读；符合 Calm UI 降噪原则 |
