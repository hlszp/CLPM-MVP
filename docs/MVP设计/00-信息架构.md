## 关键依赖关系

- **导航顺序**：监控 → 评估 → 诊断 → 整定 → 处置 → 报告 → 配置 → 系统（按 `order` 1~8，统计报告升一级菜单后配置→7、系统→8，2026-08-23 IA 优化 P0~P4；2026-08-24 显示名“统计报告”改为“报告”）。
- **监控默认首页分流**：EXPERT 角色进「回路工作台」，其余角色进「装置工作台」。
- **隐藏项（不占导航但路由有效）**：
  - 监控：回路实时表格 `/loop/monitor`、回路实时表格（旧版）
  - 配置：回路台账、PID 结构模板
  - 各类 `legacy redirect`（链路/测点/回路/工厂模型/数据管理/指标配置/诊断配置/预警规则等旧路径兼容）

## 角色权限要点

| 角色 | 权限范围 |
|------|----------|
| ADMIN | 全部菜单 |
| IC_ENGINEER | 监控/评估/诊断/整定/处置/报告/配置（链路/指标/诊断/预警规则配置除外）+ 系统查看 |
| PE_ENGINEER | 监控/评估/诊断/整定/处置/报告查看 + 部分配置查看（链路/指标/诊断/预警规则不可见） |
| SPONSOR | 监控/评估/诊断/整定/处置/报告查看，无配置/无系统 |
| EXPERT | 监控/诊断/整定/处置/报告，无评估/无配置菜单 |

> 报告角色口径：父菜单全角色可见；绩效/收益报告不含 EXPERT；订阅配置仅 ADMIN（见 `reports.ts` authority）。
