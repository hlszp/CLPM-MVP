## 关键依赖关系

- **导航顺序**：工作台 → 监控 → 评估 → 诊断 → 整定 → 处置 → 报告 → 配置 → 系统（按 `order` 0~8；工作台 2026-08-25 v2.0 挂 order=0，统计报告 order=6 为 2026-08-23 IA 优化 P0~P4 产物，2026-08-24 显示名“统计报告”改为“报告”）。
- **监控默认首页分流**：EXPERT 角色进「回路工作台」，其余角色进「装置总览」。
- **隐藏项（不占导航但路由有效）**：
  - 监控：回路实时表格 `/loop/monitor`、回路实时表格（旧版）
  - 评估：`/metric/kpi-report` 旧路径 redirect（→ `/reports/performance`）
  - 处置：处置工作台 `/handling/workbench`、处置报告 `/handling/statistics`（报告已迁 `/reports/handling`）
  - 配置：回路台账、PID 结构模板
  - 系统：订阅配置 `/system/reports` redirect（→ `/reports/subscription`）、算法参数配置 `/system/algorithm-params` redirect（→ `/config/metric`）
  - 预警：`/alert/events`、`/alert/rules`（预警事件归监控、预警规则归配置后的旧路径兼容）
  - 各类 `legacy redirect`（链路/测点/回路/工厂模型/数据管理/指标配置/诊断配置/预警规则等旧路径兼容）

## 角色权限要点

| 角色 | 权限范围 |
|------|----------|
| ADMIN | 全部菜单 |
| IC_ENGINEER | 监控/评估/诊断/整定/处置/报告/配置（链路/指标/诊断/预警规则配置除外）+ 系统查看 |
| PE_ENGINEER | 监控/评估/诊断/整定/处置/报告查看 + 部分配置查看（链路/指标/诊断/预警规则不可见） |
| SPONSOR | 监控/评估/诊断/整定/处置/报告查看，无配置/无系统 |
| EXPERT | 监控/诊断/整定/处置/报告，无评估/无配置菜单 |

> 工作台角色口径：`/workbench` 全角色可见（ADMIN/EXPERT/IC_ENGINEER/PE_ENGINEER/SPONSOR），为跨模块总览入口，不设 meta.module、不参与模块热插拔过滤。
> 评估角色口径：性能总览/指标分析/回路性能全角色可见（EXPERT 除外，EXPERT 无评估菜单）；评估记录/评估任务仅 ADMIN/IC_ENGINEER。
> 报告角色口径：父菜单全角色可见；绩效/收益报告不含 EXPERT；订阅配置仅 ADMIN（见 `reports.ts` authority）。
