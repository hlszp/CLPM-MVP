## 风险点

1. **workbench.vue 体量大（3612 行）**：需谨慎删除 DOM 块，避免误删评估区代码。建议按行号范围逐步删除，每步验证。
2. **provide/inject 链**：`diagnosisDetail`/`tuningLatest` 等通过 provide 注入子组件，删除前需确认子组件不再 inject（阶段 3 删除子组件文件后此风险消除，但阶段 2 需保留 `v-if="!MVP_DISABLE"` 守卫或直接删除 DOM）。
3. **CSS 样式残留**：删除 DOM 后对应 CSS 类不会报错但增加包体积，可在阶段 3 统一清理。
4. **类型定义滞后**：`MonitorApi.AttentionSource` 和 `LifecycleStageName` 可能仍包含 TRACKER/VERIFICATION/DIAGNOSE 等枚举值，前端删除展示映射即可，不改类型定义（类型定义在阶段 3 或后端契约更新时统一处理）。
