## 1. 通用映射约定（逐项适用，不再重复填写）

| # | 约定 | 内容 |
|---|---|---|
| G1 | 窗口映射 | 工作台 24h/7d/30d 窗口 → 明细页 `startTime`/`endTime`。**窗口边界以 `workbench_window_summary` 的窗口起止为准**（而非前端跳转瞬间的 now），避免预计算窗口与实时查询错位导致数字对不上 |
| G2 | scope 映射 | workbench scopeId（整数，`plant_node.source_node_id` 口径）→ 明细页 `plantNodeId`（字符串，递归子树语义）。映射链路：A-00 `/workbench/scope-tree` 取节点 → plantNodeId；口径范式参照 `backend/app/services/workbench_tuning.py` `_get_scope_source_ids` |
| G3 | 评估快照粒度 | 计数类对账（参评回路数、等级分布）用 `latestOnly=true`（回路粒度）；历史明细/趋势用 `latestOnly=false`（快照粒度）。**带窗口下钻必须显式传 `latestOnly=false`**（默认 true 是已知陷阱） |
| G4 | 模块禁用态 | 诊断/整定/处置被模块管理禁用（MAINTENANCE/UNINSTALLED）时，对应统计卡片**不下钻**，跟随 ModuleVeil 展示 |
| G5 | 空结果态 | 下钻落地 0 结果时，明细页展示"当前口径下无记录"空态，并**展示带入的筛选条件**便于用户自查口径 |
| G6 | 明细页接参 | 各明细页支持从 URL query 读取筛选初值（处置已有 `?focus={id}` 契约，推广为通用模式；评估/诊断/整定明细页目前均不读 route.query，属本次新增工作） |
| G7 | 参数名以 API 签名为准 | 各页参数名不同构（评估 `startTime/endTime`、工单 `plannedBefore/plannedAfter`），逐项以签名核对，不凭模式臆测 |
