# 08 - 诊断模块实施计划（Phase 1）

> **For agentic workers:** 本计划按任务逐项执行，步骤用 checkbox（`- [ ]`）跟踪。设计事实来源：`07-诊断模块设计方案.md`。

**Goal:** 落地诊断模块 Phase 1：11 个元算子迁移 + 族内融合 + 6 分类映射 + `diagnosis_run` 表 + 5 个 API + 前端两页（诊断工作台/诊断记录）+ 回路工作台入口，全部门禁通过。

**Architecture:** 算子层（`app/services/diagnosis_operators/`，无状态纯函数+注册表）→ 编排层（`app/services/diagnosis_orchestrator.py`，取数→门禁→算子→融合→分类→快照→落库）→ Celery 任务（`app/tasks/diagnosis_v2.py`）→ API（`app/api/v1/endpoints/diagnosis_v2.py`）。旧 `diagnosis_engine.py`/`endpoints/diagnosis.py` 按屏蔽策略**原样保留不删**，新代码走新文件名，算法内核从引擎**逐函数等价复制**（带等价性回归测试）。

**Tech Stack:** FastAPI + SQLAlchemy(async) + Alembic + Celery(AsyncTask/TaskTracker) + numpy/scipy；Vue3 + antd-vue + EchartsUI + vitest。

**关键实现决策（对设计文档的落地细化）：**

| # | 决策 | 理由 |
|---|---|---|
| D1 | 新文件名一律 `_v2` 后缀（endpoints/diagnosis_v2.py、tasks/diagnosis_v2.py），旧文件不删不改 | 遵守 MVP"注释屏蔽保留"硬约束；旧 diagnosis.py(59KB)/diagnosis_engine.py(174KB) 保留回滚能力 |
| D2 | 算子内核从 `diagnosis_engine.py` **复制**（非 import）：每个算子文件含 `# 复制自 diagnosis_engine.py Lxxxx-Lyyyy` 溯源注释 | services 不得依赖 tasks 包；import 会触发旧任务注册，破坏屏蔽 |
| D3 | 取数走引擎同路径：`get_provider().make_query_fn(db)` 宽表查询（tag_roles=pv/sp/op/mode, interval_s=1）+ B4 异常点剔除 + `ConfidenceEvaluator` | 设计文档写"DataPlanner 统一入口"，落地时诊断需要原始波形+质量码+MODE（bundle 面向 KPI mask），引擎直查路径已验证；仍满足"本地 TDengine 唯一数据源"红线 |
| D4 | 阈值 Phase 1：算子默认值来自 `OperatorMeta.threshold_schema`（与旧 `_THRESHOLD_SCHEMA` 键值一致）；四级覆盖经 `diagnosis_threshold.recommend_for_loop()` 合并（旧表有种子数据，缺失键回退默认） | 等价迁移优先，覆盖能力复用 |
| D5 | `OperatorMeta` 增加 `diag_code` 字段（旧诊断码，如 OSCILLATION），用于阈值分组查询与算子启停 | 与旧阈值体系对齐 |
| D6 | 时间口径：全库 naive UTC（项目约定，无 TIMESTAMPTZ） | models/base.py 约定 |
| D7 | TaskType 复用：查 `task_tracker.py` 的 TaskType 枚举，若已有 DIAGNOSIS 用之，否则在枚举中新增 | 任务中心可见 |
| D8 | GET /diagnosis/runs 支持按 `taskId` 筛选 | 工作台批量发起后按任务拉结果 |

```python
@operator(OperatorMeta(
    name="oscillation_fft", display_name="FFT 频域振荡检测", family="oscillation",
    diag_code="OSCILLATION",
    description="对 PV 做 FFT（Hann 窗），主峰能量占比+完整周期数+信噪比三条件判定振荡",
    required_signals=("pv",), min_sample_rate=0.0,
    outputs_schema={"frequency": "主峰频率(Hz)", "amplitude": "主峰幅值", "index": "振荡指数"},
    threshold_schema={"fft_osc_index_threshold": 0.3, "fft_min_zero_crossings": 5,
                      "fft_min_cycles": 2.0, "fft_min_snr": 6.0},
    symptom_tags=("OSCILLATION",), enabled_by_default=True, fast_group=False,
))
def detect(input: OperatorInput, threshold: dict[str, Any]) -> OperatorResult:
    pv = input.signals.get("pv")
    if pv is None or len(pv) < 16:
        return OperatorResult("oscillation_fft", executed=False, skip_reason="pv 数据不足")
    res = _fft_kernel(pv, float(input.meta.get("sample_interval", 1.0)), threshold)
    feats = {k: v for k, v in res.items()
             if k not in ("detected", "confidence", "frequencies", "amplitudes")}
    return OperatorResult(
        "oscillation_fft", executed=True, detected=bool(res["detected"]),
        confidence=float(res["confidence"]), features=feats,
        evidence=[EvidenceItem("osc_index", round(float(res["index"]), 4),
                               threshold.get("fft_osc_index_threshold"),
                               "主峰能量占比" + ("达标" if res["detected"] else "未达标"))])
```
