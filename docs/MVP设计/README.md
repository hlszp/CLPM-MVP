# CLPM-MVP 精简改造设计文档

## 文档目的

本目录是 CLPM-MVP 项目精简改造的设计事实来源。原项目（CLPM v6.2）包含 6 大模块（工作台/回路管理/性能评估/诊断中心/回路整定/系统管理），MVP 版本只保留**监控、评估、配置、系统**四个模块，彻底删除**诊断、整定**模块以及相关的**流程闭环**内容。

## 改造原则

1. **彻底删除而非注释屏蔽**：当前 MVP 第一轮改造采用"注释屏蔽"策略（路由导出空数组、条件渲染 `v-if="false"`），后续改造应彻底删除相关代码，减少维护负担
2. **保留模块功能完整**：监控、评估、配置、系统四个模块的功能不受影响，种子数据和链路配置全部保留
3. **基础设施完整保留**：PostgreSQL + TDengine + Redis + Celery 全部保留，端口隔离运行
4. **数据库 schema 不改动**：ORM 模型和 Alembic 迁移脚本保持原样，避免数据迁移风险（诊断/整定表保留但不再写入）

## 使用场景

生产环境最小可用版：提供控制回路性能监控与评估能力，不具备整定功能；诊断功能按 [07-诊断模块设计方案.md](07-诊断模块设计方案.md) 重新建设（2026-08-16 立项，只诊断+建议、仅手动触发、按原因分类）。
