## 1. 背景与定位

CLPM-MVP 已完成"监控 → 评估 → 诊断 → 整定 → 处置"全链路闭环重建。现有系统面向工程人员进行配置、运维与细节分析（装置工作台=工程分析视角）。本方案新增**平台驾驶舱**，面向**管理者与操作人员**提供 1920×1080 满屏总览：

- 总览装置、回路的性能与关键指标、发展趋势、处置待办
- 纯查看、零操作；所有配置/运维/细节工作在后台（现有系统）完成
- 驾驶舱与后台之间做有效的权限隔离

**与装置工作台差异化并存**：装置工作台（`/dashboard/workbench`）是工程分析工具（排名联动下钻分析）；驾驶舱是管理驾驶视角（状态—趋势—行动三层总览 + 行动分发提示）。两者互不替代。

## 2. 设计铁律

1. **纯查看零操作（Poka-Yoke）**：驾驶舱内不出现任何写操作入口。所有卡片/数值/行的点击只产生两种效果——**深度弹窗**（舱内查看详情）或**区块联动**；不出现任何直接跳转后台的链接或按钮。
2. **唯一后台入口**：顶栏"管理后台"按钮是唯一跳转后台的入口，且点击时做权限验证（见 §3.2）。
3. **一屏原则**：1920×1080 满屏无页面滚动，区块内部滚动（复用 04 系统概览标杆页口径）。
4. **Calm UI**：无自动轮播、无闪烁动效；实时数据刷新以数值/曲线平滑更新呈现。

## 3. 用户角色与权限

### 3.1 角色映射（不新增角色）

| 驾驶舱用户 | 现有角色 | 使用方式 |
|---|---|---|
| 管理者 | SPONSOR | 默认落地驾驶舱；纯驾驶舱用户（默认无后台权限） |
| 操作人员 | IC_ENGINEER / PE_ENGINEER | 默认落地驾驶舱；经"管理后台"入口进入后台执行操作 |
| 其它 | ADMIN / EXPERT | 保持原落地页；菜单可进驾驶舱 |

登录后默认落地逻辑（前端路由守卫）：角色 ∈ {SPONSOR, IC_ENGINEER, PE_ENGINEER} → 重定向 `/cockpit`；否则保持现行为。

### 3.2 "管理后台"入口权限（配置化角色清单）

- sys_config 新增配置键：`cockpit.backend_access_roles`，值为逗号分隔角色列表，**默认 `IC_ENGINEER,PE_ENGINEER,ADMIN,EXPERT`**（SPONSOR 默认不可进后台）。
- 前端顶栏按当前用户角色与该配置判断"管理后台"按钮可见/可用；无权限角色点击 → 提示"当前角色无后台访问权限"。
- 进入后台后按现有角色权限矩阵隔离（复用现有权限体系，无新增）。

### 5.2 区块规格

| 区块 | 内容 | 数据源（API） | 交互（全部舱内） |
|---|---|---|---|
| §1 指标带 | 6 卡：①全厂综合评分（五档色染+环比）②自动投用率（AUTO+CAS+REMOTE+APC 占比+环比）③回路总数（附五色等级分布微型条）④劣化回路数（**双口径**：主数字=警告+不合格数；副标=环比下降回路数）⑤处置待办数（待处理+处理中+验证中；超期红标）⑥预警事件数（时间窗内活跃+未确认数） | `GET /cockpit/overview`（新，一次取齐） | 点击卡片 → 清单类弹窗（如④→劣化回路清单） |
| §2 装置排名横道图 | **v1.3 改回排名（固定）**：各装置按综合评分降序横道图——排名徽章（TOP3 金银铜）+装置名+劣化回路数+评分（五档色染）+评分横道（长度=得分，五档色）+全厂平均参考竖线（虚线）；**固定全厂口径，不随节点变更，无节点选择器** | `getNodeRankingApi`（现有） | 纯展示，无联动 |
| §3 绩效发展趋势 | 综合评分+自动投用率双曲线；下方五色等级分布堆叠面积；粒度随时间窗自适应（24h→小时，7d/30d→天）；恒为全厂口径（v1.3：总览页无节点联动） | `getBoardTrendApi`（现有） | 悬浮查数值（无点击行为） |
| §4 处置待办 | 顶部五态胶囊（待处理/处理中/验证中/已闭环/重开，各带计数）；下方 TOP 待办清单：回路号+问题摘要+状态+停留时长（VERIFYING>24h 红标"验证超期"） | `GET /handling/statistics` + `GET /handling/items`（现有） | 点待办行 → 待办详情弹窗 |
| §5 闭环治理漏斗 | 治理转化链四级管道：发现异常 N₁（时间窗内评估发现劣化回路数）→ 完成诊断 N₂（diagnosis_run COMPLETED 按回路去重）→ 产出方案 N₃（整定方案确认数）→ 处置闭环 N₄（loop_action_item CLOSED）；级间转化率；底部积压条（待处理 x·处理中 y·验证中 z） | `GET /cockpit/overview`（新） | 点阶段 → 阶段明细弹窗（该级回路/记录清单） |
| §6 问题回路 TOP-8 | 表格：回路号+名称+装置+综合评分+**最差维度标签**（六维中得分最低维度，如"平稳率 42"）+7 天趋势火花线+状态；按劣化程度排序（全厂口径） | `getRankingApi` + loop snapshots（现有） | 点行 → 回路详情深度弹窗 |
| §7 预警事件流 | 时间窗内最新预警 8 条：级别色条+规则名+回路+触发时间+持续时长；未确认高亮 | 预警事件 API（现有）+ WebSocket `/api/v1/ws/alerts` 推送 | 点事件 → 预警事件详情弹窗 |

### 5.3 时间窗口径

- 档位：近 24h（默认）/ 近 7 天 / 近 30 天，页面级总开关，驱动 §1/§2/§3/§5/§6/§7。
- §7 预警流为实时口径（WebSocket 增量 + 时间窗过滤）。
- 环比口径：与上一等长时间窗对比。

### 5.4 六维指标统一口径（v1.1 用户定义）

全系统雷达图统一采用以下六维（0-100 标尺）：

| 维度 | 别名/口径说明 |
|---|---|
| 自控率 | 平均自控率（=自动投用率：AUTO+CAS+REMOTE+APC 占比） |
| 平稳率 | 平稳率（稳定率） |
| 准确率 | 准确率 |
| 快速率 | 快速率 |
| 好值率 | 好值率 |
| 有效率 | 有效自控率（有效质控率） |

**雷达图中心显示综合评分**（五档色染）。

适用范围（v1.3）：页2 节点性能雷达（左树联动）、页2 回路详情雷达、回路详情弹窗雷达——全部同源口径，避免多套维度词汇；总览页不再出现雷达图。

### 6.3 右侧详情面板（页2 核心交互，纯只读，两态切换）

**态一：聚合视图（默认，两段弹性布局，v1.5 无滚动条）**：

| 区段 | 内容 |
|---|---|

**态二：单回路详情（点击回路卡）**（与回路详情弹窗内容同源，弹性布局）：

| 区块 | 内容 |
|---|---|
| 头部 | 等级徽章 + 回路号/名称/装置 + 综合评分 + ‹ › 连续浏览导航 + 取消选择 |
| 实时数据 | PV/SP/OP/模式/P/I/D/可信度 八项网格（WebSocket 实时刷新，绿色呼吸点标识） |
| 实时趋势（固定高 ~130px） | 近 24h PV/OP 曲线（虚线=SP） |
| 六维雷达（**flex 弹性**） | 该回路六维得分（统一口径，中心=综合评分） |
| 最近闭环记录 | 最近诊断结论 + 处置状态摘要（只读） |

**交互规则**：

- **卡片墙分页（v1.4）**：每页 20 个回路卡，**右上角分页控件**（‹ 第 x/y 页 · 共 N 个 ›）切换上一页/下一页；筛选/排序/装置变化后若存在选中回路则自动跳到其所在页，否则回到当前结果第 1 页；详情面板 ‹ › 连续浏览跨页时自动翻页并保持卡片选中高亮。
- ~~顶部等级统计条~~（v1.4 已删除：等级分布由总览 §1 回路总数卡的分布微型条与筛选按钮承担）。
- **左树节点点击 → 联动右侧面板**：顶部模式柱状图与中部雷达切换为该节点口径；同时过滤卡片墙（节点计数角标显示回路数）。
- 等级/模式筛选 + 排序（评分降序/劣化降序）。
- **点击回路卡 → 右侧内联详情面板即时展示（态二）**（不遮挡卡片墙，便于连续浏览比对多回路）。
- 面板头部 ‹ › 在当前筛选结果内逐个浏览（跨页自动翻页）；× 取消选择回到聚合视图。
- 筛选/排序/装置切换后，若选中回路被过滤掉则自动回到聚合视图。
- PV/SP/MODE 经现有 SignalR 实时通道刷新（每回路订阅其 tag）。

## 7. 深度弹窗体系（4 类，统一规格）

| 弹窗 | 触发源 | 内容 |
|---|---|---|
| 回路详情弹窗 | 页1 §6 表格行 / 清单类弹窗行（页2 回路卡走右侧内联详情面板，不入弹窗） | 头部（回路号+名称+装置+等级徽章+评分）；三列主体：实时值区（PV/SP/OP/MODE/P/I/D）｜趋势曲线（时间窗内 PV/SP/OP）｜六维雷达（统一口径，中心=综合评分）；底部：最近闭环记录摘要（最近诊断结论+处置状态，只读）。**无任何操作按钮** |

统一规格：宽 ~880px 居中；深/浅主题随驾驶舱主题；ESC/遮罩关闭；弹窗内数据随打开时时间窗口径拉取。

## 8. 视觉与主题

- **深色默认**：深蓝黑底（#0A1220 系）+ 高对比数据色，适合投屏与长时间观看；提供浅色切换（对齐后台浅色工业风）。
- **主题实现**：驾驶舱容器根元素挂 `data-theme`，CSS 变量**作用域限于驾驶舱容器**（不污染后台 vben 全局主题）；偏好 localStorage 持久化（键 `cockpit-theme`）。
- **状态色语义**：遵循现有色彩约定表（等级五档、五态、预警级别），深色主题下使用提亮变体保证 WCAG AA 对比度。

## 13. 验收标准

1. 1920×1080 浏览器满屏两页均无页面级滚动，区块内滚动正常。
2. 驾驶舱内全部点击行为仅为弹窗/联动；Grep 检查驾驶舱组件无后台路由跳转调用（除顶栏"管理后台"）。
3. SPONSOR 默认不可见/不可用"管理后台"；`cockpit.backend_access_roles` 配置修改后无需重启即生效。
4. 深/浅主题切换仅影响驾驶舱容器，后台主题不受影响；刷新后偏好保持。
5. 驾驶舱接口只读：无任何 POST/PUT/DELETE 调用。
6. 预警 WebSocket 推送后 §7 秒级更新；待办轮询 60s；KPI 5min 自动刷新可暂停。
7. 节点性能雷达仅存在于页2（含回路级雷达与弹窗雷达），随工厂模型左树选择联动刷新，中心显示综合评分；六维口径全系统统一（自控率/平稳率/准确率/快速率/好值率/有效率）。
8. 页2 右侧面板聚合视图为两段弹性布局：顶部模式微型柱状图（固定高）与中部雷达（flex 弹性）随左树节点联动；面板任何屏幕高度均不出现上下滚动条（v1.5 已删"全厂装置排名"段，全厂排名仅存在于总览 §2）。
9. 总览 §2 为装置排名横道图：固定全厂口径、不随节点变更、无节点选择器；总览页无任何节点联动（§3/§6 恒为全厂口径）。
10. 顶栏三段式：主标题「控制回路绩效监控驾驶舱」居中且两侧有装饰条，「总览/回路」Tab 位于左端；页2 无等级统计条。
11. 页2 卡片墙分页：每页 ≤20 张回路卡，右上角分页控件可切换页码并显示"第 x/y 页 · 共 N 个"；筛选/排序/装置切换后页码正确回跳；详情面板 ‹ › 跨页浏览时自动翻页。
