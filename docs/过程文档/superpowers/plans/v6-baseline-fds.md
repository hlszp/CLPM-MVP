## 2. 术语表

FDS 未设独立"术语表"章节，以下术语在文档各处明确定义：

| 术语（中文） | 英文/缩写 | 简要定义 |
|---|---|---|
| 工作台（门户） | Portal | 性能总览首页，全角色日常作业入口，聚合多模块数据 |
| AAS Tag 同步层 | Tag Sync | 系统定期从 AAS 同步所有 OPC tag 位号信息；同步的是 tag 位号，非回路实体 |
| 数据接入层 | Ingestion | 调度器按引擎规则触发，拉取已关联 tag 的原始时序数据 |
| 数据清洗层 | Cleansing | 执行质量码处理策略，为每个时间戳每个 Tag 打 valid 标记 |
| 数据编排层 | DataPlanner | 读取指标数据需求契约，按 tagGroup 合并查询计划，优先查 DataBlock 缓存，分发 MetricDataBundle [v4.0 新增] |
| tagGroup | - | DataPlanner 引入的概念，5 个分组（BASE/OP_HF/PVOP_HF/MODE_HF/QUALITY_HF），用于合并查询计划 |
| DataBlock Cache | - | Redis + zstd + 分层 TTL + LRU 的数据缓存，降低 TDengine 查询压力 [v4.0 新增] |
| MetricDataBundle | - | DataPlanner 生成的指标数据包，分发给对应指标计算器 |
| Metric Validity Mask | - | 决定各指标有效点集合的标记（如准确率取 pv_valid && sp_valid） |
| KEEP_ALL_WITH_VALIDITY | - | 质量码处理策略，不删除任何数据点，为每个时间戳每个 Tag 打 valid=True/False 标记 [v4.0] |
| 回路 | Loop | 系统核心实体，由用户在 CLPM 系统中创建并关联 7 个 OPC tag |
| 回路状态 - 就绪 | Ready | PV/SP/OP/MODE 四个必填 tag 全部关联成功，回路进入评估流程 |
| 回路状态 - 部分就绪 | Partial | 必填 tag 缺失，回路标红提示，不参与评估计算 |
| 回路状态 - 数据不足 | Inconclusive | 好值率低于设定阈值（默认 valid_rate < 0.20），不计算评分，打灰色标签 |
| 控制类型 | control_type | 枚举值 STABLE/SLOW/FAST/LOGIC，存储于回路台账，决定评分权重模板 |
| 重要等级 | importance_level | 数值类型 1/2/3（一/二/三级），存储于回路台账，决定装置级聚合权重（一级=3、二级=2、三级=1）[v5.1 类型修订] |
| 是否参与评估 | include_in_evaluation | Boolean，默认 true，决定回路是否进入综合性能评分与装置级 KPI 聚合 [v5.0 新增] |
| 3+1+8 指标体系 | - | 3 核心质量指标 (A/F/S) + 1 投用指标 (R) + 8 辅助诊断指标，共 12 项 [v5.0 修订] |
| 回路级性能评分 | Loop-Level Score / P_loop | 基于控制类型权重计算单回路 A/F/S 加权评分，公式 P_loop = (A·a + F·f + S·s)/(a+f+s) × (R/100) |
| 综合性能评分 | Composite Performance Score / P_composite | 基于回路重要等级权重 × 回路级评分加权聚合，装置级/单元级 |
| 装置级三大 KPI | - | 综合性能 / 平均自控率 / 稳定率（外加实时自控率作为运行态即时指标）[v5.0 新增] |
| 实时自控率 | Auto_rt | 当前时刻 MODE=AUTO 的参评回路数 / 装置参评回路总数，每分钟刷新 |
| 性能定级 | - | 5 级分类：EXCELLENT/GOOD/FAIR/WARNING/POOR（一级~五级），国标默认阈值可配置 |
| 指标可信度 | - | A/B/C/D/E 五级，基于 valid_rate 分级（A≥0.95、B 0.80-0.95、C 0.60-0.80、D 0.20-0.60、E<0.20）[v4.0] |
| 有效点率 | valid_rate | valid=True 点数 / 总点数，∈ [0, 1]，用于可信度分级 |
| Action Tracker | - | 异常跟踪子模块，v3.0 中降级为诊断中心子模块，状态机 PENDING→IN_PROGRESS→IMPLEMENTED/IGNORED |
| 8 类诊断标签 | - | OSCILLATION/VALVE_STICTION/OVERAGGRESSIVE/OVERCONSERVATIVE/EXTERNAL_DISTURBANCE/QUALITY_ABNORMAL/OUTPUT_SATURATION/MANUAL_REVIEW |
| Dempster-Shafer 证据融合 | - | 多诊断算法置信度融合方法，公式 C_fused = (Π cᵢ) / (Π cᵢ + Π (1-cᵢ)) |
| 表达式引擎 | simpleeval | 安全沙箱执行用户自定义公式；v5.0 起仅用于诊断规则配置，不再用于性能指标计算 |
| 算法版本号 | - | 格式 `<algorithm_name>v<major>.<minor>`，如 KPI_CALC_v1.0、IMC_TUNE_v1.0 |
| FOPDT | First-Order Plus Dead Time | 一阶惯性加纯滞后模型 G(s) = K·e^(-θs) / (τs+1) |
| SOPDT | Second-Order Plus Dead Time | 二阶加纯滞后模型，FOPDT 拟合度 R²<0.85 时升级 |
| RK4 | Fourth-Order Runge-Kutta | 四阶龙格-库塔法，用于闭环仿真 ODE 求解 |
| LTTB | - | 降采样算法，用于大数据量波形渲染（maxPoints=2000） |
| RBAC | Role-Based Access Control | 基于角色的权限控制 |
| GB/T 44693.2-2024 | - | 国家标准，CLPM 性能指标算法依据 |

## 3. 模块清单

FDS §5 核心模块详细功能规格共包含 **5 个业务模块 + 1 个门户**：

| 序号 | 中文名称 | 英文名称 | 章节号 | 职责描述 |
|---|---|---|---|---|
| 0 | 工作台（门户） | Portal | §5.1 | 性能总览首页，全角色日常作业入口，聚合性能评估、诊断中心、异常跟踪多模块数据。顶部筛选栏 + KPI 卡片区 + 低效回路列表 + 趋势摘要 + 组合趋势图 |
| 1 | 回路管理 | Loop Management | §5.2 | 管理回路全生命周期，自包含"配置 → 运行"两态。AAS Tag 同步、工厂层级配置、回路台账管理、Tag 关联管理、回路监控列表与运行详情 |
| 2 | 性能评估 | Performance Assessment | §5.3 | 自包含"指标配置 → 引擎规则 → 全量计算 → 全局看板 → 低效排行 → 统计分析"全流程 |
| 3 | 诊断中心 | Diagnosis Center | §5.4 | 自包含"指标配置 → 诊断列表 → 诊断详情 → 异常跟踪 → 统计分析"全流程。Action Tracker 在 v3.0 中降级为本模块子模块 |
| 4 | 回路整定 | Loop Tuning | §5.5 | **Phase 2 功能，原型先行设计**。整定工作台、模型辨识、整定算法、闭环仿真、整定效果统计。Phase 1 仅原型页面，Phase 2 实现算法 |
| 5 | 系统管理 | System Management | §5.6 | 用户与角色管理、审计日志、安全边界说明、自动报表管理 |

> 注：FDS 变更记录 v3.0 描述为"由 5 模块升级为 6 模块 + 1 门户（新增工作台门户、回路整定 Phase 2 原型先行）"。AGENTS.md 中表述为"6 模块 + 1 门户：工作台 / 回路管理 / 性能评估 / 诊断中心 / 回路整定 / 系统管理"。本提取以 FDS §5 实际章节结构为准（5.1 门户 + 5.2~5.6 五个业务模块）。

## 4. 功能项列表（按"配置/运行/分析"三态组织）

### 4.1 工作台（门户）— §5.1

工作台门户未明确区分三态，整体偏向"运行/分析"态：

| 功能点 | 三态归属 | 说明 |
|---|---|---|
| 顶部筛选栏 | 运行 | 全厂/装置/单元级联筛选；日/周/月统计粒度单选（默认日统计）；筛选条件持久化至 URL |

### 4.5 回路整定 [Phase 2，原型先行设计] — §5.5

> Phase 1 仅原型页面，Phase 2 实现算法。整定方法严格对齐 GB/T 44693.2-2024 §8。

| 功能点 | 子功能 | 说明 |
|---|---|---|
| 整定工作台 | 待整定回路列表 | 来自诊断建议或手动添加 |
| | 整定状态概览 | 当前评分、历史整定记录、推荐状态 |
| | 任务快捷入口 | 模型辨识/整定算法/闭环仿真三个快捷入口 |
| 模型辨识 | 辨识参数配置 | 数据段选择、采样周期、模型类型（FOPDT/SOPDT）|
| | 辨识结果 | FOPDT 两点法+面积法；SOPDT 继电器反馈+非线性最小二乘；R²<0.85 升级 SOPDT |
| 整定算法 | 算法选择 | IMC/Lambda/Ziegler-Nichols/Cohen-Coon/SIMC（5 种 PID 整定）|
| | 参数推荐 | 推荐 PID 参数表（P/I/D 三组对比）、性能预测指标 |
| 闭环仿真 | 仿真参数 | 当前 PID vs 推荐 PID 切换、扰动类型、仿真时长 |
| | 仿真结果 | RK4 求解 FOPDT/SOPDT，PID 增量式离散化；阶跃响应双波形对比、性能指标对比表 |
| 整定效果统计 | 效果统计 | 整定前后 KPI 对比柱状图、整定效果趋势折线 |

**7 种整定方法**：FOPDT 模型辨识、SOPDT 模型辨识、IMC 整定法、Lambda 整定法、Ziegler-Nichols 整定法、Cohen-Coon 整定法、SIMC 整定法。

### 4.7 任务管理（独立模块？）

FDS 中任务管理**不是独立模块**，而是性能评估模块的子节（§5.3.11，[v4.0 新增]）。任务管理区分两类：

| 任务类型 | 触发方式 | 存储表 | 是否参与装置级聚合 |
|---|---|---|---|
| 标准任务 | 每小时定时评估（调度器自动触发）| kpi_snapshot_hourly | ✅ 参与 |
| 自定义任务 | 按需触发（用户手动指定回路+时间窗+指标范围）| kpi_snapshot_custom | ❌ 不参与 |

任务状态：PENDING/RUNNING/SUCCESS/FAILED/INCONCLUSIVE。

## 6. 关键设计决策

FDS §1.3 明确声明四项产品化设计原则，并在各章节做出以下关键设计决策：

### 6.1 四项产品化设计原则（§1.3）

1. **产品化、工具化**：系统是可复用的产品，非项目型定制化系统；提供充分的配置组态能力，用户自助完成配置。
2. **模块内聚、自包含**：每个功能模块自包含其"配置 → 运行 → 分析"三态功能，减少模块间交叉。
3. **配置驱动**：指标公式、诊断算法、引擎规则等均支持用户自助配置，无需开发介入。
4. **实体内聚**：回路作为核心实体，其配置态（台账/映射）和运行态（监控）归属同一模块管理。

### 6.2 架构与数据层决策

| 决策 | 章节 | 当前口径 |
|---|---|---|
| AAS 数据模型 | §4 | AAS 同步 tag 位号（非回路实体）；回路由用户创建并关联 7 个 OPC tag（PV/SP/OP/MODE/PID_P/PID_I/PID_D）；PID 参数与控制模式从关联 tag 只读读取 |
| 数据编排层 DataPlanner | §4, §5.3.9 [v4.0] | 引入 tagGroup（5 个分组）合并查询计划，DataBlock 缓存降低 TDengine 压力 |
| 质量码处理策略 | §4, §5.3.1.2 [v4.0] | KEEP_ALL_WITH_VALIDITY——不删除任何数据点，为每个时间戳每个 Tag 打 valid 标记，由 Metric Validity Mask 决定各指标有效点 |
| 指标体系 | §5.3.1.1 [v5.0] | 3+1+8 结构（3 核心 A/F/S + 1 投用 R + 8 辅助诊断），共 12 项指标 |
| 综合评分公式 | §5.3.7.1 [v5.0] | `P_loop = (A·a + F·f + S·s)/(a+f+s) × (R/100)`，按控制类型分 4 类权重 |
| 装置级三大 KPI | §5.3.7.3 [v5.0] | 综合性能 / 平均自控率 / 稳定率，外加实时自控率 |
| 两类评分体系 | §5.3.7 [v5.0] | ① 回路级性能评分（控制类型权重）；② 综合性能评分（重要等级权重）|
| INCONCLUSIVE 处理 | §5.3.7.1, §5.3.10 [v4.0] | 基于指标可信度 E 级（valid_rate < 0.20），整条快照标记 INCONCLUSIVE，score 置 NULL |
| 指标可信度 | §5.3.10 [v4.0] | A/B/C/D/E 五级，基于 valid_rate 分级 |
| Action Tracker | §5.4 | v3.0 中降级为诊断中心子模块，状态机 PENDING→IN_PROGRESS→IMPLEMENTED/IGNORED，不走审批流 |
| 统计分析 | §2.1 | 不设独立模块，分散到各业务模块的"分析"态；自动报表归入系统管理 |
| 回路整定 | §5.5 | Phase 1 保留页面与原型先行设计，Phase 2 实现算法；只输出建议/证据/风险/回退方案，不下写 DCS |
| 表达式引擎 | §5.3.8 [v5.0 修订] | simpleeval 安全沙箱；**v5.0 起仅用于诊断规则配置，不再用于性能指标计算**（12 项指标算法已固化为独立函数模块）|
| 算法版本管理 | §8 | 所有算法实行版本管理，每条计算结果关联算法版本号，格式 `<algorithm_name>v<major>.<minor>` |
| 安全边界 | §5.6.3, §6 | 平台不直接修改 DCS 的 P/I/D 参数；前后端彻底剔除任何针对 DCS OPC 节点的 Write/Set 接口调用；数据流为纯单向只读 |
| 算法依据 | 全文 | 对齐 GB/T 44693.2-2024 附录 B/C/D/E/F 与《关键算法设计说明 v2.0》|

## 7. KPI 指标相关

### 7.1 3+1+8 指标体系（§5.3.1.1，[v5.0 修订]）

CLPM 性能指标体系由"3 核心 + 1 投用 + 8 辅助诊断"三层结构构成，共 **12 项指标**，依据 GB/T 44693.2-2024 附录 B/C/D/F。

**指标编号 ①~⑫ 全局唯一，后续章节均以编号引用。**

| 编号 | 层级 | 指标代码 | 中文名称 | 是否参与评分 | Metric Validity Mask | 单位 |
|:---:|---|---|---|:---:|---|---|
| ② | 1 投用指标 | `effective_auto_rate` (R) | 有效自控率 | ✅ 折扣因子 | `mode_valid && op_valid` | % |
| ③ | 3 核心质量指标 | `accuracy_rate` (A) | 准确率 | ✅ 加权评分 | `pv_valid && sp_valid` | % |
| ④ | | `fast_rate` (F) | 快速率 | ✅ 加权评分 | `pv_valid && sp_valid` | % |
| ⑤ | | `steady_rate` (S) | 稳定率 | ✅ 加权评分 | `pv_valid && sp_valid` | % |
| ① | 8 辅助诊断指标 | `auto_mode_rate` | 自控率 | ❌ | `mode_valid` | % |
| ⑥ | | `oscillation_rate` | 振荡率 | ❌ | `pv_valid` | % |
| ⑦ | | `saturation_rate` | 饱和率 | ❌ | `op_valid && mode_valid` | % |
| ⑧ | | `good_value_rate` | 好值率 | ❌ 影响可信度 | 不删除行，统计质量码占比 | % |
| ⑨ | | `stiction_index` | 粘滞系数 | ❌ | `pv_valid && op_valid` | % |
| ⑩ | | `output_trip_index` | 输出行程指数 | ❌ | `op_valid && consecutive_valid` | %/h |
| ⑪ | | `settling_time` | 实际稳态时间 | ❌ | `pv_valid && sp_valid` | s |
| ⑫ | | `ideal_settling_time` | 理想稳态时间 | ❌ | 回路组态参数 | s |

### 7.2 指标依赖关系（分层计算）

- **第 0 层（回路组态参数，非计算）**：⑫ 理想稳态时间
- **第 1 层（基础指标）**：① 自控率、② 有效自控率、③ 准确率、⑥ 振荡率、⑦ 饱和率、⑧ 好值率、⑨ 粘滞系数、⑩ 输出行程指数、⑪ 实际稳态时间
- **第 2 层（依赖指标）**：④ 快速率（依赖 ⑪+⑫）、⑤ 稳定率（依赖 ⑥）

### 7.3 装置级三大 KPI（§5.3.7.3，[v5.0 新增]）

| KPI 名称 | 计算公式 | 落库位置 |
|---|---|---|
| ① 综合性能 Composite Performance | `P_composite = Σ(w_levelᵢ × P_loopᵢ) / Σ w_levelᵢ` | `unit_kpi_summary.avg_score` |
| ② 平均自控率 Average Auto Rate | `Auto_avg = Σ(w_levelᵢ × auto_mode_rateᵢ) / Σ w_levelᵢ` | `unit_kpi_summary.auto_mode_rate` |
| ③ 稳定率 Stability Rate | `Stab_unit = Σ(w_levelᵢ × steady_rateᵢ) / Σ w_levelᵢ` | `unit_kpi_summary.stability_rate` |
| （辅助）实时自控率 Real-time Auto Rate | `Auto_rt = auto_loops_rt / evaluated_loops × 100` | Redis 实时键 `plant:{plant_id}:auto_rate_rt` |

### 7.4 工作台 KPI 卡片（6 项运营 KPI，非评分体系）

工作台 KPI 卡片区展示 6 项运营 KPI 摘要（注：此为看板展示卡片，**非 §5.3.1 的 3+1+8 评分指标体系**）：
- 自控率、稳定率、综合评分、报警次数、操作频次、好值率

### 7.5 性能定级（5 级，§5.3.7.1，[v5.0 新增]）

| 性能评分 P | 国标定级 | 英文标识 | 颜色 |
|---|---|---|---|
| 90 ≤ P < 100 | 一级 | EXCELLENT | 绿色 |
| 80 ≤ P < 90 | 二级 | GOOD | 蓝色 |
| 70 ≤ P < 80 | 三级 | FAIR | 黄色 |
| 60 ≤ P < 70 | 四级 | WARNING | 橙色 |
| 0 ≤ P < 60 | 五级 | POOR | 红色 |

### 7.6 回路级评分权重模板（4 类控制类型，国标默认值）

| 控制类型 | a (准确率 ③) | f (快速率 ④) | s (稳定率 ⑤) | 适用场景 |
|---|:---:|:---:|:---:|---|
| STABLE（稳定型）| 0.2 | 0.3 | 0.5 | 温度控制、压力控制 |
| SLOW（慢速型）| 0.3 | 0.1 | 0.6 | 缓慢调节的工艺参数 |
| FAST（快速型）| 0.2 | 0.5 | 0.3 | 副回路、速度控制 |
| LOGIC（逻辑型）| 0.0 | 0.4 | 0.6 | 安全动作、联锁保护 |

### 7.7 指标可信度 A/B/C/D/E 五级（§5.3.10，[v4.0 新增]）

| 等级 | valid_rate 范围 | 含义 | 系统表现 |
|:---:|:---:|---|---|
| A | ≥ 0.95 | 高可信 | 正常参与评分与聚合 |
| B | 0.80 ~ 0.95 | 较高可信 | 正常参与评分与聚合 |
| C | 0.60 ~ 0.80 | 中等可信 | 正常参与评分，看板标注"可信度 C" |
| D | 0.20 ~ 0.60 | 低可信 | 评分仅供参考，看板标注"可信度 D，谨慎使用" |
| E | < 0.20 | 不可信 | 标记 INCONCLUSIVE，综合评分置 NULL，不参与装置级聚合 |
