## 一、结论先行

**这批脚本不阻塞生产删表**：它们都不在运行时链路（后端 API / Celery 任务 / 订阅器）上，删表不影响线上功能。

⚠️ **但有两个脚本会在运行后"重建宽表"**，属于"删了又回来"的风险点，建议优先处置：

- `import_kpi_test_data.py:149` `CREATE STABLE IF NOT EXISTS st_loop_data`
- `data_simulator.py:859` `CREATE STABLE IF NOT EXISTS st_loop_data`
