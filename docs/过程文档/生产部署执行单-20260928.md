### 步骤 E：AAS 网关加 `/clpm/`（在**宿主机**上）

1. 打开 `D:\AAS\nginx-1.24.0\conf\nginx.conf`，按交付物 #4 的片段添加；**要点两条**：
   - `proxy_pass` 必须写 **`http://192.168.60.132:7141/`**（写 `127.0.0.1:7141` 会打到宿主机自己 → 502）；
   - 若该 conf 里**已有** `map $http_upgrade $connection_upgrade {...}`，**删除片段中的 map 块、复用原有的**（重复定义会让 `nginx -t` 失败）；
   - 片段里 `location /clpm/` **必须在** `location /`（AAS 的）之前或不受其影响（nginx 前缀匹配取最长，通常无需调整）。
2. 语法检查 + 平滑重载：
   ```
   cd /d D:\AAS\nginx-1.24.0 && nginx.exe -t
   ```
   ```
   nginx.exe -s reload
   ```
3. 验收（在任意能访问宿主机的机器上）：
   ```
   curl.exe -sI http://<宿主机IP>:82/clpm/
   ```
   ```
   curl.exe -s -X POST http://<宿主机IP>:82/clpm/api/v1/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
   ```

   期望：第一条 200；第二条返回 `code:"0"` 与 token。浏览器打开 `http://<宿主机IP>:82/clpm/` → 登录 → 工作台正常，**零 404**（F12 Network 看有无红色请求）。
