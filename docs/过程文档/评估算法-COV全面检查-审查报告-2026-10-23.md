### 2.4 综合评分与可信度

- P=(A·a+F·f+S·s)/(a+f+s)×R：R 缺失/E → INCONCLUSIVE；权重>0 核心指标缺失/E
  → INCONCLUSIVE（不隐性扣分）；零总权重 → INCONCLUSIVE；合法 0 与 NULL 区分清晰；
  NaN 经 G20 收口 INCONCLUSIVE。**无问题**。
- 可信度 = 回路级（pv∧op ZOH 有效率×时间覆盖率），阈值 pub/sub 同步；组级失真
  两处（QUALITY_HF/ideal_settling）即 R6/R7 已修。

### 2.5 正式入口与持久化

- 定时/手动/custom/backfill 四入口收敛同一
  `_calculate_loop_kpi → DataPlanner → TDengineProvider(本地) → Pipeline`；
  无入口绕过 ZOH；backfill 显式 `bundle_cache=False` 不吃缓存。**无问题**。
- L1/L2 键含 `dataVersion={layout}:{tqpv}:{pre}`（1054=tqpv5:pre_v5），旧缓存
  不混算；空块不写 L1（负缓存防护）。快照 UPSERT 幂等；status 三态映射正确
  （score=NULL→INCONCLUSIVE 三处：composite E / gate / 观测覆盖闸门）。
- 无计算路径静默截断（read_events 游标翻页 G12）或静默降级（查询异常上抛
  F02 收束）；LTTB 仅展示路径。

## 三、已确认缺陷与修复（先复现后修复）

### R1（P0）七角色质量码在取数链丢失

- 复现：builder `raw.quality_codes` 仅 `pv_quality`（tests 3 项失败实证）；PV
  Good+其余角色全 Bad → 7 角色 validity 全真、回路有效率 1、conf=A（坏质量被
  洗白）。
- 修复：`logical_wide_builder.py` 逐角色收集 `role_quality`（与值同状态保持，
  未知槽 -1），输出 `{role}_quality`（伪角色 pv_quality 走 setdefault 不变）；
  `tdengine_provider.py` 合并层整体透传（长度异常列补 -1 不丢角色）。下游
  `_step1_identify_quality` 泛型消费，OP Bad → op_valid=False → GATE 交集正确
  扣分；SP/MODE/PID 不进门禁（维持 2026-10-22 裁决，未引入全角色硬门禁）。
- 回归：`test_builder_emits_quality_codes_for_all_requested_roles` 等 4 项。

### R2（P0）锚点 coverage_until 被丢弃

- 复现：anchor -10s/coverage_until=+3s、无事件、查询 0..9s → 10 槽全 known
  （应为 3）；到期后回退更旧事件同样越界。
- 修复：`_PointStream.state_at` 支持状态级 `valid_until`（半开）：到期→None
  （UNKNOWN，归因 no_initial，与 builder 既有注释口径一致），不回退更旧状态；
  锚点后新事件正常恢复。
- 回归：4 项（到期截断/无限保持不变/事件恢复/不回退旧事件）。

### R3（P1）缓存版本未随语义演进

- pre_v3→（1053）pre_v4→（1054）**pre_v5**；tqpv4→**tqpv5**。R1 改 validity、
  R2 改覆盖游程，1053 部署期的 L1/L2 缓存全部自然失效，不混算。
- 回归：`test_cov_policy_does_not_reuse_pre1053_l1_or_l2_cache` 断言更新为
  `point-test:tqpv5:pre_v5` ≠ `point-test:tqpv4:pre_v4`。

### R4（P1）accuracy/stability 把 UNKNOWN 槽当观测（交接 §4C 实锤部分）

- 复现：sp 侧 gap 槽（保持陈值大偏差）计入准确率均值→分数大幅失真；pv 侧
  gap 陈值计入 σ→假波动拉低稳定率（tests 断言修复前 100 分/σ=0 不可得）。
- 修复：`MetricCalculatorBase._known_slot_indices`（视图可用时取
  `masked ∩ 已知(OBSERVED∪HELD)`；legacy 无视图返回 None 行为零回归）；
  accuracy 与 stability（含 durations 对齐）接入。正常 COV 保持（HELD）不剔，
  与 R/Auto/Sat"未知不进分子不缩分母"口径对齐。
- 明确不动（交接 §4C 纪律）：未做全局 mask 改造；统计类/动态类 legacy 行为
  见 §五 L1/L2。

### R5（P1）good_value_rate/usable_rate 在 gap 期间虚高

- 修复：`compute_quality_summary` 新增 `known_slots` 掩码——好值率/可用率只在
  PV 覆盖已知槽上算（分子分母同口径）；全窗未知 → None=不可判定（不冒充
  0/100）。pipeline 从 series_context 逐槽计算掩码传入；legacy 全槽口径不变。

### R6（P0，交接 §4D）QUALITY_HF 伪角色块 conf 恒 E

- 复现链：伪角色块无 pv_valid/op_valid → GATE 交集空 → loop_valid_rate=0 →
  conf 恒 E，而 good_value_rate 有值（值对等级错，metricsSemantic 自相矛盾）。
  独立复核确认该 E 不阻断 composite（仅查 R/A/F/S），与交接结论一致。
- 修复：pipeline 置信度回退——pv_valid 缺失且存在 pv_quality 质量码时，以
  质量码（Good=有效）为该块数据依据，再经 `_zoh_validity` 覆盖合并。全 Good
  全覆盖 → A；半 Bad → 0.5→D；无质量码/无覆盖 → 维持 E（不编造）。

### R7（P2）ideal_settling_time conf 恒 E

- 虚拟 CONFIG DataBlock 落默认 "E"。修复：CONFIG 值为确定性配置来源，显式
  `loop_confidence_level="A"/loop_valid_rate=1.0`（fast_rate 只消费 value，
  composite 不受影响）。

### R8（P2）backfill 窗口失败计数虚高

- `_backfill_window_batch` 窗口异常分支 `agg["failed"] += len(loops)`：skip_existing
  模式下已跳过回路被虚报失败。修复为 `len(todo_loops)`。

受保护文件改动（golden manifest 已随授权更新，仅 R3 版本行 + R4 两计算器）：
`pipeline.py`、`time_axis.py`（版本常量）、`accuracy.py`、`stability.py`、
`base.py`、`quality_summary.py`。授权链：用户 2026-10-23 原话"再帮我做一次
评估算法的全面检查，没有问题，我们就提交、推送，锁定一个部署版本" +
交接文档 §1/§6。
