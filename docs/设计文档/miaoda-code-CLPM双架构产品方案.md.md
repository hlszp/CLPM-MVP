# CLPM 双架构产品终版方案

> 包含：新版页面架构 + 前后台功能边界SOP + 双范式UI交互规范

---

## 文档总述

适配产品最新顶层战略：

**前台 = 智能驾驶舱（全员日常监控、预警、轻分析、结果消费）**

**后台 = 专家工作站（工程师深度分析、整定、建模、配置、系统管理）**

核心设计哲学：

**95%高频日常操作极简前台承载，5%低频高危高阶能力严格收拢后台**

**普通用户只看结果、专家用户可做深度改造，权限隔离、场景隔离、风险隔离、AI分层**

---

# 第一部分：新版完整页面信息架构（最终落地版）

## 1. 系统全局总规则

### 1.1 双模式全局切换（系统唯一顶层入口）

系统统一单登录、单账号、双视图：

- 顶部全局固定 Tab：【智能驾驶舱｜专家工作站】
- 权限自动锁死：
  - 操作工/班组长：仅可见「智能驾驶舱」，隐藏后台入口
  - 工艺/仪表工程师：双模式自由切换
  - 管理员：默认进入专家工作站，可切前台

### 1.2 全局统一公共能力（前后台通用）

- 全局AI助手（自动适配前后台话术与能力）
- 全局搜索（位号/装置/工段检索）
- 全局消息告警通知
- 个人中心、主题切换、深浅色、大屏模式

### 1.3 核心分层逻辑

- 前台：**结果驱动、问题优先、只读为主、极简交互**
- 后台：**过程驱动、能力优先、可编辑可配置、专业交互**

---

## 2. 模式一：智能驾驶舱（前台·全员日常工作区）

### 定位

面向：操作工、装置主管、班组长、初级工程师

能力：**监控、预警、洞察、轻分析、查报告、看趋势、看结论**

禁止：任何参数修改、算法配置、PID整定、模型调整

### 页面树结构

```
1.装置总览驾驶舱（默认首页）
  1.1 全厂回路健康度总览
  1.2 AI全局智能洞察（风险/劣化/优化）
  1.3 装置健康分布热力图
  1.4 今日异常事件汇总
  1.5 全厂性能趋势大盘

2.回路监控工作台
  2.1 回路健康列表（风险优先级自动置顶）
  2.2 单回路轻量详情（趋势+指标+AI一句话结论）
  2.3 回路简易对比（2-4条快速对比）

3.异常预警中心
  3.1 未处理告警聚合列表
  3.2 已归档异常事件追溯
  3.3 今日/本周风险统计

4.AI智能洞察中心
  4.1 AI风险预警清单
  4.2 AI设备劣化预告警（阀门磨损、性能衰减）
  4.3 AI节能优化机会清单

5.报告中心（轻量化）
  5.1 系统自动日报/周报
  5.2 异常事件简报
  5.3 报告预览&下载（不可编辑模板）

6.个人待办工作台
  6.1 待处理风险回路
  6.2 待关注劣化设备
  6.3 历史处理记录
```

### 前台核心跳转逻辑

1. 大盘风险卡片 → 直达对应异常回路详情
2. AI洞察卡片 → 直达异常区间+AI结论
3. 告警条目 → 直达回路轻量诊断页
4. 所有页面**无任何配置入口、无整定入口、无算法参数入口**

2.PID AI整定仿真平台

  4.3 AI模型置信度校准

5.告警高级配置中心
  5.1 告警级别自定义
  5.2 告警聚合策略配置
  5.3 静默策略、时段策略配置

6.数据采集管理
  6.1 数据源接入配置
  6.2 采集频率配置
  6.3 数据质量监控

7.高级报告定制中心

  7.2 自定义统计维度配置
  7.3 定时报告任务配置

8.系统权限与运维
  8.1 用户角色权限管理
  8.2 全量操作日志
  8.3 系统参数配置

# 第二部分：前后台功能边界SOP落地规范（开发强制执行）

## 1. 绝对边界总原则（铁律）

### 1.1 前台【只可读、不可改、不可配、不可整定】

允许操作：

- 查看所有指标、趋势、结论
- 简单圈选分析、工况查看
- 导出报告、查看历史
- 自然语言简单查询

禁止操作：

- ❌ 修改任何系统参数
- ❌ 修改算法阈值
- ❌ 调整PID参数
- ❌ 编辑回路台账
- ❌ 配置告警规则
- ❌ 模型调整与重训

### 1.2 后台【所有配置、整定、建模、深度分析唯一入口】

所有**变更类、生产类、建模类、配置类**能力**仅后台可见、仅后台可用**

---

## 2. AI能力分层SOP（核心差异化）

### 前台AI：应用型AI（服务日常运维）

输出形态：**结论化、总结化、口语化、低专业门槛**

能力清单：

- 全厂风险自动汇总
- 回路一句话异常结论
- 设备劣化提前预警
- 简单自然语言问答
- 自动生成简报

话术特征：

- 给出问题、给出现象、给出简易建议
- 隐藏复杂指标、隐藏推理过程

### 后台AI：专家型AI（服务优化改造）

输出形态：**推理化、数据化、可溯源、可干预、可仿真**

能力清单：

- 完整根因推理链路
- 异常类型精准分类
- 上下游因果传播分析
- 历史相似工况深度匹配
- 回路模型辨识 + PID智能整定仿真
- 指标异常热力归因

话术特征：

- 展示依据、展示指标、展示推理权重
- 提供可落地工程方案、多方案对比

- 整定前后仿真曲线对比
- 批量时段对比分析

## 4. 报告能力边界

### 前台

- 只读成品报告
- 下载、预览
- 系统自动生成的标准化简报

### 后台

- 自定义模板
- 自定义章节、自定义指标
- 定时任务配置
- 报告内容人工深度编辑

## 5. 告警能力边界

### 前台

- 告警结果聚合
- 已处理/未处理状态展示
- 关联回路快速跳转

# 第三部分：新版双范式UI&交互规范（前台/后台独立交互体系）

## 1. 双范式顶层设计差异

| 维度 | 前台-智能驾驶舱范式 | 后台-专家工作站范式 |
|------|---------------------|---------------------|
| 设计目标 | **降门槛、提效率、看结果** | **强专业、高精度、可操作** |
| 信息密度 | 低、留白多、卡片化、结果优先 | 高、结构化、数据密集、过程优先 |
| 操作风格 | 轻交互、少点击、自动推送 | 深度交互、可配置、可微调、可仿真 |
| 文案风格 | 通俗、结论化、建议化 | 专业、精准、量化、溯源化 |
| AI形态 | 智能助手、总结推送 | 专家工具、推理引擎、仿真引擎 |
| 权限形态 | 全只读、零风险 | 可编辑、可配置、可下发、留痕审计 |
| 用户心智 | 我要知道：哪里坏了、有多严重、要不要处理 | 我要知道：为什么坏、怎么修、怎么优化、怎么根治 |

---

## 2. 前台UI&交互详细规范

### 2.1 整体风格

- 工业极简驾驶舱风
- 大卡片、大指标、强视觉层级
- 问题高亮、正常弱化
- 适合中控室长期值守、远距离观看

### 2.2 组件规范

1. **核心指标大字化**：健康度、异常数量、风险等级放大突出
2. **AI洞察卡片化**：每条风险独立卡片，结论前置
3. **列表自动优先级排序**：严重异常置顶，无需人工筛选
4. **弱化复杂专业指标**：前台隐藏滞后时间、增益、死区等专业参数
5. **极简曲线交互**：仅保留查看、放大、简易AI识别

### 2.3 前台AI交互规范

1. 禁止展示：算法参数、置信度细节、推理权重
2. 固定输出：**一句话问题 + 影响说明 + 简易处理建议**
3. 对话仅支持：日常查询、问题咨询、结果解读
4. 无任何模型调优、参数微调入口

### 2.4 动效规范

- 极度克制
- 仅用于风险提示、新洞察推送
- 无花哨动效，保障工业值守稳定性

---

## 3. 后台UI&交互详细规范

### 3.1 整体风格

- 专业工程师工作站风格
- 高密度结构化布局
- 多面板、多数据、多参数并列展示
- 强调可对比、可追溯、可操作

### 3.2 组件规范

1. **全量指标展示**：所有专业性能参数全开
2. **推理树可视化**：AI根因推理链路图形化展示
3. **多视图并列**：原始曲线+指标统计+模型曲线+案例对比同屏
4. **精细化操作控件**：滑块、参数输入、阈值微调、仿真按钮

### 3.3 后台AI交互规范

1. 所有结论**强制带溯源依据**
2. 展示置信度、匹配维度、推理权重
3. 支持多轮深度专业追问
4. 支持模型重分析、重新拟合、重新检索
5. 支持整定方案手动微调+实时仿真刷新

### 3.4 操作安全规范（工业红线）

1. 所有修改类操作**二次确认**
2. 所有参数变更**自动日志留痕**
3. 高危操作（PID下发）**权限校验+审批**
4. 所有配置可**回滚、可对比、可历史追溯**

---

## 4. 全局统一规范（前后台通用）

1. 工业三色语义不变：绿正常、黄预警、红异常
2. PV/SP/MV曲线全局固定配色
3. 深色模式为主（适配中控夜班）
4. 所有AI内容标注「AI分析建议，仅供人工核验」
5. 断网降级策略：前台监控完全可用，后台AI功能自动禁用

---

## 5. 双架构体验统一原则

1. 账号、权限、用户配置全局同步
2. 主题、字体、布局偏好前后台统一
3. 同一条回路，前后台数据完全同源，不出现数据差异
4. 从前台回路详情可**一键跳转后台专家分析模式**（无缝衔接）

---

# 终版架构核心商业总结（可直接用于售前PPT）

1. **行业唯一双范式CLPM**：区分普通人运维场景 & 专家优化场景
2. **零操作风险**：普通用户完全隔离配置与整定权限
3. **AI分层差异化**：普通人用AI结果、专家用AI能力
4. **极致易用 + 极致专业兼得**
5. 解决传统CLPM：界面杂乱、新手难用、专家不深、操作风险高四大行业痛点
