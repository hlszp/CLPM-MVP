## 1. 页面定位与核心价值

### 1.1 定位

## 3. 第一性原理评估（视角一）

### 3.1 用户核心需求

| 问题 | 回答方式 | 当前实现 |
|---|---|---|
| 如何手动重算某回路？ | 手动任务 Tab → recompute.vue | ✅ |
| 自动评估计划怎么配？ | 自动任务 Tab → task/list.vue | ✅ |
| 历史快照怎么查？ | 评估历史 Tab → history-snapshots.vue | ✅ |
| 评估参数/权重怎么配？ | 策略配置 Tab → task-strategy.vue | ✅ |

### 3.2 范式级评估

**优点**：
- 4 Tab 覆盖评估任务全生命周期（手动/自动/历史/策略），职责清晰
- 子组件异步加载（defineAsyncComponent），避免首屏加载全部
- tabKeys 自增强制重载，切换 Tab 时子组件重新拉取数据
- 权限收紧合理（仅 ADMIN/IC，PE/SPONSOR/EXPERT 不可见）

**不足**：
- **无 URL 深链**：与诊断任务页不同，评估任务页无 `?tab=` URL query 同步，不支持深链和浏览器前进后退
- **工具栏仅刷新+帮助**：无创建任务快捷入口（需进入手动任务 Tab 操作）
- **策略配置 Tab 定位模糊**：策略配置（评估参数与权重策略）与配置模块的指标配置（`/config/metric`）有功能交叉

### 3.3 范式级发现

| 编号 | 发现 | 级别 | 理由 |
|---|---|---|---|
| F-ET-001 | **无 URL 深链** | P2 | [tasks.vue:L13-L23](file:///Users/zhangping/DEV/CLPM/frontend/apps/web-antd/src/views/metric/tasks.vue#L13-L23) 无 `?tab=` query 同步。诊断任务页有深链，评估任务页没有，一致性不足 |
| F-ET-002 | **策略配置与配置模块功能交叉** | P3 | 策略配置 Tab（评估参数与权重策略）vs `/config/metric`（指标配置）。需明确边界 |
| F-ET-003 | **工具栏无创建任务快捷入口** | P3 | 工具栏仅刷新+帮助，创建手动任务需进入手动 Tab |

## 10. 结论

**核心建议**：
1. **短期**：增加 URL 深链（0.5 天）+ 策略配置边界明确（评估）
2. **中期**：随双架构路径 B，评估任务作为工作站模式任务管理页面
3. 评估任务页是**工作站模式的任务管理页面**——4 Tab 全生命周期管理天然适合工作站场景
