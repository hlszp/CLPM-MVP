## 1. 页面定位与核心价值

### 1.1 定位

测点配置页是配置模块的**实体管理层核心**——管理 CLPM 系统中所有测点（Tag）的定义、属性和实时数据。以工厂树→表格的主从布局，支持测点 CRUD、批量操作、实时值更新、质量戳展示。

### 1.2 核心价值

| 价值 | 实现 | 评估 |
|---|---|---|
| 测点实体管理 | 工厂树→测点的主从布局 + CRUD | ✅ |
| 实时数据活度 | WebSocket 实时更新测点值和质量戳 | ✅ |
| 数据健康状态 | ClpmDataHealthBadges 展示数据健康状态 | ✅ |
| 批量配置效率 | 批量删除 + 智能统计可删除数 | ✅ |
| 多维度筛选 | 装置/测点类型/参数类型/关联状态/关键词 | ✅ |
| 安全删除 | 已关联测点不允许删除 + 二次确认 | ✅ |

## 3. 第一性原理评估（视角一）

### 3.1 用户核心需求

| 问题 | 回答方式 | 当前实现 |
|---|---|---|
| 有哪些测点？ | 工厂树→测点表格（主从布局） | ✅ |
| 测点实时值是什么？ | WebSocket 实时更新 + ClpmNumeric 组件 | ✅ |
| 数据质量怎么样？ | 质量戳 GOOD 绿/BAD 红/UNCERTAIN 黄 | ✅ |
| 测点关联了吗？ | 关联状态筛选 + 已关联测点不允许删除 | ✅ |
| 批量操作怎么弄？ | 行选择 + 批量删除（智能统计） | ✅ |
| 测点详情？ | Drawer 内联查看，不离开列表 | ✅ |

### 3.2 范式级评估

**优点**：
- 工厂树→表格的主从布局符合工业场景习惯
- 质量戳 GOOD 绿/BAD 红/UNCERTAIN 黄，符合工业场景直觉
- WebSocket 实时更新测点值和质量戳，反映系统活度
- 智能批量删除：`selectedDeletableCount` 实时计算可删除数量
- ClpmDataHealthBadges 展示数据健康状态徽章
- ClpmNumeric 组件右对齐数字，专业规范
- 表格密度三档切换

**不足**：
- WebSocket 断线处理：代码中引用 `realtimeWs` 但未看到断线重连逻辑
- 批量删除关联保护：批量操作时缺少"已选中 X 个，其中 Y 个不可删除"的醒目提示
- 质量戳颜色与 ClpmConfidenceBadge 可信度颜色可能混淆
- 导出格式仅 Excel，缺少 CSV 选项

### 3.3 范式级发现

| 编号 | 发现 | 级别 | 理由 |
|---|---|---|---|
| F-TAG-001 | **WebSocket 断线无重连逻辑** | P2 | 实时数据是测点配置的核心价值，断线后无提示和重连 |
| F-TAG-002 | **批量删除关联保护提示不足** | P2 | 缺少醒目的不可删除数量提示 |
| F-TAG-003 | **质量戳颜色可能混淆** | P3 | GOOD 绿/BAD 红/UNCERTAIN 黄与可信度颜色可能混淆 |

## 10. 结论

测点配置页是 CLPM **实体管理层的核心页面**（3.46/4.0），工厂树→表格的主从布局、质量戳语义化、WebSocket 实时更新、ClpmDataHealthBadges 健康徽章等实现质量良好。

**核心问题**是 WebSocket 断线处理（F-TAG-001）和批量删除关联保护提示不足（F-TAG-002）。实时数据是测点配置的核心价值，断线处理需要完善。

**核心建议**：
1. **短期**：WebSocket 断线重连（1 天）+ 批量删除关联提示优化（0.5 天）
2. **中期**：质量戳图例说明 + CSV 导出
3. 测点配置页是**双架构的重要页面**——驾驶舱看异常测点和实时数据，工作站做全量管理和批量操作
