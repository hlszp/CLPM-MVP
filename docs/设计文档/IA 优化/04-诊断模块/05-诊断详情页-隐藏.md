## 1. 页面定位与核心价值

### 1.1 定位

诊断详情页是诊断中心的**单回路深度诊断页面**——展示诊断结论、证据链、处置时间线与状态操作。经过 Phase C 三区重构（结论先行 + 问题定位路径 + 证据折叠），该页是诊断证据可解释性的核心载体。隐藏路由，从总览 Top5、诊断任务行"详情"、异常跟踪行"详情"或回路工作台诊断区进入。

## 3. 第一性原理评估（视角一）

### 3.1 用户核心需求

工程师查看诊断详情时，认知路径是**"什么问题 → 为什么 → 怎么处理 → 处置记录"**。详情页应回答：

| 问题 | 回答方式 | 当前实现 |
|---|---|---|
| 什么问题？ | 顶部标签+置信度+风险等级 + 结构化报告结论 | ✅ |
| 有多严重？ | 综合评分 + 风险等级（HIGH/MEDIUM/LOW） | ✅ |
| 为什么？ | 问题定位路径（标签→现象→特征→原因） | ✅ Phase C |
| 证据在哪？ | 波形图 + PV-OP 散点 + 特征值表 | ✅ |
| 建议什么？ | 推荐动作（Recommendations 组件） | ✅ |
| 处置了什么？ | Tab2 时间线 + 审计字段 | ✅ |
| 当前状态？ | 顶部状态 Tag + 6 态状态机 | ✅ |
| AI 怎么看？ | ClpmAiDrawer diagnosis 场景 | ✅ |

### 3.2 范式级评估

**优点**：
- **结论先行**：顶部 SummaryBar 聚合标签+置信度+风险+状态+时间窗，3 秒掌握结论
- **问题定位路径**：标签→现象描述→特征值→原因分析→推荐动作，形成可解释的证据链
- **特征字典**：feature-dictionary.json 为特征值提供工程含义列，非专业用户也能理解
- **多图联动**：D2 趋势图↔散点图联动，点击趋势图点位散点图高亮对应
- **三区折叠**：证据区特征值表默认折叠（技术细节），波形/散点默认展开（保证 ECharts 首屏渲染）

**不足**：
- **Tab3/Tab4 预留未实现**：注释标注 Tab3"整定对比"和 Tab4"A/B验证"为预留，但 Tab 标题可见，用户点击发现空内容会困惑
- **状态操作在 Tab2 内**：用户在 Tab1 看完结论后需切到 Tab2 才能操作状态，增加一次点击

## 10. 结论

诊断详情页是**诊断模块实现质量最高的页面**（3.17/4.0），Phase C 三区重构（结论先行+问题定位路径+证据折叠）+ 特征字典 + 多图联动 + AI 洞察 + 阈值微调 + PDF 导出，**证据可解释性达到优秀水平**。

**核心问题**是 Tab3/Tab4 预留未实现（F-DD-001），用户点击发现空内容会困惑。建议隐藏或标注"敬请期待"。

**核心建议**：
1. **短期**：Tab3/Tab4 预留处理（0.5 天）+ 顶部快捷状态操作（1 天）
2. **中期**：随双架构路径 B，详情页作为工作站模式核心页面，驾驶舱模式提供 AI 结论摘要版
3. 诊断详情页是**工作站模式的诊断核心**——三区重构+特征字典天然适合工作站深度分析场景
