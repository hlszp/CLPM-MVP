## 1. 页面定位与核心价值

### 1.1 定位

异常跟踪页是诊断中心的**Action Tracker 闭环管理页面**——管理诊断异常的处置全生命周期（PENDING → IN_PROGRESS → VERIFYING → CLOSED / REOPENED / IGNORED），提供状态机可视化、KpiStrip 聚合、A/B 对比抽屉、PDF 导出、CSV 导出等功能。支持抽屉模式（从诊断列表/详情页打开）和独立页模式统一使用 CLPM 组件。

### 1.2 核心价值

| 价值 | 实现 | 评估 |

| 状态机闭环 | 6 态状态机 + 状态更新 Modal + 审计字段 | ✅ P1a |

| A/B 对比验证 | 抽屉展示处置前后 KPI 对比 | ✅ Batch 4 |

| 严重度徽章 | ClpmSeverityBadge | ✅ |
| 列偏好持久化 | usePagePreference + ClpmColumnSettings | ✅ |

## 3. 第一性原理评估（视角一）

### 3.1 用户核心需求

工程师管理异常处置时，认知路径是**"待处理 → 处理中 → 验证 → 闭环"**。异常跟踪页应回答：

| 问题 | 回答方式 | 当前实现 |
|---|---|---|
| 有多少待处理？ | KpiStrip "待处理" 卡片 | ✅ |
| 有多少处理中？ | KpiStrip "处理中" 卡片 | ✅ |
| 有多少已闭环？ | KpiStrip "已实施" 卡片 | ✅ |
| 有多少验证超期？ | 系统概览 KpiStrip "验证超期" | ✅ C1-3 |
| 每个异常什么状态？ | 表格状态列 Tag | ✅ |
| 严重程度如何？ | ClpmSeverityBadge | ✅ |
| 处置前后效果？ | A/B 对比抽屉 | ✅ |
| 处置记录在哪？ | 状态更新 Modal 审计字段 | ✅ |

### 3.2 范式级评估

**优点**：
- 6 态状态机闭环完整（PENDING→IN_PROGRESS→VERIFYING→CLOSED，VERIFYING→REOPENED，IMPLEMENTED 兼容映射 VERIFYING）
- 抽屉/独立页统一设计，从诊断列表/详情页打开抽屉或直接进独立页体验一致
- A/B 对比在抽屉内完成，不跳转页面，操作连续性好
- 状态更新 Modal 含"变更说明"审计字段，可追溯
- 验证超期（VERIFYING > 24h）接入系统概览 KpiStrip

**不足**：
- **与诊断任务状态边界不清**：诊断任务 PENDING=待执行诊断，异常跟踪 PENDING=待处置异常
- **与关注队列重叠**：关注队列 TRACKER 来源 = 异常跟踪待处理项，两个页面展示同一数据的不同视图
- **状态选项注释不完整**：tracker.vue 注释仅列 PENDING/IN_PROGRESS/IMPLEMENTED/IGNORED 4 态，实际代码支持 6 态（缺 VERIFYING/CLOSED/REOPENED 注释）

### 3.3 范式级发现

| 编号 | 发现 | 级别 | 理由 |
|---|---|---|---|
| F-TRK-001 | **与诊断任务状态边界不清** | P2 | 两子模块 PENDING 含义不同。KpiStrip 文案需区分 |
| F-TRK-002 | **与关注队列重叠** | P3 | 关注队列 TRACKER 来源 = 异常跟踪待处理项。需明确：关注队列=跨模块行动优先级，异常跟踪=诊断模块管理表格 |
| F-TRK-003 | **状态选项注释不完整** | P3 | [tracker.vue:L7-L8](file:///Users/zhangping/DEV/CLPM/frontend/apps/web-antd/src/views/diagnosis/tracker.vue#L7-L8) 注释仅 4 态，实际 6 态 |

## 10. 结论

异常跟踪页是**诊断模块闭环管理的核心页面**（3.12/4.0），6 态状态机 + KpiStrip 聚合 + A/B 对比抽屉 + PDF/CSV 导出 + 抽屉/独立页统一 + 列偏好持久化的功能完整，**闭环管理实现质量高**。

**核心问题**是与诊断任务的状态边界不清（F-TRK-001），两子模块 PENDING 含义不同。建议 KpiStrip 文案区分"诊断任务待执行" vs "异常待处置"。

**核心建议**：
1. **短期**：状态选项注释补齐（0.5 天）+ 关注队列与异常跟踪职责说明（1 天）
2. **中期**：随双架构路径 B，异常跟踪作为驾驶舱待办行动视图 + 工作站完整管理
3. 异常跟踪页是**驾驶舱模式的核心行动页面**——KpiStrip+待处理列表天然适合驾驶舱"先处理哪个"场景
