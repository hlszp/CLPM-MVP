| 项目 | 内容 |

## 1. 证据采集总则

### 1.1 三源证据 + 第一性原理

本评审要求每个发现必须有**四源证据**支撑（v2 新增第一性原理）：

| 证据源 | 形式 | 必要性 | 权威性 |
|---|---|---|---|
| 代码走查 | `file:line` | 必需（实现层） | 最高 |
| 设计文档对照 | `契约 §X` / `UI/UX §X` | 必需（契约层，作参考） | 高 |
| 角色场景走查 | `角色@步骤N` | 必需（行为层） | 中 |
| 第一性原理分析 | `本质问题:分析` | 范式级问题必需 | 高 |

### 1.2 证据记录格式

```
证据：
- 代码：frontend/apps/web-antd/src/views/loop/workbench.vue:L120-L145
- 契约：实现契约 §2.1 Phase B（单页四区布局）
- 场景：IC_ENGINEER@巡检步骤2（左侧列表选择回路）
- 原理：注意力机制-Glanceability（3 秒扫视要求首屏异常优先）
```

## 2. 代码走查 Checklist

### 2.1 路由走查（每模块必做）

**文件**：`frontend/apps/web-antd/src/router/routes/modules/*.ts`

| 检查项 | 检查方式 | 输出 |
|---|---|---|
| 路由路径 | 读取 `path` 字段 | 完整路径 |
| 组件路径 | 读取 `component` 字段 | .vue 文件路径 |
| 权限 | 读取 `meta.authority` | 角色列表 |
| 菜单可见性 | 读取 `meta.hideInMenu` | 可见/隐藏 |
| 菜单排序 | 读取 `meta.order` | 数字 |
| 图标 | 读取 `meta.icon` | 图标名 |
| 标题 | 读取 `meta.title` | 中文名 |
| 重定向 | 读取 `redirect` | 目标路径 |
| fullPathKey | 读取 `meta.fullPathKey` | true/false |
| 子路由 | 读取 `children` | 嵌套层级 |

### 2.2 页面走查（每页面必做）

**文件**：`frontend/apps/web-antd/src/views/**/*.vue`

| 检查项 | 检查方式 | 关注点 |
|---|---|---|
| 模板结构 | 读取 `<template>` | 区块划分、布局方式、组件嵌套 |
| 组件使用 | grep `<Clpm` / `<clpm` | 规范组件使用率 |
| API 调用 | 读取 `<script setup>` 中的 import + 调用 | API 端点、请求代次保护 |
| 路由 query | grep `route.query` / `useRoute` | loopId/taskId 处理 |
| 权限守卫 | grep `v-permission` / `usePermission` | 按钮级权限 |
| 空/错/载态 | grep `empty` / `loading` / `error` | 三要素完整性 |
| WebSocket | grep `RealtimeWS` / `useWebSocket` | 实时数据接入 |
| 状态机映射 | grep `STATUS` / `statusMap` | 状态渲染完整性 |
| Emoji | grep emoji 字符 | Emoji 清零 |
| hex 色值 | grep `#[0-9a-fA-F]{3,6}` | hex 清零（棘轮守护） |
| 行内样式 | grep `style="` | 行内样式收敛 |
| 请求竞态 | grep `useLatestRequest` / `AbortController` | 请求代次保护 |

### 2.3 组件走查（共享组件）

**文件**：`frontend/apps/web-antd/src/components/clpm/*.vue`

| 组件 | 检查项 | 关注点 |
|---|---|---|
| `ClpmPageToolbar` | props（title/actions/aiScene）、插槽 | 工具栏规范使用 |
| `ClpmEmptyState` | props（reason/action/range）、三要素 | 空态三要素 |
| `ClpmDangerConfirmModal` | props（level/title/requireCode）、确认码机制 | 危险操作确认 |
| `ClpmBulletChart` | props（value/target/bands）、替代 gauge | 子弹图规范 |
| `ClpmAiInsight` | props（scene/loopId/hideWhenDisabled）、场景 | AI 洞察组件 |
| `ClpmDataCanvas` | props（empty/emptyReason）、空态载体 | 图表空态 |
| `LoopFleetView` | 结构、props、事件 | 左栏列表组件 |
| `useSavedView` | composable、workspace/table 双模式 | 视图模式切换 |

### 2.4 后端契约走查

**文件**：`backend/app/api/v1/endpoints/*.py` + `backend/app/core/permissions.py`

| 检查项 | 检查方式 | 关注点 |
|---|---|---|
| API 端点 | grep `@router` | 路径、方法 |
| 权限装饰器 | grep `require_perms` | 权限码 |
| 状态机 | grep `status` / `Status` | 状态枚举 |
| 请求/响应模型 | 读取 Pydantic schema | 字段完整性 |
| WebSocket | grep `websocket` / `ws` | 实时推送 |

## 6. 注意力机制评估工具

### 6.1 首屏 3 秒扫视测试

**方法**：打开页面，3 秒内闭眼回忆，记录能记住的关键信息。

**达标标准**：
- 能说出"哪里有异常"（异常优先）
- 能说出"多严重"（严重度分级）
- 能说出"要不要立即处理"（优先级）

**记录格式**：
```
首屏 3 秒扫视：
- 能记住的信息：？
- 遗漏的关键信息：？
- 视觉噪音：？
- 达标：是/否
```

### 6.2 操作效率测试

**方法**：完成核心任务的点击数与决策点数。

**达标标准**：
- 核心任务 ≤3 点击
- 决策点 ≤2 个
- 无多余确认弹窗

### 6.3 注意力打断计数

**方法**：完成任务过程中，记录注意力被打断的次数。

**打断类型**：
- 自动弹窗
- Toast 通知
- 视觉噪音
- 不相关信息

**达标标准**：核心任务完成期间打断 ≤1 次
