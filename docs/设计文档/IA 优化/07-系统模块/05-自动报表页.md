## 1. 页面定位与核心价值

### 1.1 定位

自动报表页是系统模块的**定期输出入口**，定位为 CLPM 报表自动化配置中心——支持班报/日报/周报/月报 4 类周期报表配置，异步生成+进度轮询跟踪，收件人管理和启停控制。页面采用表格+Modal CRUD 模式，内嵌进度条实时展示生成状态。

### 1.2 核心价值

| 价值 | 实现 | 评估 |
|---|---|---|
| 4 类周期报表 | 班/日/周/月覆盖不同时间粒度 | ✅ |
| 异步生成 | generateReportApi + usePolling 轮询 | ✅ |
| 进度跟踪 | 表格内嵌 Progress 条 | ✅ |
| 启停控制 | Switch 快速启停 | ✅ |
| 收件人管理 | 表单配置收件人列表 | ✅ |
| 空态处理 | ClpmEmptyState | ✅ |

## 3. 第一性原理评估（视角一）

### 3.1 用户核心需求

| 问题 | 回答方式 | 当前实现 |
|---|---|---|
| 需要定期出什么报表？ | 4 类周期：班/日/周/月 | ✅ |
| 报表怎么配置？ | 新增/编辑配置 → Modal 表单 | ✅ |
| 报表生成进度如何？ | 表格内嵌 Progress 条 | ✅ |
| 想立即生成一份？ | "立即生成"按钮触发异步任务 | ✅ |
| 不想自动生成？ | Switch 开关启停 | ✅ |
| 以前生成的报表在哪？ | — | ❌ 缺少历史记录 |

### 3.2 范式级评估

**优点**：
- **4 类周期覆盖全面**：班报（8h）/日报（24h）/周报（168h）/月报（720h）满足不同时间粒度需求
- **异步生成+进度轮询**：`generateReportApi` + `usePolling` 实时跟踪生成进度，无需 WebSocket
- **进度条内嵌表格**：Progress 条直接显示在表格行内，一目了然
- **Switch 快速启停**：`isEnabled` 开关即时生效，配置即控制
- **ClpmEmptyState**：空态友好提示，引导新增首个报表

**不足**：
- **收件人格式校验不足**：收件人用文本框输入，格式验证不够严格，建议增加邮箱格式校验和多选支持
- **缺少历史报表记录**：已生成的报表无查看/下载入口，用户无法回溯历史结果
- **缺少批量操作**：无法按周期批量触发生成

### 3.3 范式级发现

| 编号 | 发现 | 级别 | 理由 |
|---|---|---|---|
| F-RPT-001 | **收件人格式校验不足** | P2 | 收件人文本框无邮箱格式校验，建议增加正则校验和多选 Chip |
| F-RPT-002 | **缺少历史报表记录** | P3 | 无已生成报表的查看/下载入口，建议增加"历史报表"Tab |
| F-RPT-003 | **缺少批量生成** | P3 | 无法批量触发生成，建议支持按周期批量触发 |

## 10. 结论

自动报表页是系统模块的**定期输出基础设施**（3.42/4.0，B+），4 类周期覆盖全面，异步生成+进度轮询跟踪，Switch 快速启停，ClpmEmptyState 空态处理，实现了报表自动化的基础能力。

**核心问题**是收件人格式校验不足（F-RPT-001）和缺少历史报表记录（F-RPT-002）。进度条与表格混合显示略显拥挤，可优化视觉布局。

**核心建议**：
1. **短期**：收件人格式校验+多选（1 天）+ 历史报表 Tab（1 天）
2. **中期**：随双架构路径 B，自动报表在驾驶舱模式简化为状态卡片+最近结果，工作站模式保留完整配置管理
3. **长期**：批量操作支持、报表模板库
