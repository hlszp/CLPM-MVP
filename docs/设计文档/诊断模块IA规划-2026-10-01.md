# 诊断模块 IA 规划（2026-10-01）

> 基于现状四页（0936 重构后）+ 16 号文能力全景（F1~F6）+ 07 设计方案，提出的演进规划。本文档为方案，实施待确认。

## 一、现状与问题

当前四页：诊断工作台 / 诊断概览 / 诊断记录 / 诊断任务（0936-0938 重构后）。

| 问题 | 说明 |
|---|---|
| 能力藏在抽屉里 | F1 回路档案（概览行抽屉）、F2 复诊对比（详情弹窗内）、F4 共性组对比（drawer）——都是二级弹层，用户不点开不知道存在 |
| 工作台与概览的回路上下文割裂 | 工作台看单回路结论，想看该回路历史/对比要跳概览找行点抽屉 |
| F3 覆盖台账折叠在概览顶部 | 每日全量诊断上线后覆盖数据是核心运营指标，折叠块展示分量不足 |
| 记录页与档案功能部分重叠 | 记录=全厂检索，档案=单回路纵向——两者互补但入口分散 |

## 二、子菜单规划（五页）

```
诊断
├── 诊断概览      /diagnosis/overview     全厂现状（保持，微调）
├── 诊断工作台    /diagnosis/workbench    单回路发起+结论（保持，强化）
├── 诊断记录      /diagnosis/records      全厂历史检索（保持）
├── 诊断任务      /diagnosis/tasks        执行监控（保持）
└── 诊断分析 ★    /diagnosis/analysis    新增：F3+F4 合页（覆盖台账全量 + 共性问题回路组）
```

**新增"诊断分析"页**（把藏起来的能力升为一等公民）：
- 上区：**F3 诊断覆盖台账**全量视图（每日全量诊断的覆盖率/触发方式分布/未诊断归因——现在概览顶部折叠块迁来并展开为完整面板）
- 下区：**F4 共性问题回路组**（按主分类聚合的回路组列表 + 组内横向对比——现 cohort-compare-drawer 的内容平铺 + 组间导航）
- 角色：ADMIN/工程师看全局质量与批量问题（如"某装置 12 个回路同为工艺外扰"→ 批量处置依据）

**概览页微调**：F3 折叠块移除（迁至诊断分析），概览专注"每回路最新一条 + 复核闭环"，页面更轻。

## 三、诊断工作台布局规划（强化版）

现状（0936 重构）：左脊柱（装置树+回路单选+可诊断过滤+徽标筛选）→ 主区上部发起卡 / 下部三 Tab。

```
┌─────────────┬──────────────────────────────────────────────┐
│ 装置树       │ 行1 选中回路卡（位号/描述/适用性/预检徽标）        │
│             ├──────────────────────────────────────────────┤
│ 回路列表     │ 行2 发起区：时间窗 | 算子 | [发起诊断]            │
│ ·单选       │      （L0/L1 阻断告警 / L2 警告 / 进度条）        │
│ ·仅可诊断✓  ├──────────────────────────────────────────────┤
│ ·徽标筛选    │ 行3 结论区 Tabs（v-if 有结果）：                 │
│             │  [诊断结论] [证据链] [处置建议] [历史档案 ★]       │
│             │   ↑新增第 4 Tab：本回路历史 run 列表（F1 档案     │
│             │    纵向时间线平铺，点击任一条→本区切换到该次结论    │
│             │    + F2 与上一次对比入口）                        │
└─────────────┴──────────────────────────────────────────────┘
```

**核心增量：第 4 个"历史档案" Tab**——工作台内闭环"发起→看结论→翻历史→对比"，不再跳概览找抽屉。复用 loop-archive-drawer 的数据接口，以平铺时间线替代抽屉；行点击即把结论区切到历史 run（Tab 内二次切换，面包屑提示当前查看的是历史次）。

## 四、实施建议（两批）

- **批 1（纯前端，半天）**：工作台加"历史档案"Tab（复用 F1 接口）；概览移除 F3 折叠块。
- **批 2（纯前端，一天）**：新增"诊断分析"页（F3 全量 + F4 平铺 + 组内对比从 drawer 改内嵌）；路由/菜单 order 重排（概览 0-工作台 1-记录 2-任务 3-分析 4）。

无后端改动（F1/F3/F4 接口全部现成）。

## 五、明确不做（保持克制）

- 不加"诊断看板/大屏"类页面——驾驶舱（cockpit）已承担；
- 不在工作台做多回路批量（每日定时全量已覆盖批量场景，手动路径保持单回路聚焦）；
- 不把复核工作流独立成页（复核频率低，概览行内抽屉够用）。
