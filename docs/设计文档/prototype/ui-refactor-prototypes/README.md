# CLPM UI 重构原型

本目录包含基于评估报告设计的两个核心页面静态原型，用于视觉和交互效果评估。

## 原型文件

| 文件 | 说明 |
|------|------|
| [dashboard-bento.html](dashboard-bento.html) | **系统概览页（Bento网格版）** - 12列Bento网格布局，展示跨模块待办、数据链路健康、异常预测、诊断摘要、整改有效率、性能趋势等。 |
| [loop-workbench.html](loop-workbench.html) | **回路工作台（单页四区升级版）** - master-detail布局，左侧回路列表+右侧四区垂直结构（概览→性能→诊断→整定），展示就地交互模式。 |

## 设计升级要点

### 1. 设计系统扩展
- 多级阴影体系（xs/sm/card/hover/modal）
- 4级圆角（sm/r/md/lg）
- 微交互动效时长变量
- 保留ZL工业五色板和冷灰白底色

### 2. 借鉴的设计模式
- **Bento网格布局**：系统概览页采用12列CSS Grid，信息密度高但有序
- **KPI环形进度**：轻量SVG组件替代部分ECharts小图
- **就地交互**：诊断标签hover显示确认/忽略/创建跟踪按钮，减少弹窗
- **卡片微交互**：hover微上浮+阴影加深，反馈即时
- **状态色条**：卡片顶部/左侧彩色状态条（teal/blue/amber/rose）
- **gauge仪表盘**：整改有效率用半圆仪表盘直观展示

### 3. 保留的工业特性
- 冷灰白底色 #f4f7fb（未用米黄旧纸色）
- 无衬线字体Inter + Fira Code等宽数字（未用衬线/手写字体）
- 1px强分割线为主，阴影克制
- 低饱和工业状态色（emerald/amber/rose/blue/slate + teal）
- 无装饰性元素（纸纹/胶带/邮票/猫咪等）
- 双轴导航架构保留

## 如何查看

直接在浏览器中打开HTML文件即可，无需服务器或构建。两个页面右下角有互相跳转链接。
