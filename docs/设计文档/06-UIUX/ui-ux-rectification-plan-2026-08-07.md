## 1. 整改目标

一句话：**把 CLPM 前端从"框架默认脸 + 规范执行不齐"提升到"有品牌身份的工业专业工具"**，同时修复信任级缺陷、打通两类核心角色的日常动线。

三维目标：

1. **信任**（Phase 0）：消灭全部 P0——死导航、风险确认绕过、波形轴错误、品牌缺失、审计/用户数据映射失效。
2. **专业**（Phase 1 主体）：界面风格整体升级（专项 A）——色彩有纪律、数字可比较、空态会引导、图表说人话、品牌可识别。
3. **效率**（Phase 1-2）：仪控工程师高频动线无摩擦（巡检有增量、筛选不丢失、验证有提醒）；管理者门面页面零报错、排序直达关注点。

可度量验收指标（终验对照表）：

| 指标 | 现状 | 目标 | 验证方式 |
|---|---|---|---|
| Nielsen 启发式总分 | 20/40 | ≥28/40 | 复评（同一清单） |
| P0 缺陷 | 5 项 | 0 | 逐条复现验证 |
| 硬编码 hex | 155 行 / 33 文件 | 0（stylelint 白名单守护） | `grep` + lint |
| 裸"暂无数据"页面 | 8+ | 0 | 逐页走查 |
| `aria-label` / 键盘可达 | 0 处 | 工具栏+行内操作 100% | grep + 键盘走查 |
| 装饰图表空转（gauge/donut/饼） | 3 处 | 0 | 走查 |
| 审计/用户列表显示与 API 一致性 | 全列 "—"/全员"禁用" | 一致 + E2E 断言 | E2E |
| 管理者首屏错误 toast | 登录必现 | 0 | sponsor 账号实测 |
| 巡检增量视图 | 无 | 监控+工作台上线 | 实测 |
| 同名异物（页面/菜单/统计卡） | 3+ 处 | 0 | 词表比对 |

## 2. 总体策略：四条设计宪法 + 执行机制

四条宪法（源自审查报告 §9.1，是本方案全部具体动作的判定依据）：

1. **颜色是信息通道，不是装饰材料**——每处用色必须能回答"这个颜色在告诉我什么"；类别维度一律中性化，语义五色仅服务"状态/异常/需行动"。
2. **空状态是一等公民**——三要素（为什么空/下一步做什么/数据范围）；无数据时不渲染装饰图表；0 值与无数据是两种状态。
3. **数字必须可比较**——右对齐 + tabular-nums + 全站统一精度表 + 单位进表头；每个关键数字带上下文（目标/区间/趋势/时间）。
4. **专家效率与新手引导双通道**——高频页补加速器（筛选入 URL、密度切换、行内快捷动作），新手路径保持渐进披露，互不干扰。

执行机制（让宪法不反弹）：

- **token 单一来源**：`industrial-light.css` CSS 变量为唯一真相，`preferences.ts`/`use-clpm-theme.ts`/ECharts preset 全部引用之；禁第二套语义色。
- **lint 门禁**：stylelint 禁裸 hex（白名单豁免）；eslint 规则禁 `transition: all`；vue-a11y 类规则逐步开启。
- **PR 检查单**：§8 第 2 条的 15 条精简清单进 PR 模板。
- **视觉回归**：Playwright 截图基线（21 个关键页面），风格改动必跑 diff 评审。
- **文档回写**：token/组件规则变更同步 UI/UX 规范版本号。

## 3. 专项 A：整体界面风格升级（重点专项）

> 用户判断"整体界面风格还有很大提升空间"——审查证实这一判断：当前界面是"vben/antd 框架默认脸"，品牌缺位、色彩无纪律、层级靠卡片平铺。本专项给出方向选型、token 级规范、组件与页面改造清单。

### A.1 现状风格诊断（为什么现在看起来"不专业"）

| 维度 | 现状 | 专业参照的差距 |
|---|---|---|
| 品牌 | 全站 "Vben Admin"，登录页 SaaS stock 插画 + 占位符幽灵字 | 工业软件第一眼定生死：Siemens iX / Emerson DeltaV Live 首屏即品牌 |
| 色彩 | 类别七色（温度红/压力蓝…）、彩虹 gauge×6、零值彩色、彩色 icon 圆底统计卡 | ISA-101 灰度纪律：90% 中性色，颜色只给异常；现界面色相数远超上限 |
| 层级 | 白卡平铺等权重、大空白盒、10+ 图标工具栏 | 专业工具靠"分区线+标题条+密度"建立层级，不靠卡片堆叠（Linear/ GitLab Pajamas 式密度） |
| 图表 | 单值 gauge、单分类 donut、假数据饼图、45° 轴标签 | Stephen Few：bullet/sparkline/区间带；图表无数据不渲染 |
| 数字 | 单位逐格重复、精度不一、对齐不统一 | 工业软件数字是主角：等宽、右对齐、精度全站一致 |
| 细节 | 截断（"理员"/"04:19:1"）、断行（规则代码）、Emoji 区标 | 专业感死在细节：截断=信息丢失=不信任 |

结论：风格问题不是"美化"问题，是**纪律**问题——现有 UI/UX v6.1 规范写对了 80%，代码执行了 40%，且缺少"品牌识别层"。

### A.2 风格方向选型

| 方向 | 描述 | 优点 | 风险/成本 | 判定 |
|---|---|---|---|---|
| 方向一：**工业浅色深化（Calm Light 2.0）** | 保留浅色主基调；中性灰阶 + 单蓝 accent 收敛 + 语义五色校准对比度；去卡片化、细分隔线、密排表格；图表语言全面更换 | 符合 NN/g 实证（小字密集分析界面亮模式更优）；贴合现有 token 基础；改造风险低、可分页渐进 | 视觉上"变化不够炫"，需要靠纪律和细节取胜 | **推荐主方向** |
| 方向二：深色控制室专项 | 仅面向中控室大屏/长时间监视场景的独立深色主题（按 ISO 11064 环境光逻辑），**不做全站反色** | 覆盖真实中控室场景；告警色深色下更醒目 | 全量暗色 token + 逐页验收，成本高 | Phase 3 专项；当前 vben 原生暗色经校准后保留开放（A.7） |
| 方向三：品牌壳层强化 | 侧边栏深色石墨品牌化（现有 semiDarkSidebar 基础）、登录页/页眉/关于页品牌区、统一插画与空状态视觉体系 | 品牌识别收益最大、改动集中在壳层 | 与内容区衔接需设计走查 | **并入方向一执行** |

**最终方向 = 方向一为主体 + 方向三的壳层品牌化 + 方向二列为 Phase 3 专项。**

场景句（决定明暗与密度的锚点）："仪控工程师在办公室 27 寸显示器上，白光环境，连续 2 小时做诊断与整定分析；班前巡检 15 分钟高频扫读；管理者每周 10 分钟看汇总。"——这句话强制了：浅色、高密度、数字优先、异常优先。

### A.3 Token 级目标规范（写入 UI/UX 规范 v6.2 的增量）

**色彩约定表（每色唯一语义，全站唯一真相）：**

| Token | 目标值 | 语义 | 使用白名单 |
|---|---|---|---|
| `--bg-page` | `#F6F7F9`（微偏冷灰） | 页面底 | 全局 |
| `--bg-panel` | `#FFFFFF` | 内容面板 | 卡片/表格/弹窗 |
| `--border-default` | `#E4E7EB` | 1px 分隔 | 全部隔线 |
| `--text-primary/secondary/muted` | `#1F2937 / #4B5563 / #6B7280` | 文字三级 | 全局 |
| `--accent` | `#0D6EFD`（沿用） | 主操作/当前态/链接/焦点 | 主按钮、选中、链接、focus ring，**其余禁用** |
| `--status-ok` | `#198754` | 正常/达标/在线 | 状态徽章、异常卡片着色 |
| `--status-warning` | 文字 `#B45309` + 底 `#FEF3C7` | 警告/需关注 | **注意：现规范 `#FFC107` 浅底白字对比度不达标，必须改为"深琥珀文字+浅琥珀底"组合** |
| `--status-danger` | `#DC3545` | 危险/故障/需立即行动 | 仅异常态，**禁止用于类别（如温度 tag）** |
| `--status-neutral` | `#6C757D` | 中性/数据不足/INCONCLUSIVE | 零值、空态、"—" |
| 类别色板 | **退役** | 回路类型/规则类型/指标类别 | 改为 slate 灰底（`#F1F5F9`）+ 深灰文字（`#475569`）+ 可选小图标 |

配套纪律：① 同屏色相 ≤4（含 accent）；② 零值/无数据/正常态不着色；③ 状态=颜色+图标+文字三维（沿用 §7.2）；④ 任何新色值必须先进约定表再进代码（lint 守护）。

**字体与数字：**

- 字体栈：系统无衬线（PingFang SC / Microsoft YaHei / Noto Sans SC）；`--font-mono` 沿用（位号/代码/版本号）。
- 字号阶梯：12 辅助 / 13 表格正文 / 14 正文 / 16 区块标题 / 18 页标题 / 24 KPI 主值（≤5 级执行）。
- 数字四件套（强制基线组件 `ClpmNumeric`）：右对齐、tabular-nums、精度表（**按指标定义全站统一小数位**：PV/SP 2 位、OP 1 位、评分 1 位、百分比 1 位、计数整数）、单位进表头；KPI 主值 Semibold。
- 中西文混排留 1/4 字宽间距（盘古之白），CSS 统一处理。

**间距/圆角/阴影/密度：** 沿用规范 §3.4-3.5（4pt 基栅、圆角 4/8、1px 边框优先、禁重阴影）；密度三档 32/36/44 组件级落地（当前仅台账页有）。

**新增"分区层级"规则（去卡片化）：** 页面内一级分区用"标题条（16px/600 + 1px 底分隔线）+ 内容"，不再默认白卡包裹；卡片只用于真正需要边界的内容（弹窗内分组、可点击入口）。嵌套卡片禁止。

### A.5 四个样板页面的 before→after

1. **登录页**：去 vben 品牌与 stock 插画 → CLPM 品牌区（名称/全称/版本号/工业剪影）+ 右侧浅灰表单卡；`%VITE_APP_TITLE%` 幽灵字修复（配 `.env`）。
2. **系统概览（工作台）**：待办卡非零优先排序且仅有数据卡着色 → 预测卡空态收敛为一行文字 → 链路健康 4 格时间戳等宽定宽 → 页面名与菜单统一。
3. **性能总览（L1 重做）**：6 彩虹 gauge → 4 个核心 bullet（自控率/性能评分/平稳率/好值率，值+目标+正常区间）+ 异常回路列表（评分升序）+ 趋势 sparkline；donut/饼图退役；工厂树抽屉化；一屏看完。
4. **回路实时监控**：11 彩色 chip → 一行中性文字筛选器（仅非零可点）；表格单位进表头、数值右对齐；行内 3 彩按钮 → 位号链接 + 行尾"更多"；类型 tag 中性化；趋势弹窗浅色头 + OP 副轴修复。

### A.6 图表语言统一（写进 ECharts preset 强制）

- 选型纪律：单值对目标→bullet；随时间→折线（直接标注端点值，少图例往返）；对比→条形；构成→≤5 类才用堆叠条，饼图默认禁；趋势进表格→sparkline。
- 区间语义：正常区间=灰带（markArea），越限才着色；告警线=细虚线 + 文字标注。
- 无数据不渲染图表（显示空态三要素）。
- 禁用清单：彩虹弧 gauge、3D、阴影渐变、`shadowBlur`（沿用 §15.2 UI-06）、45° 轴标签（改稀疏刻度/旋转 0°/悬浮显示）。
- 落地：`use-echarts-preset.ts` 扩为唯一入口，手写 option 的页面（monitor/pid-dashboard/overview）迁移。

### A.7 暗色策略（2026-08-07 实测修正后决策）

- **浅色为默认主题**（NN/g 实证：小字密集分析界面亮模式更优）；**暗色保留并校准后正式开放**——经真实开关复测，vben 原生暗色（darkAlgorithm + CSS 变量）整体可用，此前"半成品"判断系测试方法误差（手工注入 class 未触发 Vue 响应式算法）。
- Phase 1 校准项：`useClpmTheme` 明暗双板接入 ECharts preset；语义五色暗色对比度重校；补 `color-scheme: dark`；`industrial-light.css` 的 292 处补丁随 token 单源化逐步退役；28 条清单暗色走查通过后摘掉"未验收"帽子。
- 中控室大屏级深色为独立专项（Phase 3 立项）：按 ISO 11064 环境光逻辑单独调校，不做全站反色补丁。

### A.8 风格验收方式

- 视觉回归基线：21 个关键页面 Playwright 截图基线，风格 PR 必附 diff 评审；
- 走查清单：审查报告附录 A 的 28 条逐页过；
- 门禁：stylelint hex 白名单 + "无裸 hex"grep 进 pre-push；
- 文档：UI/UX 规范升 v6.2（色彩约定表/分区层级规则/图表语言/暗色决策回写）。

## 5. 专项 C：角色工作流闭环

**C1 仪控工程师动线（Phase 1-2）**
