## 1. 文档概述与定位

### 1.1 文档目的

本文档将 PRD v4.0、FDS/ADS/DDS/IDS v4.0、《关键算法设计说明》v2.0 与《控制回路性能评估数据流程图》v4.0 的约束收敛为一份**面向当前实现的体验规范**，定义 CLPM 平台所有模块与页面的视觉系统、信息架构、组件标准、交互模式与状态表达。

**v5.0 核心变更摘要**（对齐 v4.0 设计文档）：
- 指标体系重构为 **3+1+8 结构**：3 核心质量指标（准确率 A / 快速率 F / 稳定率 S）参与加权评分 + 1 投用指标（有效自控率 R）作折扣因子 + 8 辅助诊断指标不参与评分
- 综合评分公式更新为 **P = (A·a + F·f + S·s)/(a+f+s) × R**（R 为折扣因子而非平等加权项）
- 新增**指标可信度 A/B/C/D/E 五级**展示，基于有效数据率（valid_rate）自动判定
- 新增**数据血缘**下钻展示（8 字段：sampling_freq / quality_policy / tag_group / valid_rate 等）
- PV 质量码波形从"断线"改为**"灰色虚线保留连线"** + pvValid 标记（对齐 KEEP_ALL_WITH_VALIDITY 策略）
- 术语变更：**平稳率 → 稳定率**、**跟随率 → 快速率**

### 1.2 产品定位

CLPM 是面向流程工业（石油、化工、电力、冶金、造纸、医药中间体等）的**控制回路全生命周期绩效治理与优化闭环平台**，是**产品化、工具化**的产品（非项目型定制化系统）。

- **核心价值链**：`可信数据 → 自动性能评估 → 异常自动定位 → 回路诊断 → 建议与整定 → 轻量跟踪与验证 → 规模化交付`
- **产品化设计原则**：模块内聚自包含（每个模块"配置 → 运行 → 分析"三态自包含）、配置驱动（指标公式/诊断算法/引擎规则均支持用户自助配置）、实体内聚（回路作为核心实体，配置态与运行态归属同一模块）。
- **安全边界**：平台不直接修改 DCS 的 P/I/D 参数，只输出建议、证据、风险与回退方案；参数由授权人员人工实施并留痕。UI 不得出现任何"下发参数""写入 DCS"类入口。
- **不是**：单机 PID 调参软件、自动下写 DCS 的黑盒自整定系统、APC/RTO/SIS 替代品、繁重审批流的通用工单系统。

### 1.3 分期范围

| 阶段 | 定位 | UI 范围 |
|---|---|---|
| **Phase 1 (MVP/V1.0)** | 跑通"自动评估、自动诊断、轻量跟踪"闭环 | 工作台门户、回路管理、性能评估、诊断中心、系统管理全部页面；回路整定模块原型页面设计完成 |
| **Phase 2 (V2.0)** | 深度算法与高级整定 | 回路整定算法实现（模型辨识、PID 参数整定、闭环仿真）、整定效果统计、AI 辅助波形解读 |
| **Phase 3 (V3.0)** | 规模化与全厂优化 | 多厂区 1200+ 回路并发、厂级振荡源追踪、批次分析、经济效益折算 |

本文档覆盖 Phase 1 当前实现契约中的菜单页、隐藏详情页、专项配置页与 Phase 2 整定模块的结构性规范。旧 25 页面清单保留为历史来源，不再作为当前菜单验收项。

### 1.4 模块结构总览（v4.2：重构后实现契约）

CLPM 当前采用 **6 大功能模块 + 1 个门户入口** 的产品化架构，页面组织以 `implementation-contract.md` §2 为准：

| 模块 | 页面数 | 核心职责 | 分期 |
|---|---|---|---|
| 工作台（门户） | 1 | 全角色日常作业入口，聚合多模块数据 | Phase 1 |
| 回路管理 | 5 | AAS tag 同步 → 回路创建 → tag 关联 → 运行监控（实体内聚） | Phase 1 |
| 性能评估 | 5 | 指标配置 → 引擎规则 → 全局看板 → 低效排行 → 统计分析（功能内聚） | Phase 1 |
| 诊断中心 | 5 | 指标配置 → 诊断列表 → 诊断详情 → 异常跟踪 → 统计分析（功能内聚） | Phase 1 |
| 回路整定 | 5 | 工作台 → 模型辨识 → 整定算法 → 闭环仿真 → 效果统计（原型先行） | Phase 2（原型 Phase 1） |
| 系统管理 | 4 | 用户角色、审计日志、安全边界、自动报表 | Phase 1 |

## 2. 设计基调与反 AI Slop 原则

### 2.1 视觉语气

**稳重、审计化、任务驱动。** 这是工业治理平台，不是通用 SaaS 控制台，也不是概念展示网站。

- 信息密度高，但层级清晰。
- 优先展示状态、风险、下一步动作。
- 文案以业务动作和结论为中心，避免营销化表达。
- 首屏必须先回答"现在该做什么"，再解释"为什么"。

### 2.2 反 AI Slop 禁忌（强制）

| 禁忌 | 原因 | 替代方案 |
|---|---|---|
| 大面积装饰性渐变（紫/霓虹） | AI 训练语料的"科技感"万能公式，无品牌信息 | 单一工业蓝作 accent，中性底色 |
| Emoji 作功能图标 | 训练语料里每个 bullet 配 emoji，不专业 | 语义化 SVG 图标库（Lucide） |
| 圆角卡片 + 左彩色 border accent | 2020-2024 Material/Tailwind 烂大街组合 | 诚实边框分隔，表格为主 |
| 卡片瀑布流代替工作台 | 消费级模式，不适合工业高密度场景 | 高密度表格 + 侧栏详情 + 时间线 |
| SVG 画人脸/场景/物品 | AI 画 SVG 比例诡异 | 真实数据可视化或诚实 placeholder |
| 装饰性 icon 每处都配 | icon slop，无信息量 | 仅承载差异化信息的密度元素 |
| 编造 stats/quotes 装饰 | data slop | 留白或真实数据 |

### 2.3 信息密度分型

CLPM 属于**高密度型**产品（Dashboard/Tracker/诊断类），核心卖点是"数据驱动治理"。因此：

- 每屏需至少 3 处可见的产品差异化信息（非装饰性数据、状态推断、上下文关联）。
- 装饰性 icon 仍然忌讳——加的是**有内容的**密度，不是装饰。
- 列表和工作台页面优先高密度紧凑布局，不做营销站式大留白。

## 3. 设计系统 (Design Tokens)

### 3.1 色彩系统

所有颜色必须从 CSS 变量引用，不允许页面散落写死 hex。

#### 3.1.1 基础色

| Token | 值 | 用途 |
|---|---|---|
| `--bg-page` | `#F8F9FA` | 页面背景，长时间监控眼部舒适 |
| `--bg-panel` | `#FFFFFF` | 面板背景 |
| `--bg-muted` | `#EEF1F4` | 次级背景/表头底色 |
| `--border-default` | `#E5E7EB` | 默认 1px 边框，区分模块不用重阴影 |
| `--text-primary` | `#1F2937` | 主文本 |
| `--text-secondary` | `#4B5563` | 次文本 |
| `--text-muted` | `#6C757D` | 辅助说明 |

#### 3.1.2 品牌与动作色

| Token | 值 | 用途 |
|---|---|---|
| `--accent-blue` | `#0D6EFD` | 主 CTA、当前态、链接、焦点态（单一蓝色，仅用于主操作） |
| `--accent-blue-bg` | `#E7F1FF` | 主操作浅底色（hover/selected 行） |

#### 3.1.3 风险语义色（严格遵守）

风险色优先用于标签、边线、状态点，**不大面积铺底**。

| Token | 值 | 语义 | 适用场景 |
|---|---|---|---|
| `--status-ok` | `#198754` | 正常/达标 | 评分高、好值率达标、IMPLEMENTED、Auto 模式 |
| `--status-info` | `#0D6EFD` | 信息/提示 | IN_PROGRESS、Cascade 模式 |
| `--status-warning` | `#FFC107` | 警告/需关注 | PARTIAL、评分中、需现场核实、Uncertain 质量 |
| `--status-danger` | `#DC3545` | 危险/故障 | 评分低、PENDING、Manual 模式、Bad 质量 |
| `--status-neutral` | `#6C757D` | 中性/数据不足 | INCONCLUSIVE、IGNORED、可信度 E 级 |

#### 3.1.4 评分分级配色（动态映射）

综合评分 `score`（0-100）的颜色映射，阈值由算法配置决定，UI 需支持动态读取：

| 区间（默认） | 颜色 | 语义 |
|---|---|---|
| `score >= 80` | `--status-ok` 青绿 | 优良 |
| `60 <= score < 80` | `--status-warning` 琥珀 | 关注 |
| `score < 60` | `--status-danger` 警示红 | 低效（Bad Actor） |
| `status = INCONCLUSIVE` | `--status-neutral` 冷灰 | 数据不足，**严禁显示 0 分** |

#### 3.1.5 PV 数据质量色（v5.0 更新：灰色虚线保留连线）

PV tag 质量码（Good/Bad/Uncertain）的视觉表达（对齐 v4.0 KEEP_ALL_WITH_VALIDITY 策略）：

| 质量码 | 颜色 | 波形表现 | pvValid | 标签表现 |
|---|---|---|---|---|
| `Good` | `--status-ok` 青绿 | PV 实线正常显示 | `true` | 绿色"Good"徽章 |
| `Bad` | `--status-neutral` 冷灰 | **PV 灰色虚线保留连线**（v5.0 变更：不再断线）+ 悬浮提示"PV 数据质量不可信" | `false` | 红色"Bad"徽章 |
| `Uncertain` | `--status-warning` 琥珀 | PV 琥珀色虚线保留连线 + 悬浮提示"PV 数据质量不确定" | `false` | 琥珀"Uncertain"徽章 |

> **v5.0 关键变更**：对齐 IDS v4.0 §4.4 与 FDS §5.3.1.2 KEEP_ALL_WITH_VALIDITY 策略，Bad 点不再断线，改为灰色虚线保留连线。数据点保留在时间序列中，通过 `pvValid` 标记区分有效/无效，不删除任何数据点。

#### 3.1.6 指标可信度色（v5.0 新增）

指标可信度 A/B/C/D/E 五级颜色编码（对齐 FDS §5.3.10 / 算法说明 §3.7.2）：

| 可信度等级 | valid_rate | 颜色 | 语义 | UI 处理 |
|---|---|---|---|---|
| `A` | ≥ 0.95 | `--status-ok` 青绿 | 高可信 | 正常展示 |
| `B` | 0.80 ~ 0.95 | `--status-info` 深蓝 | 较高可信 | 正常展示 + 可信度角标 |
| `C` | 0.60 ~ 0.80 | `--status-warning` 琥珀 | 中等可信 | 显著标注 + 建议复核 |
| `D` | 0.20 ~ 0.60 | `--status-danger` 警示红 | 低可信 | 警告提示 + "谨慎使用" |
| `E` | < 0.20 | `--status-neutral` 冷灰 | 极低可信 | **标记 INCONCLUSIVE**，评分留空（显示"—"） |

## 6. 页面设计规范

本章按 6 模块 + 门户组织，对 25 个页面逐一规范。每个页面规范包含：路由、页面结构模式、目标角色、分期、页面内容、设计要点。

### 6.1 工作台（门户）

#### 6.1.1 性能总览首页 `/`

**页面结构模式**：工作台页（上中下三行布局 + 顶部筛选栏）
**目标角色**：全角色（仪控工程师默认首页）
**分期**：Phase 1

**页面布局**：

```
+----------------------------------------------------------------------------------------+
| 顶部筛选栏：[全厂 ▼][装置 ▼][单元 ▼]  统计粒度：(•)日 ( )周 ( )月                       |
+----------------------------------------------------------------------------------------+
| 上行（20%）：KPI 卡片区（v5.0：3+1+8 结构展示）                                          |
| [准确率A] [快速率F] [稳定率S] [有效自控率R] [综合评分P] [好值率(可信度)]                |
+----------------------------------------------+-----------------------------------------+
| 中行左（60%）：低效回路列表                  | 中行右（40%）：选中回路摘要              |
| [位号 | 评分 | 预诊标签 | 关键指标]          | 小趋势缩略图（PV/SP/OP）                |
| [位号 | 评分 | 预诊标签 | 关键指标]          | 关键状态：MODE/PID/质量码                |
| [位号 | 评分 | 预诊标签 | 关键指标]          | 快捷动作：进入诊断 / 进入异常跟踪        |
+----------------------------------------------+-----------------------------------------+
| 下行（30%）：最近月/周关键指标组合趋势                                                  |
| 自控投用率（蓝线）+ 稳定率（绿线）双轴折线  粒度切换：(•)日 ( )小时                       |
+----------------------------------------------------------------------------------------+
```

**页面内容**：
- **顶部筛选栏**：全厂/装置/单元级联下拉 + 日/周/月单选（默认日）
- **上行 KPI 卡片区**（v5.0 更新：3+1+8 结构）：6 项核心指标卡片（准确率 A / 快速率 F / 稳定率 S / 有效自控率 R / 综合评分 P / 好值率），每卡显示当前值 + 同比变化箭头 + **可信度等级角标**（A/B/C/D/E 颜色编码，对齐 §3.1.6）。综合评分卡片额外显示评分构成分解（A/F/S 加权 + R 折扣，对齐 §7.12）。好值率卡片显示可信度等级（valid_rate → A/B/C/D/E），影响综合评分可信度
- **中行左**：低效回路列表（位号/评分/预诊标签/关键指标），按评分升序排列
- **中行右**：选中回路的小趋势缩略图（PV/SP/OP 三线，PV 线根据质量码灰色虚线保留连线）+ 关键状态摘要（控制方式/PID 参数/数据质量/可信度等级）+ 快捷动作入口
- **下行**：最近月/周关键指标组合趋势（自控投用率 + 稳定率双线），支持日/小时粒度切换

**设计要点**：
- 上中下三行高度比约 20% : 40% : 30%（剩余 10% 为筛选栏与间距）
- KPI 卡片不使用渐变/彩色 border，仅用数值大小与颜色（评分色块）传递信息
- 中行左右联动：点击左侧回路行，右侧摘要即时刷新
- 下行趋势图默认显示最近 7 天，可切换至最近 30 天
- 数据来源：`kpi_snapshot_hourly`（最新一小时快照）、`action_tracker`（待办聚合）、`st_loop_data`（小趋势）

**关键交互**：

| 触发 | 行为 | 结果 |
|---|---|---|
| 切换装置/单元筛选 | 重载 KPI 与低效列表 | 上下文保持 |
| 切换日/周/月粒度 | 重算 KPI 聚合 | 卡片数值更新 |
| 点击低效回路行 | 选中当前回路 | 中行右摘要联动刷新 |
| 点击"进入诊断" | 跳转 `/diagnosis/:loopId` | 带 `loopId` |
| 点击"进入异常跟踪" | 跳转 `/diagnosis/tracker` | 带当前回路上下文 |
| 点击 KPI 卡片 | 展开详细说明 | 展示趋势、说明和相关低性能回路 |

- Tag 关联缺失时整行标红，tooltip 提示缺失项

  - `min` ≤ `alert` ≤ `max` 约束，违反时把手抖动反馈 + 红色边框
  - 滑轨分段着色：`[min, alert]` 绿色（优良区）、`[alert, max]` 琥珀（关注区）、超 `max` 红色（低效区）

  - 4 个按钮横向排列：`STABLE 稳定型` / `SLOW 慢速型` / `FAST 快速型` / `LOGIC 逻辑型`

  - 控制类型决定权重模板（对齐《关键算法设计说明》§4.7.3）
- **公式编辑器**：支持变量插入（pv/sp/op/mode/pv_quality/timestamps/pv_range/n）与函数插入（sum/mean/std/count/count_if/abs/sqrt/min/max/duration），实时语法校验（simpleeval 安全沙箱，对齐 C7），错误标红 + 提示

- **批量保存**：支持调用 `PUT /api/v1/configs/metrics` 批量保存全部 6 项配置（对齐 IDS v3.2 §2.8.2），事务化处理

#### 7.2.6 指标可信度标签（v5.0 新增，`confidence_level`）

对齐 FDS §5.3.10 / 算法说明 §3.7.2，基于有效数据率（valid_rate）自动判定五级，颜色编码详见 §3.1.6：

| 值 | 颜色 | 文本 | 图标 | 触发条件 | UI 处理 |
|---|---|---|---|---|---|
| `A` | `--status-ok` 青绿 | 高可信 | ✓ | valid_rate ≥ 0.95 | 正常展示，无额外提示 |
| `B` | `--status-info` 深蓝 | 较高可信 | ✓ | 0.80 ≤ valid_rate < 0.95 | 正常展示 + 可信度角标 |
| `C` | `--status-warning` 琥珀 | 中等可信 | ⚠ | 0.60 ≤ valid_rate < 0.80 | 显著标注 + tooltip "建议复核" |
| `D` | `--status-danger` 警示红 | 低可信 | ⚠ | 0.20 ≤ valid_rate < 0.60 | 警告提示 + tooltip "数据有效率低，谨慎使用" |
| `E` | `--status-neutral` 冷灰 | 极低可信 | ? | valid_rate < 0.20 | **标记 INCONCLUSIVE**，评分显示"—"，禁止参与聚合 |

**展示规则**：
- 角标形式：`[评分值] [可信度等级徽章]`，如 `78.5 [B]`
- 可信度 E 级时：评分区域显示 `INCONCLUSIVE —`，评分数值不展示
- 综合评分可信度 = min(A 可信度, F 可信度, S 可信度)，取最低等级
- 悬浮提示展示 `valid_rate` 具体数值（如 "有效数据率 87.3%"）
- 与计算状态标签（§7.2.1）联动：可信度 E 级时强制 `status=INCONCLUSIVE`

### 7.3 时序波形 (Time-Series Waveform)

**FDS 强制约束**：诊断详情页与回路运行详情页使用上下分栏，上部为时序波形。

**技术要求**：
- 图表库：ECharts，Canvas/WebGL 渲染
- **降采样**：必须开启 LTTB 降采样，`maxPoints` 默认 2000；超 10 万点强制降采样（`ERR_TS_DOWNSAMPLE_REQ`）
- **多轴联动**：PV、SP 同一 Y 轴（主轴）；OP 独立副 Y 轴（0-100%）
- **MODE 背景带**：按 `mode` 值分段着色（Manual 红/Auto 绿/Cascade 蓝）
- **PV 质量码表达**（v5.0 更新，对齐 KEEP_ALL_WITH_VALIDITY 策略）：
  - `Good`：PV 实线正常显示，`pvValid=true`
  - `Bad`：**PV 灰色虚线保留连线**（v5.0 变更：不再断线），`pvValid=false`，悬浮提示"PV 数据质量不可信"，**绝不使用 0 掩盖**
  - `Uncertain`：PV 琥珀色虚线保留连线，`pvValid=false`，悬浮提示"PV 数据质量不确定"
  - **SP/OP 线正常显示**，不受 PV 质量码影响
- **交互**：鼠标框选放大 (Zoom)、平移 (Pan)、十字准星联动 (Crosshair Sync)
- **时间窗**：最大跨度 30 天，超限提示 `ERR_TS_001`

### 7.9 空状态与异常状态

**空状态 (Empty)**：必须说明原因 + 提供动作入口。
- "暂无计算数据，请检查数据接入配置"
- "当前时间窗无低效回路"

**Partial 状态**：明确"缺什么、还能继续做什么、下一步去哪"。
- 批次 Partial：黄色警告横幅，列出 Inconclusive 回路数量与影响

**Inconclusive 状态**（v5.0 更新：对齐可信度 E 级，数据不足是一等公民，不是错误）：
- 灰色标签"数据不足" + 可信度角标"E"
- 波形区灰色虚线保留连线（pvValid=false 的点）
- 评分区显示"—"而非 0（**严禁以 0 分掩盖数据缺失**）
- tooltip"可信度 E 级（有效数据率 < 20%），无法计算"
- INCONCLUSIVE 快照在排行/聚合统计中单独计数展示，不参与装置级评分聚合

**Error 状态**：
- 计算超时/内存溢出：中断批次，记录日志，触发管理员告警
- 越权操作：全局 Toast"无权限"
- 网络异常：标准错误态 + 重试按钮

**8 类诊断标签颜色编码**：

| 标签 | 中文名 | 颜色 | 图标 |
|---|---|---|---|
| `OSCILLATION` | 振荡 | `--status-warning` 琥珀 | 〰 |
| `VALVE_STICTION` | 阀门粘滞 | `--status-danger` 警示红 | ⚠ |
| `OVERAGGRESSIVE` | 参数过激 | `--status-danger` 警示红 | ⚡ |
| `OVERCONSERVATIVE` | 参数过保守 | `--status-info` 深蓝 | 🐢 |

**诊断结论卡片结构**：

+----------------------------------------------------------+

+----------------------------------------------------------+

+----------------------------------------------------------+

| • 拟合度：0.92 (椭圆拟合)                                 |

| • 推理：PV-OP 散点图呈现椭圆轨迹，拟合度 0.92             |

**组件字段映射**（对齐 IDS v3.2 §2.4.2）：
- `fusedConfidence`：融合置信度（0-1），醒目展示在卡片顶部，进度条 + 百分比
- `diagnosisLabels[]`：诊断标签数组，每项含：

  - `algorithm`：算法版本号
- `featureValues`：特征值对象（oscillation_amplitude/oscillation_frequency/stiction_index/output_saturation_rate）
- `evidenceChain`：证据链（waveformUrl/scatterPlot/reasoning）
- `algorithmVersion`：算法版本号
- `diagnosedAt`：诊断时间

**交互**：

| 安全边界说明 | 正在加载内容 | — | 读取失败 | 展示安全边界说明 | — |

### 8.2 核心状态机

#### 8.2.1 回路就绪状态
```
Partial（Tag 关联字段缺失，标红） → 就绪（PV/SP/OP/MODE 完整校验通过）
```

#### 8.2.2 回路评估状态（`kpi_snapshot_hourly.status`，v5.0 更新：可信度联动）
```
正常计算 → SUCCESS（输出评分，标注可信度 A/B/C/D 等级）
valid_rate < 0.20（可信度 E 级） → INCONCLUSIVE（不计算评分、不参与聚合、灰色虚线保留连线）
0.20 ≤ valid_rate < 0.60（可信度 D 级） → SUCCESS + 警告"数据有效率低，谨慎使用"
部分字段缺失 → PARTIAL（黄色横幅）
```
- 可信度等级由 `valid_rate` 自动判定（对齐 §3.1.6 / §7.2.6 / §7.15）
- 可信度 E 级强制 `status=INCONCLUSIVE`，评分数值留空显示"—"
- 可信度 C/D 级评分正常展示，但附加角标提示

#### 8.2.3 Action Tracker 处理状态（`action_tracker.action_status`，v5.0 更新：状态枚举变更）
```
ACTIVE → RESOLVED（触发 A/B 对比采集）
ACTIVE → SUPPRESSED（人工抑制，不再展示但不删除）
SUPPRESSED → ACTIVE（重新激活）
```
- 每次变更记录 `updated_by` + `updated_at` + severity（INFO/WARN/ERROR/CRITICAL）
- 标记 RESOLVED 后截取 `[T-7天,T]` vs `[T,T+7天]` 窗口

#### 8.2.4 诊断标签（v4.1 更新，8 类枚举对齐 C6）
- `OSCILLATION` 振荡（FFT/自相关检测，振荡周期/频率特征命中）
- `VALVE_STICTION` 阀门粘滞（PV-OP 散点拟合命中椭圆/平行四边形）
- `OVERAGGRESSIVE` 参数过激（PID 增益分析，增益偏差/振荡指数超阈值）
- `OVERCONSERVATIVE` 参数过保守（PID 增益分析，响应时间/settling time 超阈值）
- `EXTERNAL_DISTURBANCE` 外扰频繁（频谱分析，扰动指数/频率集中度超阈值）
- `QUALITY_ABNORMAL` PV 质量异常（质量码统计，Bad/Uncertain 占比超阈值）
- `OUTPUT_SATURATION` 输出饱和（OP 范围统计，饱和时长占比超阈值）
- `MANUAL_REVIEW` 人工复核（综合评分 < 40，算法置信度低，需人工介入）

*说明：v4.1 对齐《关键算法设计说明》§5 C6 修正，诊断标签从自由文本改为 8 类固定枚举。多标签可共存（如同时存在振荡+阀门粘滞），通过 Dempster-Shafer 证据理论融合置信度（`fusedConfidence`）。*

#### 8.2.5 PV 数据质量状态（v5.0 更新：灰色虚线保留连线）
```
PV tag 质量码：
  Good → PV 实线正常显示，pvValid=true，参与 KPI 计算
  Bad → PV 灰色虚线保留连线（v5.0 变更：不再断线），pvValid=false，悬浮提示"PV 数据质量不可信"，不计入好值率
  Uncertain → PV 琥珀色虚线保留连线，pvValid=false，悬浮提示"PV 数据质量不确定"，按权重折算
SP/OP 线不受 PV 质量码影响，始终正常显示
```
- 对齐 KEEP_ALL_WITH_VALIDITY 策略：Bad/Uncertain 数据点保留在时间序列中，不删除
- 各指标通过 Metric Validity Mask 决定有效点（对齐算法说明 §3.5）

#### 8.2.6 整定推荐状态（v4.0 新增，Phase 2）
```
待辨识 → 已辨识（模型辨识完成） → 已整定（PID 参数推荐完成） → 已仿真（闭环仿真完成）
```

#### 8.2.7 报表生成状态
```
生成中 → 已生成（可下载）
生成异常（截图服务失败）→ 支持手动重试
```

#### 8.2.8 配置变更状态（v4.0 新增）
```
编辑中 → 弹确认弹窗（填写变更说明） → 确认变更 → 记录审计日志 → 生效
```

#### 8.2.9 任务状态（v5.0 新增，对齐 §7.13）
```
PENDING（排队） → PROCESSING（处理中） → SUCCESS（成功，写入快照表）
                                    └→ FAILED（失败，可重试）
PENDING/PROCESSING → CANCELLED（仅自定义任务可取消）
```
- 标准任务（STANDARD）：系统每小时定时触发，不可取消，结果写入 `kpi_snapshot_hourly` 参与聚合
- 自定义任务（CUSTOM）：用户按需触发，可取消，结果写入 `kpi_snapshot_custom` 不参与聚合
- 任务结果均带可信度角标（对齐 §7.15），可信度 E 级结果标注 INCONCLUSIVE

## 9. 交互模式规范

### 9.1 全局交互原则

- 任何页面优先服务当前用户要完成的动作，而非展示所有信息。

### 10.5 PV 质量码在波形图中的处理（v4.0 关键）

**核心规则**：数据质量主要针对 PV 值，PV tag 携带质量码（Good/Bad/Uncertain）。

| 质量码 | PV 线表现 | SP/OP 线表现 | 悬浮提示 |
|---|---|---|---|
| `Good` | 实线正常显示（青绿或主色） | 正常显示 | 无 |

**实现要点**：
- PV 线根据质量码分段渲染：Good 段实线、Bad 段灰色虚线保留连线、Uncertain 段琥珀虚线保留连线

- 质量码图例固定显示在波形区右上角
- KPI 好值率基于 PV 质量码统计（Good 时长 / 总时长）

| huashu-design 原则 | CLPM 应用 |
|---|---|
