## 1. 文档概述与定位

### 1.1 文档目的

本文档将 PRD v3.0 的产品需求、FDS v3.0 的功能规格、ADS v3.0 的系统架构、DDS v3.0 的数据模型、IDS v3.2 的接口契约、《关键算法设计说明》v1.0 的算法规范收敛为一份**面向实现的设计规范**，定义 CLPM 平台所有模块与页面的视觉系统、信息架构、组件标准、交互模式与状态表达。

### 1.2 产品定位

CLPM 是面向流程工业（石油、化工、电力、冶金、造纸、医药中间体等）的**控制回路全生命周期绩效治理与优化闭环平台**，是**产品化、工具化**的产品（非项目型定制化系统）。

- **核心价值链**：`可信数据 → 自动性能评估 → 异常自动定位 → 回路诊断 → 建议与整定 → 轻量跟踪与验证 → 规模化交付`
- **产品化设计原则**：模块内聚自包含（每个模块"配置 → 运行 → 分析"三态自包含）、配置驱动（指标公式/诊断算法/引擎规则均支持用户自助配置）、实体内聚（回路作为核心实体，配置态与运行态归属同一模块）。
- **安全边界**：平台不直接修改 DCS 的 P/I/D 参数，只输出建议、证据、风险与回退方案；参数由授权人员人工实施并留痕。UI 不得出现任何"下发参数""写入 DCS"类入口。
- **不是**：单机 PID 调参软件、自动下写 DCS 的黑盒自整定系统、APC/RTO/SIS 替代品、繁重审批流的通用工单系统。

### 1.3 分期范围

| 阶段 | 定位 | UI 范围 |
|---|---|---|
| **Phase 1 (MVP/V1.0)** | 跑通"自动评估、自动诊断、轻量跟踪"闭环 | 工作台门户、回路管理、性能评估、诊断中心、系统管理全部页面；回路整定模块原型页面设计完成 |
| **Phase 2 (V2.0)** | 深度算法与高级整定 | 回路整定算法实现（模型辨识、PID 参数整定、闭环仿真）、整定效果统计、AI 辅助波形解读 |
| **Phase 3 (V3.0)** | 规模化与全厂优化 | 多厂区 1200+ 回路并发、厂级振荡源追踪、批次分析、经济效益折算 |

本文档覆盖 Phase 1 全部 25 个页面（含回路整定模块原型页面）+ Phase 2 整定模块的结构性规范。Phase 3 页面仅保留结构占位。

### 1.4 模块结构总览（v4.0 核心变更）

CLPM v4.0 采用 **6 大功能模块 + 1 个门户入口** 的产品化架构，共 **25 个页面**：

| 模块 | 页面数 | 核心职责 | 分期 |
|---|---|---|---|
| 工作台（门户） | 1 | 全角色日常作业入口，聚合多模块数据 | Phase 1 |
| 回路管理 | 5 | AAS tag 同步 → 回路创建 → tag 关联 → 运行监控（实体内聚） | Phase 1 |
| 性能评估 | 5 | 指标配置 → 引擎规则 → 全局看板 → 低效排行 → 统计分析（功能内聚） | Phase 1 |
| 诊断中心 | 5 | 指标配置 → 诊断列表 → 诊断详情 → 异常跟踪 → 统计分析（功能内聚） | Phase 1 |
| 回路整定 | 5 | 工作台 → 模型辨识 → 整定算法 → 闭环仿真 → 效果统计（原型先行） | Phase 2（原型 Phase 1） |
| 系统管理 | 4 | 用户角色、审计日志、安全边界、自动报表 | Phase 1 |

## 2. 设计基调与反 AI Slop 原则

### 2.1 视觉语气

**稳重、审计化、任务驱动。** 这是工业治理平台，不是通用 SaaS 控制台，也不是概念展示网站。

- 信息密度高，但层级清晰。
- 优先展示状态、风险、下一步动作。
- 文案以业务动作和结论为中心，避免营销化表达。
- 首屏必须先回答"现在该做什么"，再解释"为什么"。

### 2.2 反 AI Slop 禁忌（强制）

| 禁忌 | 原因 | 替代方案 |
|---|---|---|
| 大面积装饰性渐变（紫/霓虹） | AI 训练语料的"科技感"万能公式，无品牌信息 | 单一工业蓝作 accent，中性底色 |
| Emoji 作功能图标 | 训练语料里每个 bullet 配 emoji，不专业 | 语义化 SVG 图标库（Lucide） |
| 圆角卡片 + 左彩色 border accent | 2020-2024 Material/Tailwind 烂大街组合 | 诚实边框分隔，表格为主 |
| 卡片瀑布流代替工作台 | 消费级模式，不适合工业高密度场景 | 高密度表格 + 侧栏详情 + 时间线 |
| SVG 画人脸/场景/物品 | AI 画 SVG 比例诡异 | 真实数据可视化或诚实 placeholder |
| 装饰性 icon 每处都配 | icon slop，无信息量 | 仅承载差异化信息的密度元素 |
| 编造 stats/quotes 装饰 | data slop | 留白或真实数据 |

### 2.3 信息密度分型

CLPM 属于**高密度型**产品（Dashboard/Tracker/诊断类），核心卖点是"数据驱动治理"。因此：

- 每屏需至少 3 处可见的产品差异化信息（非装饰性数据、状态推断、上下文关联）。
- 装饰性 icon 仍然忌讳——加的是**有内容的**密度，不是装饰。
- 列表和工作台页面优先高密度紧凑布局，不做营销站式大留白。

## 3. 设计系统 (Design Tokens)

### 3.1 色彩系统

所有颜色必须从 CSS 变量引用，不允许页面散落写死 hex。

#### 3.1.1 基础色

| Token | 值 | 用途 |
|---|---|---|
| `--bg-page` | `#F8F9FA` | 页面背景，长时间监控眼部舒适 |
| `--bg-panel` | `#FFFFFF` | 面板背景 |
| `--bg-muted` | `#EEF1F4` | 次级背景/表头底色 |
| `--border-default` | `#E5E7EB` | 默认 1px 边框，区分模块不用重阴影 |
| `--text-primary` | `#1F2937` | 主文本 |
| `--text-secondary` | `#4B5563` | 次文本 |
| `--text-muted` | `#6C757D` | 辅助说明 |

#### 3.1.2 品牌与动作色

| Token | 值 | 用途 |
|---|---|---|
| `--accent-blue` | `#0D6EFD` | 主 CTA、当前态、链接、焦点态（单一蓝色，仅用于主操作） |
| `--accent-blue-bg` | `#E7F1FF` | 主操作浅底色（hover/selected 行） |

#### 3.1.3 风险语义色（严格遵守）

风险色优先用于标签、边线、状态点，**不大面积铺底**。

| Token | 值 | 语义 | 适用场景 |
|---|---|---|---|
| `--status-ok` | `#198754` | 正常/达标 | 评分高、好值率达标、RESOLVED、Auto 模式 |
| `--status-info` | `#0D6EFD` | 信息/提示 | IN_PROGRESS、Cascade 模式 |
| `--status-warning` | `#FFC107` | 警告/需关注 | PARTIAL、评分中、需现场核实、Uncertain 质量 |
| `--status-danger` | `#DC3545` | 危险/故障 | 评分低、PENDING、Manual 模式、Bad 质量 |
| `--status-neutral` | `#6C757D` | 中性/数据不足 | INCONCLUSIVE、IGNORED |

#### 3.1.4 评分分级配色（动态映射）

综合评分 `score`（0-100）的颜色映射，阈值由算法配置决定，UI 需支持动态读取：

| 区间（默认） | 颜色 | 语义 |
|---|---|---|
| `score >= 80` | `--status-ok` 青绿 | 优良 |
| `60 <= score < 80` | `--status-warning` 琥珀 | 关注 |
| `score < 60` | `--status-danger` 警示红 | 低效（Bad Actor） |
| `status = INCONCLUSIVE` | `--status-neutral` 冷灰 | 数据不足，**严禁显示 0 分** |

#### 3.1.5 PV 数据质量色（v4.0 新增）

PV tag 质量码（Good/Bad/Uncertain）的视觉表达：

| 质量码 | 颜色 | 波形表现 | 标签表现 |
|---|---|---|---|
| `Good` | `--status-ok` 青绿 | PV 实线正常显示 | 绿色"Good"徽章 |
| `Bad` | `--status-neutral` 冷灰 | PV 灰色虚线断线 + 悬浮提示"PV 数据质量不可信" | 红色"Bad"徽章 |
| `Uncertain` | `--status-warning` 琥珀 | PV 琥珀色虚线 + 悬浮提示"PV 数据质量不确定" | 琥珀"Uncertain"徽章 |

### 3.2 字体系统

| Token | 值 | 用途 |
|---|---|---|
| `--font-sans` | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans SC", sans-serif` | 通用界面文字 |
| `--font-mono` | `"Monaco", "Consolas", "SFMono-Regular", monospace` | 数字、规则 ID、tag 位号、版本号 |

**等宽强制规则**：所有 `tag_name`、`loop_tag`（回路位号）、`score`、KPI 数值、时间戳、版本号、PID 参数必须使用 `--font-mono`，确保数值对齐与快速扫视。

### 3.3 字阶与层级

页面的层级由大小、粗细、间距共同表达，不只靠颜色。

| Token | 值 | 用途 |
|---|---|---|
| `--text-h1` | `24px / 700` | 页面主标题 |
| `--text-h2` | `18px / 700` | 模块/分区标题 |
| `--text-h3` | `15px / 600` | 卡片/小节标题 |
| `--text-body` | `14px / 400` | 正文数据（高密度表格可降至 13px） |
| `--text-small` | `12px / 400` | 辅助说明/标签 |

### 3.4 间距系统

采用 4px/8px spacing scale。

| Token | 值 |
|---|---|
| `--space-1` | `4px` |
| `--space-2` | `8px` |
| `--space-3` | `12px` |
| `--space-4` | `16px` |
| `--space-6` | `24px` |
| `--space-8` | `32px` |

规则：一级区块上下间距（`--space-6` 至 `--space-8`）大于区块内元素间距（`--space-2` 至 `--space-4`）。

### 3.5 圆角与阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | `4px` | 控件圆角（克制） |
| `--radius-md` | `8px` | 面板圆角 |
| `--radius-pill` | `999px` | 标签/徽章 |
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,0.05)` | 层级分离 |
| `--shadow-drawer` | `-4px 0 16px rgba(0,0,0,0.08)` | 右侧抽屉 |

**阴影只做层级分离，不做悬浮装饰。** 坚决不使用大面积重阴影。

### 3.6 动效

| 场景 | 动效 | 时长 |
|---|---|---|
| 状态更新反馈 | 全局 Toast fade-in-out | 300ms |
| 抽屉滑出 | `transform: translateX` | 250ms ease-out |
| 表格行 hover | 背景色过渡 | 150ms |
| Tag 关联拖拽放置 | 槽位高亮反馈 | 150ms |
| 配置确认弹窗 | fade-in + scale | 200ms |
| 页面切换 | 无过渡（生产系统求快） | - |

## 6. 页面设计规范

本章按 6 模块 + 门户组织，对 25 个页面逐一规范。每个页面规范包含：路由、页面结构模式、目标角色、分期、页面内容、设计要点。

### 6.1 工作台（门户）

#### 6.1.1 性能总览首页 `/`

**页面结构模式**：工作台页（上中下三行布局 + 顶部筛选栏）
**目标角色**：全角色（仪控工程师默认首页）
**分期**：Phase 1

**页面布局**：

```
+----------------------------------------------------------------------------------------+
| 顶部筛选栏：[全厂 ▼][装置 ▼][单元 ▼]  统计粒度：(•)日 ( )周 ( )月                       |
+----------------------------------------------------------------------------------------+
| 上行（20%）：KPI 卡片区（6 项）                                                          |
| [自控投用率] [平稳率] [综合评分] [报警次数] [操作频次] [好值率]                          |
+----------------------------------------------+-----------------------------------------+
| 中行左（60%）：低效回路列表                  | 中行右（40%）：选中回路摘要              |
| [位号 | 评分 | 预诊标签 | 关键指标]          | 小趋势缩略图（PV/SP/OP）                |
| [位号 | 评分 | 预诊标签 | 关键指标]          | 关键状态：MODE/PID/质量码                |
| [位号 | 评分 | 预诊标签 | 关键指标]          | 快捷动作：进入诊断 / 进入异常跟踪        |
+----------------------------------------------+-----------------------------------------+
| 下行（30%）：最近月/周关键指标组合趋势                                                  |
| 自控投用率（蓝线）+ 平稳率（绿线）双轴折线  粒度切换：(•)日 ( )小时                       |
+----------------------------------------------------------------------------------------+
```

**页面内容**：
- **顶部筛选栏**：全厂/装置/单元级联下拉 + 日/周/月单选（默认日）
- **上行 KPI 卡片区**：6 项核心指标卡片（自控投用率/平稳率/综合评分/报警次数/操作频次/好值率），每卡显示当前值 + 同比变化箭头
- **中行左**：低效回路列表（位号/评分/预诊标签/关键指标），按评分升序排列
- **中行右**：选中回路的小趋势缩略图（PV/SP/OP 三线，PV 线根据质量码断线）+ 关键状态摘要（控制方式/PID 参数/数据质量）+ 快捷动作入口
- **下行**：最近月/周关键指标组合趋势（自控投用率 + 平稳率双线），支持日/小时粒度切换

**设计要点**：
- 上中下三行高度比约 20% : 40% : 30%（剩余 10% 为筛选栏与间距）
- KPI 卡片不使用渐变/彩色 border，仅用数值大小与颜色（评分色块）传递信息
- 中行左右联动：点击左侧回路行，右侧摘要即时刷新
- 下行趋势图默认显示最近 7 天，可切换至最近 30 天
- 数据来源：`kpi_snapshot_hourly`（最新一小时快照）、`action_tracker`（待办聚合）、`st_loop_data`（小趋势）

**关键交互**：

| 触发 | 行为 | 结果 |
|---|---|---|
| 切换装置/单元筛选 | 重载 KPI 与低效列表 | 上下文保持 |
| 切换日/周/月粒度 | 重算 KPI 聚合 | 卡片数值更新 |
| 点击低效回路行 | 选中当前回路 | 中行右摘要联动刷新 |
| 点击"进入诊断" | 跳转 `/diagnosis/:loopId` | 带 `loopId` |
| 点击"进入异常跟踪" | 跳转 `/diagnosis/tracker` | 带当前回路上下文 |
| 点击 KPI 卡片 | 展开详细说明 | 展示趋势、说明和相关低性能回路 |

#### 6.2.2 回路台账 `/loop/ledger`

**页面结构模式**：数据表页（筛选 + 表格 + 抽屉）

**右侧抽屉（编辑回路）**：

- **运行态读取（只读）**：控制方式（from MODE tag）、PID 参数（from PID tag），灰色背景标注"运行态只读"
- **扩展配置（可编辑）**：评分权重、启用状态、备注
- **AAS 同步状态（只读）**：最后同步时间、tag 总数

**设计要点**：
- 运行态字段（控制方式/PID 参数）明确标注"只读，从 tag 读取"，禁止编辑控件
- Tag 关联缺失时整行标红，tooltip 提示缺失项
- 新建回路弹窗：仅基础信息字段，创建后引导至 Tag 关联管理页面

#### 6.2.3 Tag 关联管理 `/loop/mapping`

**页面结构模式**：配置页（左列表 + 右槽位）
**目标角色**：系统管理员、仪控工程师
**分期**：Phase 1

**页面布局**：

```
+----------------------------------------------+-----------------------------------------+
| 左侧（40%）：AAS 同步 Tag 列表               | 右侧（60%）：选中回路的 7 槽位关联       |
| [搜索框] [筛选：质量/关联状态]               | 回路：[选择回路 ▼]                       |
| [tag1] PV  Good  已关联回路A                 | +-------------------------------------+ |
| [tag2] SP  Good  未关联                      | | PV   (必填) [拖入或选择 tag ▼]     | |
| [tag3] OP  Good  已关联回路A                 | | SP   (必填) [拖入或选择 tag ▼]     | |
| [tag4] MODE Bad  未关联                      | | OP   (必填) [拖入或选择 tag ▼]     | |
| [tag5] PID_P Good 已关联回路A                | | MODE (必填) [拖入或选择 tag ▼]     | |
| ...                                          | | PID_P(可选) [拖入或选择 tag ▼]     | |
|                                              | | PID_I(可选) [拖入或选择 tag ▼]     | |
|                                              | | PID_D(可选) [拖入或选择 tag ▼]     | |
|                                              | +-------------------------------------+ |
|                                              | [校验状态] [保存]                       |
+----------------------------------------------+-----------------------------------------+
```

**页面内容**：
- **左侧 Tag 列表**：AAS 同步的所有 OPC tag 位号
  - 搜索框（tag 名/描述模糊查询）
  - 筛选：数据质量（Good/Bad/Uncertain）、关联状态（已关联/未关联）
  - 列：tag 名（等宽）、描述、当前值、数据质量徽章、关联回路名
- **右侧 7 槽位关联**：选中回路后展示 7 个槽位
  - **PV tag**（必填，过程测量值，含质量码）
  - **SP tag**（必填，设定值）
  - **OP tag**（必填，输出值）
  - **MODE tag**（必填，控制模式）
  - **PID_P tag**（可选，比例参数）
  - **PID_I tag**（可选，积分参数）
  - **PID_D tag**（可选，微分参数）

**设计要点**：
- 槽位支持**拖拽**（从左侧 tag 列表拖入）或**下拉选择**两种交互方式
- 必填槽位缺失时标红 + tooltip 提示"PV tag 必填"
- 已关联的 tag 在左侧列表中显示关联回路名，避免重复关联（同一 tag 可关联至多个回路，但需提示）
- 校验状态实时显示：完整（绿色）/ 缺失（红色）
- 保存前确认弹窗："确认保存 Tag 关联？变更将影响该回路的数据采集与性能评估。"

**关键交互**：

| 触发 | 行为 | 结果 |
|---|---|---|
| 拖拽 tag 至槽位 | 槽位高亮反馈（150ms） | tag 关联至槽位 |
| 下拉选择 tag | 槽位填充 | tag 关联至槽位 |
| 点击槽位清除 | 移除关联 | 槽位空缺，必填项标红 |
| 点击"校验" | 校验完整性 | 显示完整/缺失状态 |
| 点击"保存" | 弹确认弹窗 | 填写变更说明后保存，记录审计日志 |

### 7.3 时序波形 (Time-Series Waveform)

**FDS 强制约束**：诊断详情页与回路运行详情页使用上下分栏，上部为时序波形。

**技术要求**：
- 图表库：ECharts，Canvas/WebGL 渲染
- **降采样**：必须开启 LTTB 降采样，`maxPoints` 默认 2000；超 10 万点强制降采样（`ERR_TS_DOWNSAMPLE_REQ`）
- **多轴联动**：PV、SP 同一 Y 轴（主轴）；OP 独立副 Y 轴（0-100%）
- **MODE 背景带**：按 `mode` 值分段着色（Manual 红/Auto 绿/Cascade 蓝）
- **PV 质量码表达**（v4.0 关键）：
  - `Good`：PV 实线正常显示
  - `Bad`：PV 灰色虚线断线，悬浮提示"PV 数据质量不可信"，**绝不使用 0 掩盖**
  - `Uncertain`：PV 琥珀色虚线，悬浮提示"PV 数据质量不确定"
  - **SP/OP 线正常显示**，不受 PV 质量码影响
- **交互**：鼠标框选放大 (Zoom)、平移 (Pan)、十字准星联动 (Crosshair Sync)
- **时间窗**：最大跨度 30 天，超限提示 `ERR_TS_001`

### 7.9 空状态与异常状态

**空状态 (Empty)**：必须说明原因 + 提供动作入口。

- "当前时间窗无低效回路"

**Inconclusive 状态**（数据不足是一等公民，不是错误）：

**Error 状态**：
- 计算超时/内存溢出：中断批次，记录日志，触发管理员告警

## 9. 交互模式规范

### 9.1 全局交互原则

- 任何页面优先服务当前用户要完成的动作，而非展示所有信息。
- `数据不足 / Inconclusive` 是一等状态，不是错误。

- Phase 2 整定模块原型页面允许查看结构与交互演示，算法结果为 mock 数据。

- 任何主级按钮点击必须触发明确的状态流转提示。
- 采用轻量级全局 Toast（fade-in-out，300ms），不阻断操作。
- 异步任务（如 PDF 导出）显示"生成中"状态，轮询结果，不阻塞 UI。

### 9.3 上下文保持

- 列表页点击行 → 右侧抽屉，关闭后保留列表滚动位置与筛选条件。

## 10. 数据可视化规范

### 10.1 评分颜色映射

综合评分 `score`（0-100）动态映射，阈值由算法配置决定：

| 区间（默认） | 颜色 | 表现 | status 枚举（v4.1） |
|---|---|---|---|
| `>= 80` | 青绿 `--status-ok` | 优良 | `GOOD` |
| `60-79` | 琥珀 `--status-warning` | 关注 | `WARNING` |
| `< 60` | 警示红 `--status-danger` | 低效 | `POOR` |
| 数据不足 | 冷灰 `--status-neutral` | 显示"—"非 0 | `INCONCLUSIVE` |

*说明：v4.1 对齐 IDS v3.2，评分状态从仅 `SUCCESS/INCONCLUSIVE/PARTIAL` 扩展为 `GOOD/WARNING/POOR/INCONCLUSIVE` 四态，对齐§7.12 综合评分展示组件。*

### 10.2 趋势折线图

- 全厂平稳率/自控投用率趋势，ECharts 实现
- 支持时间窗切换
- 数据量大时降采样
- 十字准星联动
- 工作台首页组合趋势：自控投用率（蓝线）+ 平稳率（绿线）双轴

### 10.3 A/B 对比柱状图

- Before/After 双柱对比
- 提升标绿、下降标红
- 标注 delta 数值

### 10.4 散点图

- PV-OP 二维分布
- 散点颜色按 PV `quality` 区分（Good 实心 / Bad 半透明 / Uncertain 半透明琥珀）
- 拟合曲线叠加（椭圆/平行四边形）
- 命中规则高亮

### 10.5 PV 质量码在波形图中的处理（v4.0 关键）

**核心规则**：数据质量主要针对 PV 值，PV tag 携带质量码（Good/Bad/Uncertain）。

| 质量码 | PV 线表现 | SP/OP 线表现 | 悬浮提示 |
|---|---|---|---|
| `Good` | 实线正常显示（青绿或主色） | 正常显示 | 无 |
| `Bad` | 灰色虚线断线 | 正常显示 | "PV 数据质量不可信" |
| `Uncertain` | 琥珀色虚线 | 正常显示 | "PV 数据质量不确定" |

**实现要点**：
- PV 线根据质量码分段渲染：Good 段实线、Bad 段灰色虚线断线、Uncertain 段琥珀虚线
- SP/OP 线始终正常显示，不受 PV 质量码影响
- 质量码图例固定显示在波形区右上角
- KPI 好值率基于 PV 质量码统计（Good 时长 / 总时长）

### 13.3 错误码与 UI 响应

| 错误码 | 含义 | UI 响应 |
|---|---|---|
| `ERR_AUTH_401` | Token 失效 | 跳转登录 |

| `ERR_CONFIG_FORBIDDEN` | 越权修改配置 | Toast"仅系统管理员可修改配置" |
