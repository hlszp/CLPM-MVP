# CLPM 文案与术语词表 v1.0

> 整改 D2-c 产出（2026-08-08）。全站用户可见文案的统一事实来源；PR 检查单第 12/14 条以此为准。
> 规则：**词表未收录的新文案，先回本表登记再入库**。

## 1. 按钮动词表（强制）

| 场景 | 标准用词 | 禁用/已退役 | 说明 |
|---|---|---|---|
| 创建实体 | **新建**（新建规则/新建用户/新建报表/新建整定/新建任务） | ~~新增~~ | 一律"新建+名词" |
| 表单提交 | **保存** | ~~确定~~（作为提交动词） | Modal ok-text 用"保存"；带语义的动作用动宾短语（确认处置/确认归档/开始补齐） |
| 取消表单/弹窗 | **取消** | — | 全站统一 |
| 删除实体 | **删除** | ~~移除~~ | 危险删除必须走 `ClpmDangerConfirmModal` |
| 状态切换 | **启用 / 停用** | ~~禁用~~（对规则/配置；用户账号场景保留"禁用用户"） | 可逆操作走 Popconfirm |
| 数据刷新 | **刷新** | ~~刷新列表~~、~~重试~~ | 工具栏标准动作，图标 `refresh` |
| 导出 | **导出**（导出 CSV） | ~~下载~~ | 工具栏标准动作 |
| 事件处置流 | **确认 → 处置 → 归档**；误报 → **标记误报 / 撤销误报** | — | 预警事件专用状态机动词，不得混用"处理/解决" |
| 标签处置 | **处理 / 抑制** | — | 诊断标签专用（tag-panel） |

## 2. 页面名 = 菜单名（一一对应）

| 菜单 title | 页面标题（ClpmPageToolbar title） | 状态 |
|---|---|---|
| 系统概览 | 系统概览 | ✅ 已统一（原"工作台"同名异物已消除） |
| 回路实时 | 回路实时 | ✅ |
| 回路工作台 | 回路工作台 | ✅（路由 meta title "工作台"沿用菜单名） |

规则：新增页面时，`route.meta.title`、菜单项、`ClpmPageToolbar.title` 三处必须字面一致。

## 3. 领域术语（不得自创同义词）

| 术语 | 用法 | 禁用 |
|---|---|---|
| 位号 | 指回路/Tag 标识 | ~~位号编号/回路编号~~ 混用 |
| 回路 | control loop | ~~环路~~ |
| 自控率 | 回路 AUTO 占比 | ~~自动率~~ |
| 评估 / 诊断 / 整定 | 三个核心动作，严格区分 | 不得互替（如"评估诊断"连用） |
| 快照 | 周期性性能计算结果 | ~~截屏~~ |

## 4. 枚举与英文露出规则

- **后端枚举（THRESHOLD/DRIFT/COMPOSITE/COMPOSITE/COMPLETED…）不直接露出 UI**；界面只显示中文名（阈值/漂移/组合/可信度/已完成）。
- 例外：DSL JSON 编辑器等明确面向高级用户的键名场景，键名保留英文（对齐后端校验），但说明文案仍以中文为主。
- 严重度：紧急(URGENT)/重要(HIGH)/提示(MEDIUM/LOW) —— 映射表见 `severity-badge.vue`。

## 5. 空态与引导

- 空态三要素：原因 + 动作 + 数据范围（组件 `ClpmEmptyState`，scene 语义化）。
- 引导动词与目标页面按钮文案一致（如空态按钮"新建规则" ↔ 页头按钮"新建规则"）。

## 6. 数字与单位

- 计数一律整数（禁止"0.0 个/条"）；单位进表头不进单元格；精度按指标定义表（组件 `ClpmNumeric`）。
