## 1. 语义五色（仅服务"状态/异常/需行动"）

| Token | 值 | 语义 | 使用白名单 |
|---|---|---|---|
| `--status-ok` | `#198754` | 正常/达标/在线 | 状态徽章、异常卡片着色、图表"达标"系列 |
| `--status-warning` | `#B45309` | 警告/需关注（**文字/图标/线条用深琥珀**） | 警告文本、徽章文字、图表警示线 |
| `--status-warning-bg` | `#FEF3C7` | 警告浅底 | 徽章/标签底色（与深琥珀文字配对） |
| `--status-error` | `#DC3545` | 危险/故障/需立即行动 | 仅异常态；**禁止用于类别**（如温度 tag） |
| `--status-info` | `#0D6EFD` | 信息/进行中 | 信息徽章、处理中状态 |
| `--status-neutral` | `#6C757D` | 中性/数据不足/零值/INCONCLUSIVE | 零值、"—"、空态、E 级 |
| `--industrial-accent` | `#0D6EFD` | 主操作/当前态/链接/焦点 | 主按钮、选中态、链接、focus ring，**其余禁用** |

> 废止：`#FFC107`（浅底白字对比度不达标，拆为深琥珀文字 + 浅琥珀底两态）；ZL 原色板（#10B981/#F59E0B/#F43F5E/#3B82F6）与 antd 色系（#52c41a/#faad14/#ff4d4f）不再作为语义色使用。

## 2. 评分等级映射（UI/UX §3.1.4）

| 等级 | 色 | 说明 |
|---|---|---|
| EXCELLENT 优良（≥80） | `#198754` | |
| GOOD 良好 | `#0D6EFD` | |
| FAIR 合格/需关注（60–79） | `#B45309` | |
| POOR 低效（<60，Bad Actor） | `#DC3545` | |
| INCONCLUSIVE 数据不足 | `#6C757D` | 显示"—"，严禁 0 分 |

## 3. 可信度 A–E（UI/UX §3.1.6）

A `#198754` / B `#0D6EFD` / C `#B45309` / D `#DC3545` / E `#6C757D`。

## 4. 类别中性化（强制性）

回路类型、规则类型、指标类别、控制类型等**中性分类信息一律禁用语义色相**，统一：
`--tag-neutral-bg: #F1F5F9` 底 + `--tag-neutral-text: #475569` 文字 + `--tag-neutral-border: #E2E8F0` 边；区分靠文字/图标，不靠颜色。

## 5. 零值与无数据

零值、无数据、正常态**不着色**（用 `--status-neutral`/次文本色）；仅非零异常值按语义着色。"0"与"无数据"是两种状态，不得混用。

## 6. 图表数据线色板（现状保留，A.6/A.15 图表语言统一时再收敛）

PV `#0D6EFD` / SP `#52C41A`（虚线）/ OP `#FA8C16` / MODE `#722ED1`；无效段灰虚线；正常区间灰带 markArea。

## 7. 暗色映射

`useClpmTheme()` 的 DARK 色板随暗色切换（当前为亮度提升的 400 级近似值，E2 暗色校准专项统一复核对比度后定稿）。

## 8. 使用纪律

1. 同屏色相 ≤4（含 accent）；
2. 每处用色必须能回答"这个颜色在告诉我什么"；
3. 状态表达 = 颜色 + 图标 + 文字三维（UI/UX §7.2），绝不只靠颜色；
4. 新色值先进本表再进代码；
5. 装饰性用色（侧条、彩虹、渐变）禁止。
