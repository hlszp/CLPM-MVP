## 一【P4-03 scope 贯穿查询、任务、实时推送与缓存】

### 【1 必读】
AGENTS.md；03 号文 §7 P4-03 卡（C25=验收正本）；01§3.5；`P4-01-交接.md`+`P4-02t-交接.md`（目录/授权消费已落——本卡数据范围维度）；现行代码：plant 层级查询、loop/performance/workbench/diagnosis/tuning/handling/report 服务与任务、`agg_cache.py`、`endpoints/{realtime,ws_realtime,ws_alert}.py`、`models/{tag,loop,plant_node}.py` 绑定查询、输入包下载、`tasks/{tuning,diagnosis_v2}.py`+`diagnosis_orchestrator.py` 写结果链。

### 【2 范围】
1. **ALL/NODE_SUBTREE 与筛选取交集**；批量/关联校验（跨 scope 对象拒绝）；01§3.5 tag 归属/共享/未绑定/旧客户端规则。
2. **WS 三件套**（realtime/ws_realtime/ws_alert）：握手/订阅/分发各自动作登记+连接主体/令牌状态校验；发送批前重验+过滤+清缓冲+发送栅栏；旧客户端未订阅规则。
3. **运行中任务栅栏**：人工任务主体绑定、每对象与提交前复核、锁策略 revision 的提交栅栏、结果/建议 outbox 同事务+发送再验；SYSTEM 独立 identity。
4. **缓存**：key 授权 hash+revision；原包下载同 scope；全厂缓存不越界。
5. **撤权语义**（C25 核心）：连接内降权/禁用/重置后无新越权帧（不靠前端退订）；排队/运行中任务降权/移除节点/禁用——暂停提交前→撤权完成→恢复无新结果/模型/建议（仅 REVOKED 审计）；撤权与提交并发可线性排序。
6. **策略变更纳入 revision 与栅栏**（角色/范围/禁用/节点/tag 改绑）。

### 【3 纪律】
唯一 worktree（p403）；P0/P4 契约冻结全部策略变更者及固定锁顺序；模型变更与迁移同批；真实 Worker/WS 试验（隔离 broker——禁与 dev 共 broker 抢任务）；C25 端到端并发负例必须真实（禁 mock 替代——14 号文口径）；30 分钟交接；不 commit/push。

### 【4 核验】
C25 全反例（A/B 节点全 HTTP 入口+原始 tag+直接 WS 正反例；共享/无绑定 tag；未订阅旧客户端；预警推送不泄漏 B；连接内降权后无越权帧；排队/运行中任务撤权；提交栅栏并发；缓存/下载不越界）；scope 贯穿清单逐 HTTP/WS 登记；门禁全量真实退出码。

### 【5 决策点】
锁顺序/schema 歧义→Owner 定稿记录；实质范围变化→停点报主协调。

## 二【P4-04 配置 UI、有效权限解释与在线变更】

### 【1 必读】
AGENTS.md；03 号文 §7 P4-04 卡；`P4-01-交接.md`（目录/矩阵/409/回退 API 已备）；`P4-02t-交接.md`（/auth/me 动作码已落）；**api-contract-allowlist.json 25 端点（本卡接通前端消费后逐条移除——登记）**；09 号文 §3（IA 契约）；现行代码：`views/system/permissions.vue`（若存在骨架）、`views/system/users.vue`、auth store、`authz_runtime.py`（revision 比对已落——本卡消费）、配置发布链（P2-02 五层——**本卡不含配置发布 UI**，那是 P6-04 工程模板系；P4-04=**授权配置 UI**）。

### 【2 范围】
1. **授权配置页**：角色列表/页面树/动作清单/scope（ALL/NODE_SUBTREE+节点选择）/差异预览/审计/回退——消费 P4-01 API（catalog/revisions/roles/users/rollback——**移除 allowlist 对应登记**）。
2. **替换静态矩阵**：管理员保存→409 处理→审计追溯。
3. **在线生效**：变更后版本刷新（广播或轮询——P2-02 模式复用+P4-01 策略 revision 已落）；无权 tab 撤离；最低下一路由/动作前刷新；活跃会话轮询 ≤30s；双会话无重登在线生效。
4. **有效权限解释**：与实际 403 一致（解释器=authz_runtime 同源）。
5. **失权清理**：订阅/缓存/抽屉清订阅——不清用户无关工作。
6. 用户页 scope 编辑（users/*/scope API）。

### 【3 纪律】
唯一 worktree（p404）；前端现役区（system 系非禁改区）；复用 authz_runtime/P4-01 API 不分叉；allowlist 移除同批（api_contract 测试同步）；模型变更与迁移同批如需；30 分钟交接；不 commit/push。

### 【4 核验】
管理员保存→另一会话无重登更新（双浏览器/双 token 实测）；API 下一请求即时校验；UI ≤30s 或下一交互前生效；权限解释与 403 一致；失权清理；allowlist 移除后 contract 测试过；门禁三件套+后端。

### 【5 决策点】
UI 布局歧义→按 09 号文 IA 契约；其他停点报主协调。
