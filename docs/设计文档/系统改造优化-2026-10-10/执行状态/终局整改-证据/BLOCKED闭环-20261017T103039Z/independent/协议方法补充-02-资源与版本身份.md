# 投前方法补充02：冻结资源上界与版本映射

本补充在任何正式批次之前记录。原`冻结验收协议.md`及四工具源字节保持，不改20批/每批1000/九条件/600s、历史6+3、四用户豁免或G6/G7=CONDITIONAL_PASS。

资源固定口径为三容器（整个PG、TD、专属Redis）各自`cgroup memory.current`全charge之和，加宿主API/Worker master/全部4 pool/暂停Beat的PID RSS。容器PID不重复加，anon/shmem仅分列，不再相加。这是保守内存上界，包含容器page cache，不宣称精确物理RSS。预算6GiB，逐点上界≤5153960755字节（80%向下取整），Docker VM MemAvailable≥1GiB；严格0<采样间隔≤5s、投前≥60s、各批屏障后≥30s、series末另采≥300s。缺PID/容器/原始OOM字段或日志不能自动PASS，失败后不扩大预算或换低口径。

`independent_resource_accounting.py`直接读原resources JSONL中的cgroup命令原stdout第一行与OOM原计数、ps原行RSS、VM meminfo原文，独立重算；不调用Keeper的validator，也不运行Docker/ps/API/DB。摘要memoryCurrentBytes只交叉校验，不能覆盖原值。具体容器/PID加载身份、CPU/IO/连接、资源日志、冷热与逐回路HIT仍另核，单凭算术结果不签最终容量。

`verify_capacity_series_frozen_profile.py`继承原九条件复算器，仅替换旧RSS资源方法，使用上述独立上界。**不把memory.current伪装为rssBytes。** 单批`resources`侧车改为：

```json
{
  "accountingMethod": "CgroupCurrentPlusHostPIDRSS-v1",
  "profile": {"path": "冻结resource-profile-plan.json", "sha256": "原字节SHA"},
  "runtimeProfile": {"path": "每批runtime-profile/runtime-profile.json", "sha256": "原字节SHA"},
  "resourcesJsonl": {"path": "每批raw/resources.jsonl", "sha256": "原字节SHA"},
  "rawRefs": ["以上与原始身份/配置引用，均用path/sha256对象"]
}
```

其余原九条件/1000/窗口/NODE实际输入record/父子任务/原manifest/freeze/历史6+3合同不变。所有JSONL/gzip映射必须保留原件与字段来源；实际完整数据适配仍待Keeper正式原件，不以摘要布尔值填事实。命令同旧工具，入口换为`verify_capacity_series_frozen_profile.py`。单独资源算术CLI接受plan.resourceProfile/runtimeProfile/resourcesJsonl三个SHA引用及submittedAt/terminalAt，末300s则另设recoverySeconds≥300。

新增工具自验见`resource-accounting-check-v2/`：9例/0/真实rc0，format/lint0，含闭式求和、anon/shmem不重复加、摘要低报不能覆盖原值、缺OOM、OOM、缺PID/容器、新Worker、倒序/重复/>5s、可用内存下限与预算不可放宽、侧车引用。原8例版本精确源另存在`resource-accounting-check/sources-v1/`，新源身份在v2/source-identity.json。恢复器另10例通过，原20例准备不重复扩签业务。

版本合同：正式容量固定实际PR merge checkout M；CI同时登记head与实际checkout SHA/parents，输入包/CLPM_BUILD_CODE_SHA与其实际执行身份相符。之后仅文档提交、新CI merge、最终main、最终测试部署均是不同身份，不改写成同SHA。容量资格仅可凭全tracked diff原件、产品/测试/CI/脚本/迁移/引导SQL/deploy树和实际执行E工具SHA严格等价，以及ignored.env/taos/schema/config/input/resource身份不变继承。不能把docs下可执行工具也算作普通文档豁免。最终head再跑完整CI，真实四例及数值/血缘重新独立核；合main后再核真实部署SHA、树和唯一进程。生产不动，D04未跑项不扩签。
