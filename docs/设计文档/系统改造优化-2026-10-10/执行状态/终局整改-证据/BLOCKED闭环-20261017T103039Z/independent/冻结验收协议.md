2. 先核全部 workflow 触发和部署条件，排除生产部署。CI 的 critical job/steps 无 `continue-on-error`；必须安装 e2e 自身锁文件依赖，临时 PG/Redis/TD 三服务及库归该 job；准备器隔离 guard、实际参数和退出码真实留存，不在共享本地伪造 GITHUB_ACTIONS 执行业务。

6. 非作者独立解析所有四例 JSON 与任务/血缘/数值原件，核步骤退出码对远端结论的传播；经 Keeper 对专属环境授权后补相称真实请求/反证。未获写入授权时不投业务，仅核原始证据，不能声称已独立重跑。

### 4.4 F03 判定

**PASS**：冻结候选的真实四例一次全过，结构化分母严格符合；独立算法 oracle 一致；任务→记录→输入/配置→UI 证据链完整；同 SHA 的真实 GitHub required job/检查成功且原始日志/artifact 可恢复，关键失败不得非阻塞；必要独立复核完成。

**REWORK**：有可复现业务/权限/计算/血缘/门禁漏检，或真实远端关键步骤失败却绿灯；给 exact case、请求、rc、record/run ID、文件路径及反例，退作者修，不采纳口头解释。

**BLOCKED**：只完成 static/contract/mock/test-probe/本地套件、没有真实远端 run、输入/profile/config 或必要 artifact 无法恢复、候选版本/隔离服务不明。四例过而数值 oracle 未核也不能整体 PASS。
