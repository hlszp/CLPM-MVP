**①确定性终态失败及时退出 vs pending/未完成仍等待**（`_terminal_failure_reason`，kpi_capacity_benchmark.py:874-896）：

**③RUNNING 语义**：
- `done = gate["ok"]`（九条件全真才算过）；`sloPassed = done and elapsed <= slo`；`return 0 if slo_passed else 1`——RUNNING 态任何路径都不会置 done/sloPassed 为真。

**④BARRIER_PASSED 与 sloPassed 分立**：`completion_reason="BARRIER_PASSED" if done else ...` 与 `sloPassed: done and elapsed<=slo_seconds` 为两个独立字段；屏障过而超 SLO → exit 1 + completionReason=BARRIER_PASSED + sloPassed=false，不互相覆盖。
