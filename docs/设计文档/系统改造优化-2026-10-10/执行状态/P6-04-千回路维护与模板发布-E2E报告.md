### 2.3 版本回退路径实测（自建 E2E 模板上，安全）

```
POST /engineering-templates/{id}/versions          → v2 发布，revision=2，rollbackRevision=1
GET  /engineering-templates/{id}                   → currentVersion=2，版本历史 2 行
POST /engineering-templates/{id}/versions/1/rollback（reason="…回退 v1 基线"）
   → revision=3，version=1，rollbackRevision=2
回拨后：currentVersion=1；版本历史仍 2 行（v1、v2 均在，历史不删改）
账本：R1→R2→R3 三行链完整，R3 为回拨行
```

结论：**版本回退真实可达且语义正确**（指针回拨+账本追加，非删除）。生产配置回退未执行（纪律），入口存在性已在 UI 核验。

  - **按任务纪律未点执行**，返回修改后关闭。

### 3.2 API 千回路 dry-run（5 批 ×200）

首次关联由 API 完成（`updates.engineeringTemplateId`，follow 模式）：

| 批次 | 规模 | 耗时 | affected | results |
|---|---|---|---|---|
| 1~5 | 200/批 | 30~50ms/批 | 200/批 | 200 条/批 |
| 6（失败构造批） | 2 个不存在 UUID | 20ms | 0 | 2 条 NOT_FOUND |

- **总耗时 0.19s，合并明细 1002 条：OK=1000、NOT_FOUND=2**——逐回路明细无截断、无静默丢失。
- OK 条目明细样例：`{"tagName":"PERF-T0007","status":"OK","changes":[{"field":"engineering_template_id","before":null,"after":"dc443bf9-…"}]}`。
- 失败项形态：`{"status":"NOT_FOUND","changes":[],"error":"回路不存在"}`——失败项有独立状态+错误文案，UI 弹窗以红色 Tag+错误文本呈现（颜色之外有文字，A20 口径）。
- 附带验证：向批内追加 2 个 ID 使其达 202 条时后端 422——**单批 ≤200 的 schemas 防线真实生效**。
- **零写入验证**：dry-run 后随机抽 10 回路 `GET /loops/{id}`，engineeringTemplateId 全部仍为 null → PASS。
- **重复 dry-run 幂等**：执行后对同范围再 dry-run → 200 条全 UNCHANGED、affected=0（"无差异跳过"语义正确）。

### 3.3 真实执行与明细核对（PERF-T 合成回路，已登记）

- 执行 5 批 ×200（dryRun=false）：**0.32s 完成，1000/1000 OK**。
- **抽样核对（≥10）**：随机 10 回路，dry-run 预告（changes.before/after）↔ 执行结果（status/明细）↔ 关联视图 `GET /engineering-templates/{id}/loops?limit=200`（total=1000，返回 ID 全部属于 PERF-T 集合）三方一致。
- 注：`GET /loops/{id}` 详情（basicInfo）**不序列化 engineeringTemplateId/engineeringTemplateVersion 字段**，抽样核对改经模板关联回路端点完成（该缺口登记为 DEF-3）。

### 3.4 回路侧回退路径（批维护"回退"维度）

- 版本层回退：完整可用（§2.3）。
- **批量解除关联**：`updates.engineeringTemplateId=null` 被校验拒绝（updates 全 None → 422）；空字符串 → 422（UUID 校验）。即 batch-config 语义 None=不更新，**无清空通路**。
- 单回路更新 API（schemas/loop.py：`engineeringTemplateId…NULL=未关联`）支持置空，但回路编辑抽屉 UI 无该字段（`views/loop/` 全目录 grep 无 engineeringTemplate）。
- **判定**：千回路批量关联的"回退"只能换绑到另一模板，或逐回路走 API 解除——批量回退路径不完整。
