## 1. 新增语义需求（字段名为待 Owner 对齐的设计，并非已实现 API）

| 层 | 必须保存的内容 |
|---|---|
| 完整分析输入 | 所有有效连续段及逐槽质量/mask、PV/SP/OP/MODE、PID 版本、实际时间轴、量程/单位、OP 限幅、采样与预处理版本；**不只保存最终胜出片段** |
| 段与事件目录 | `segmentId/eventId/tsStart/tsEnd/mode/regimeId/pidVersion/sampleInterval`；工况未知显式标记，不能自动伪填工况身份 |
| 搜索审计 | 被检查、选中、拒绝、未搜索的窗口与原因；计算预算终止状态；不同片段的初始状态/偏置分别保留 |
| 估计与分割身份 | 估计器 profile、模型结构、物理时滞范围与边界命中、train/selection-validation/final-test 的快照或片段引用 |
| 结果证据 | 预测指标/自由仿真指标分别存储、终验可用状态、不确定性方法/区间、适用工况、可辨识/已验证/可整定资格及原因 |
| 来源链 | `datasetSnapshotId/inputHash/resultRecordId/algorithmVersion/executableBuildDigest/modelVersionId/dcsTemplateRevision` 沿用现有设计，最终方案绑定实际模型版本与终验数据 |

## 2. 结构决策点（P2-03 Owner 定稿）

- 一个输入包内分段 **或** 多个固定输入包引用——选择与 P2-03 存储契约一致的实现；**不得跨 gap 连成等距连续曲线**。
- P2 保存版本化载体和真实输入身份；具体估计器输出由 P3 填入，未运行的字段明确为空/未计算。

## 3. 验收子例（并入 C12b，实施时展开为测试）

C12b-ID：600 点安静段＋gap＋399 点激励段；保存全部输入与选择审计 → 激励段不被丢弃、旧版本输入完整重放、不拼 gap；模型胜出片段变化不丢原搜索输入；独立终验引用可重放；同绑定改 SP/MODE/PID/质量也改变身份；旧包按旧 schema/构建复现，缺包/构建显式拒绝。

## 4. 配套纪律

- 参数需求列入待冻结清单（物理时滞范围/选窗时间尺度/候选结构/方法 profile/重采样规则/候选与计算预算）——**具体默认值和上下限在 P3 独立参考与预算证据齐备后冻结；P2 不据 07 报告临时改变 1% 激励阈值、可信度或默认算法**
- 新辨识配置接 P2-01 同一注册机制（类型/单位/合法范围/适用估计器/内部 vs 业务属性）；未实现的键不伪装可消费配置
- P2-04 补工程事实：控制作用方向、实际 OP 上下限、PID 表示与时间单位；未知 DCS 型号不得默认成标准 kp/ti/td（转换与算法消费在 P3-03 完成）
- 历史片段辨识资格与当前 PID 应用资格分别定义；原 L0/L1 门禁、权限与人工实施边界保留
