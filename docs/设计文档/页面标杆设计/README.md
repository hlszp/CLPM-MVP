## 给编程智能体的实施规则

1. **总纲 §11 是全页面强制规则**：数据诚实（溯源清单/文字三级来源/阈值禁硬编码/中文五档定级）、指标语义（正负向图形语义相反/实时点值两位小数等宽）、时间窗三层语义、布局密度、千级检索、动作与安全——逐条遵循；
2. **标杆文档即契约**：页面子目录内设计文档的 §1（一页纸契约）与 §2.5（指标溯源清单）是验收依据；凡溯源清单未列的取数方式（手算、硬编码、mock）均视为缺陷；
3. **先修断点再改布局**：[00-前置核查报告](./00-前置-FP-P0代码只读核查报告-2026-08-12.md) 中的断点（如 FP-P0-01 nextAction 空 break、FP-P0-02 时间线未绑定）是"后端已对、前端没接"，优先于任何视觉调整；
4. **fixture 验收**：实施完成后必须按设计文档走查剧本（真实数据 fixture 下的场景）逐项核对，不接受自评；
5. **不越界**：平台只读 DCS、不下写参数；整定动作仅输出建议与留痕。
