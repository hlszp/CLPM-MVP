## 4. 遇到的问题及解决方案

| 4 | TDengine SQL 注入（P0） | 添加 _validate_tag_name + _validate_time 校验函数 |
| 5 | pnpm audit 镜像源不支持 | 使用 npmmirror 镜像，通过 overrides 修复已知漏洞 |
| 5 | Celery 模块路径 | 实际路径 app.tasks.celery_app（非 app.celery_app），已修正 docker-compose |
| 6 | E2E fixture localStorage key 含版本号 | 采用扫描 `-core-access` 后缀 key 策略 |
