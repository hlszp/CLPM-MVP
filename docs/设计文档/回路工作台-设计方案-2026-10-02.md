## 4. 旅程状态条与缩略卡（入口层）

- **旅程条**：四段=评估→诊断→整定→处置，每段=环节名+时间点+最新结果摘要（评估：得分/等级/Δ+失分摘要；诊断：主分类/严重度/置信/复核态；整定：方案状态；处置：在办工单）；段间箭头；**推荐下一步**呼吸标（nextAction 逻辑迁入）；左侧"回路旅程 + 数据截至 {时钟}"。点击段→`openSection(sec)`。段=**状态与导航合一**，全页唯一剖面切换机制（分屏条按钮只管画布/工作区分屏，不切剖面）。
- **缩略卡**：四张微缩卡（评估：得分+迷你走势；诊断：主分类+置信；整定：方案+推荐 PID；处置：在办数+建议计数），常驻底部，点击展开工作区到对应剖面。
- **数据来源**：并行直调（见 §11 矩阵），**不复用** `/monitor/loops/{id}/summary`（其 diagnosis/tuning 段被后端硬编码 None，`workbench_summary.py`），**不复用**工作台 A-01~A-04 聚合（LOOP scope=全厂，`workbench_diagnosis.py` 显式旁路）。

## 5. 监视趋势图技术规格

### 5.1 数据模型（生产映射，防走样重点）

原型用"连续信号函数 + 视口按需采样"演示。**生产实现严禁搬运演示信号函数**，映射关系：

| 原型概念 | 生产实现 |
|---|---|
| 连续信号 `pvAt/spAt/opAt/qAt/modeAt` | 历史窗口：`GET /loops/{id}/monitor` 全档位统一取数（trendWindow 预设含 12H/7D；自定义档走同端点 tsStart/tsEnd；2026-10-09 v3.5 起不再走 waveform），取数后前端二次降采样到 3600 点；**实时**：WS `/ws/realtime` 订阅推送追加 |
| 视口采样 `dt=span/3600` | 对 API 返回序列做插值/聚合到 3600 点（前端工具函数，供缩放平移重采样复用） |
| 事件锚点（诊断/整定/验证） | `runs/latest`、`tuning/tasks`、`orders` 的时间戳换算为视口百分比 |
| MANUAL/质量码段 | 监测数据质量码字段 + MODE 推送历史（若后端无 MODE 历史，先以实时 MODE 渲染当下段，历史段留接口） |

### 5.2 渲染规格

- 每次绘制恒采样 **3600 点**（`dt=span/3600`）；视口 `viewX={t0,t1}`⊂数据域 `XDOMAIN`，`viewY`⊂`YDOMAIN`。
- **包络渲染**：振荡主周期像素长 `pw/(span/周期)` <12px 时，PV/OP 自动切换逐像素列 min/max 包络带（半透明填充），防混叠梳齿；放大后自动回到波形线。
- 系列：PV（蓝 #1677ff）、SP（绿 #13a876）、OP（紫 #7b61ff，右轴 20–80%）、MODE 背景带（AUTO 不着色/MANUAL 红色带+虚线边界）、质量码（BAD=灰虚线段、UNCERTAIN=琥珀点划段，白色垫层断开蓝线）。
- 轴：Y 主轴 niceStep 网格；X 刻度 5 档，跨度 ≤1.2 天用时钟 HH:MM，否则相对 `-xD`；末刻度实时="现在"/历史="截至"。

### 5.3 交互规格

- **历史/实时切换**（工具栏最左）：实时每 1.2s 追加点并右推（每 tick 推进窗口 1/150），头部 PV/SP/OP 与"数据截至"时钟联动，末刻度="现在"；窗口组 **1H/2H/4H/8H/12H/24H/3D/7D/自定义** 双模式生效（自定义=占位，正式版做起止选择器）。
- **滚动条**：底部=X 轴、右侧=Y 轴；中键平移、两端 14%/86% 区拉伸缩放；图表区滚轮缩放（因子 1.15，光标中心）、Shift+滚轮缩 Y、双击复位。X 最小跨度 60s，Y 最小 0.5。
- **事件标注层**：趋势图上方独立**固定 26px 层**（迷你态 22px），不随趋势压缩变形；徽标=白底描边圆角 pill+指示三角，按时间百分比定位，超界钳制 7%–93%；内容=▼诊断/◆整定/▮验证（锚定叙事时间：昨16:20/今06:40/昨22:10）+「⏸ 手动」段徽标；点击徽标→对应剖面（见 §8 动线）。

## 6. 四剖面内容规格

各剖面=动作条（剖面名+主动作+状态徽章+收起）+ 内容区（内滚）。摘要卡右上角统一 **↗ 角标**打开对应抽屉（§8）。

1. **性能评估**：动作条（发起评估[整点回算/自定义时段双模]、来源筛选 全部/自动/手动/重算）+ 最新得分卡（↗）+ 可信度/血缘卡 + 评估历史表（时间/得分/等级/来源/窗口/状态/操作：详情、诊断此窗→切诊断剖面并预填时间窗）。历史=三来源汇聚（D6，缺口见 §12）。
2. **回路诊断**：动作条（发起诊断[默认 24h+full，高级折叠：时间窗/算子细选]、precheck 徽标、L0~L4 门禁、异步进度）+ 最新结论卡（↗）+ 负向指标条 + 诊断历史表（行详情→抽屉）+ 结论演变时间线（loop-archive 数据）。
3. **参数整定**：当前 PID vs 推荐方案 vs 模型卡（推荐卡 ↗=效果验证抽屉）+ 四步流水（①辨识 ✓→②矩阵→③仿真→④确认，迁 `use-tuning-workbench`+四 section 组件，ctx 模式无页面耦合）+ 闭环仿真图 + 候选方案对比表；动作条含「效果验证」按钮；④确认后「创建处置项」为**页内弹窗**（零跳转）。
4. **问题处置**：建议表（5 态，页内通过/驳回）+ 工单时间线卡（↗）+ 创建处置项弹窗（来源：诊断建议/整定确认/手工）。
