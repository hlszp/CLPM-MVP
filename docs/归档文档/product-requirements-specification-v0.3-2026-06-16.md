# 危化企业控制回路性能评估与优化平台产品需求规格书

日期：2026-06-16
版本：v0.3
基线：`product-requirements-specification-v0.2-2026-06-16.md`
依据：`GB/T 44693.1-2024`、`GB/T 44693.2-2024`、`DB32/T 4822-2024`、应急管理部“工业互联网+危化安全生产”试点建设方案、`AQ 3064.1—2025`、新增竞品手册评估结果、用户正式招标需求 `1.1.1 PID性能评估与整定系统`

## 1. 版本说明

v0.3 在 v0.2 基础上进一步形成“招标响应版 PRS”，重点补齐正式招标需求中的项目实施范围、专家整定服务、模型辨识、闭环仿真、交互式整定、迁移学习、5 年 WEB 查询和验收目标。

主要变化：

- 明确项目实施范围为气化、变换及热回收、低温甲醇洗、液氮洗、氨合成、PSA 制氢、CO 分离及压缩、硫回收制酸、冷冻站、甲醇装置、醋酸装置，共 `1200` 个控制回路。
- 将软件部署、培训、PID 参数专家整定服务纳入产品交付和项目验收范围。
- 将历史在线查询从“近三年”调整为“项目实施后 5 年内任意时间段、任意单元、任意回路查询、排序和评比”。
- 将报警次数、操作频次、单回路高级报告、整定仿真验证提升为 P0。
- 新增过程模型辨识、模型质量评价、模型版本管理、闭环阶跃响应、闭环频域响应、数据激励指数、整定结果可信度。
- 新增交互式 PID 整定、专家经验库、趋势线法、特征点法、多轮迭代整定和迁移学习整定建议。
- 新增过程扰动、分布式振荡、非线性程度、阀门幅值、粘滞状况等招标指标和故障类型。
- 新增装置自控率 `>=95%` 的项目验收目标，并明确仪表阀门异常和工艺原因的例外剔除规则。

## 2. 产品定位

本产品定位为“危化企业控制回路性能评估与优化平台”，面向已采用 `DCS` 或其他 `BPCS` 实施连续生产过程控制的危化、化工、石化、煤化工等企业，提供控制回路台账治理、数据采集、性能评估、性能评分、性能定级、问题诊断、PID 参数优化建议、变更审核、实施复评、报表考核和工艺平稳性管理支撑能力。

本产品同时支持项目制交付：完成软件部署、回路清单治理、批量评估、专家整定服务、培训、验收报告和持续运维支撑。

本产品不定位为单机版 PID 调参软件，也不在首版定位为自动向 DCS 批量下写参数的闭环控制系统。首版坚持旁路只读、专家审核、人工确认更新、审计留痕。模型辨识、闭环仿真、交互式整定和迁移学习结果均作为专家审核依据，不直接自动下写 DCS。

产品主线：

`数据接入 -> 台账/投用定义 -> 指标计算 -> 评分定级 -> 诊断排行 -> 模型辨识 -> 整定仿真 -> 专家审核 -> 变更实施 -> 复评验收 -> 管理评审`

## 3. 建设目标

### 3.1 业务目标

- 支撑危化企业落实工艺平稳性和控制回路性能评估要求。
- 建立企业级、装置级、回路组、回路级控制绩效指标体系。
- 识别自控率低、有效自控率低、平稳率低、准确率低、快速率低、振荡、阀门异常、仪表异常、回路耦合、数据异常等问题。
- 形成可审核、可追踪、可复盘的 PID 参数优化与控制回路变更流程。
- 支撑工艺平稳性绩效监测、内部审核、管理评审、持续改进。
- 将控制回路优化能力纳入企业安全风险智能化管控平台。
- 支撑 1200 个控制回路规模的项目实施、专家整定、培训和验收交付。
- 通过性能评估与参数整定，支撑装置自控率目标达到 `>=95%`，仪表阀门异常和工艺原因除外。

### 3.2 产品目标

- 建立 DCS/BPCS 回路自动识别与台账治理能力。
- 原生计算 `GB/T 44693.2-2024` 与 `DB32/T 4822-2024` 的关键指标。
- 支持控制回路性能评分、性能定级和低性能回路分级管理。
- 支持不参与统计回路管理、评估周期管理、未投用原因分析和装置级考核报表。
- 支持离线和在线 PID 参数优化建议、过程模型辨识、闭环响应仿真和整定可信度评价，但首版不自动下写。
- 支持历史数据不足或激励不足场景下的交互式整定、趋势线法、特征点法和相似回路迁移建议。
- 支持参数变更的工艺、仪表、安全多角色审核。
- 支持项目实施后 5 年内评估指标在线查询和至少五年数据留存策略。

### 3.3 成功指标

- 回路自动识别准确率：首版目标 `>=90%`，人工修正后台账完整率 `>=99%`。
- 指标计算可追溯性：每个 KPI 可追溯到采样数据、统计周期、排除规则、计算公式、公式版本和阈值版本。
- 标准报告完整性：报告字段满足 `GB/T 44693.2-2024` 附录 H 的最小内容集。
- 报告生成效率：装置月度评估报告可在 `10 分钟` 内生成。
- 优化闭环率：可优化回路中完成审核、实施、复评的比例可统计。
- 安全策略：首版默认不向 DCS 自动下写 PID 参数。
- 招标项目覆盖度：支持 11 类装置、`1200` 个控制回路的清单、评估、整定和验收状态管理。
- 自控率验收目标：装置自控率 `>=95%`，并可输出仪表阀门异常和工艺原因例外清单。
- 整定分析完整性：每个进入整定流程的回路应输出辨识模型、建议参数、整定可信度、数据激励指数、闭环阶跃响应和频域响应分析。
- 培训交付完整性：培训对象、培训内容、签到、资料、考核和问题反馈可归档。

## 4. 用户与场景

### 4.1 用户角色

| 角色 | 核心关注 | 典型操作 |
|---|---|---|
| 工艺管理部门/生产技术部门 | 工艺平稳性目标、绩效评价、管理评审 | 查看绩效指标、审核整改情况、组织管理评审 |
| 工艺工程师 | 工况稳定、质量波动、负荷扰动、工艺约束 | 查看平稳率、准确率、快速率，确认优化建议是否符合工艺约束 |
| 仪表控制工程师 | 回路性能、PID 参数、阀门/仪表问题 | 配置回路、分析振荡、生成整定建议、实施参数变更 |
| 生产运行人员 | 当前装置状态、报警与波动 | 查看异常回路、确认操作影响、记录运行情况 |
| 安全管理人员 | 工艺平稳性、安全风险前移识别 | 查看关键回路异常、整改闭环、审计记录 |
| 信息化/OT 运维人员 | 数据接入、网络隔离、系统可用性 | 配置 OPC、权限、存储、备份、接口 |
| 企业管理层 | 装置考核、整改进度、经济影响 | 查看装置排行、趋势、月报、整改率 |
| 第三方运维服务商 | 持续服务、专家诊断、优化复评 | 批量诊断、出具服务报告、跟踪实施效果 |
| 项目实施与专家服务团队 | 项目部署、回路交付、培训、专家整定、验收 | 管理实施进度、执行专家整定、输出服务报告和验收包 |

### 4.2 核心场景

1. 月度工艺平稳性评估

企业按装置统计自控率、有效自控率、平稳率、性能评分和周期指标，识别不达标装置和重点回路，形成整改清单。

2. 低性能回路诊断

仪表控制工程师从性能等级、自控率、有效自控率、振荡率、黏滞系数、饱和率、好值率、相关性指数等维度筛选回路，系统给出可能原因和证据。

3. PID 参数优化

系统基于历史数据或在线数据识别对象特性，生成 PID 参数建议，经工艺、仪表、安全人员确认后，由仪表控制工程师手动更新到 DCS。

4. 闭环仿真与专家整定

仪表控制工程师或专家服务人员基于辨识模型和建议参数进行闭环响应仿真，查看阶跃响应、频域响应、数据激励指数和整定可信度，形成可审核的整定建议。

5. 交互式整定

对于历史数据不足、数据激励不足或模型辨识效果不佳的回路，系统通过专家经验库、趋势线法、特征点法和用户特征评价进行多轮交互式整定。

6. 控制回路变更管理

涉及组态变动、控制计算机系统软件升级、控制回路相关仪表设备新增、拆除、停用、PID 参数调整时，系统进入变更流程并留存记录。

7. 工艺平稳性管理评审

企业定期查看工艺平稳性绩效指标、以往问题整改情况、低性能回路趋势和改进建议，形成管理评审输入。

8. 安全风险联动

关键回路持续失稳、长时间手动、执行机构饱和、数据异常、报警频繁等情况进入企业安全风险智能化管控平台，联动报警优化、设备完整性和隐患整改。

9. 项目验收交付

项目团队按装置和回路形成交付清单，输出软件部署记录、培训记录、回路评估报告、PID 专家整定服务报告、复评结果和验收包。

## 5. 范围

### 5.1 首版范围

- 项目实施范围支持气化、变换及热回收、低温甲醇洗、液氮洗、氨合成、PSA 制氢、CO 分离及压缩、硫回收制酸、冷冻站、甲醇装置、醋酸装置等 11 类装置，共 `1200` 个控制回路。
- DCS/BPCS 数据只读接入。
- OPC DA、OPC UA、OPC AE 接入。
- OPC 冗余配置、连接测试和常见故障诊断。
- 回路台账自动识别与人工校核。
- 厂级、装置级、回路组、回路四级结构。
- 投用定义、设备模板、位号后缀模板、可信质量码、采样周期配置。
- 控制回路性能指标计算、性能评分、性能定级。
- 异常诊断、低性能回路排行和多指标综合诊断。
- PID 参数整定建议、过程模型辨识、闭环响应仿真、频域响应分析、整定可信度评价。
- 历史数据不足场景下的交互式 PID 整定和相似回路迁移建议。
- 控制回路变更、审核、实施记录、复评闭环。
- 日报、周报、月报、年报、自定义报告和标准报告导出。
- 角色权限、审计日志、项目实施后 5 年内在线历史查询和至少五年数据留存策略。
- 软件部署、培训记录、专家整定服务报告和项目验收包。

### 5.2 首版不做

- 自动批量下写 DCS 参数。
- 无人工审核的在线闭环自整定。
- 全量 APC、RTO、MPC 建模平台。
- 替代 DCS、SIS、报警管理系统。
- 面向离散制造的通用控制优化。
- 不可解释的黑盒整定决策；迁移学习必须输出相似性依据、可信度和人工确认要求。

### 5.3 后续扩展

- PI、PHD、实时数据库和工业数据湖接口。
- 阀门定位器、智能仪表、设备完整性系统接入。
- 报警优化模块联动。
- 联锁投用、工艺参数波动、报警绩效等工艺平稳性扩展指标。
- 18 种重点监管危险化工工艺模板库。
- 多工况参数库和操作分区域参数推荐。
- 高保真动态仿真、仿真回放与变更前风险评估。
- 边缘计算节点和跨厂区集团驾驶舱。

### 8.2 指标口径

| 指标 | 口径 |
|---|---|
| 实时自控率 | 当前时刻参与评估的投自动回路数 / 参与评估总回路数 |
| 回路自控率 | 统计时间范围内控制模式为自动状态的时长 / 统计总时长 |
| 有效自控率 | 统计时间范围内自动状态下输出不饱和且控制有效的时长 / 统计总时长 |
| 回路平稳率/稳定率 | 基于 PV 与 SP 偏差标准差等方法评价波动情况 |
| 准确率 | 基于 PV 与 SP 偏差程度评价控制精度 |
| 快速率 | 基于设定值变化或扰动后的响应速度评价跟踪能力 |
| 控制回路性能评分 | 按准确率、快速率、平稳率、有效自控率及权重计算 |
| 装置平均自控率 | 统计范围内参与评估回路自控率的加权平均 |
| 装置平均平稳率 | 统计范围内参与评估回路平稳率的加权平均 |
| 装置平均性能评分 | 统计范围内参与评估回路性能评分的加权平均 |
| 装置周期自控率 | 周期内回路自控率达到阈值的回路数 / 参与统计回路数 |
| 装置周期平稳率 | 周期内回路平稳率达到阈值的回路数 / 参与统计回路数 |
| 控制性能指标 | 反映回路控制效果的综合指标，可由偏差、振荡、响应速度、输出动作等子指标组合计算 |
| 参考时间 | 指标计算、仿真分析或模型辨识采用的数据参考时间窗 |
| 振荡率 | 衡量 PV 周期性重复变化程度 |
| 振荡状况/周期/幅值 | 描述是否存在振荡、主要周期和主要幅值 |
| 非线性程度 | 衡量回路 PV/OP 或过程响应在不同区间下的非线性特征 |
| 阀门幅值 | 衡量阀门输出变化幅度和动作范围 |
| 黏滞系数 | 衡量 OP 因阀门摩擦等产生的黏滞滑动特性 |
| 粘滞状况 | 描述执行机构是否存在疑似卡涩、死区或黏滑现象 |
| 饱和率 | 自控状态下 OP 处于上限或下限限位的时间 / 统计总时长 |
| 输出值行程指数 | 统计时间内 OP 累计变化量折算到单位时间的行程 |
| 好值率 | 统计时间内数据质量正常时长 / 统计总时长 |
| 相关性指数 | 衡量不同控制回路变量之间关联程度 |
| 数据激励指数 | 衡量历史数据中扰动、设定值变化或输出变化是否足以支撑模型辨识和 PID 整定 |
| 整定结果可信度 | 综合数据质量、激励充分性、模型质量、仿真结果、工况匹配、专家确认状态形成的可信度评价 |
| 装置自控率验收口径 | 项目验收时装置自控率目标为 `>=95%`，仪表阀门异常和工艺原因可按审批规则例外剔除 |

说明：

- `DB32/T 4822-2024` 的 `95%` 达标阈值应作为默认考核口径之一。
- `GB/T 44693.2-2024` 的性能评分、定级、权重和附录公式应作为产品公式库核心能力。
- 公式、阈值、权重应版本化，报告必须显示实际采用口径。

## 9. 关键流程

### 9.1 系统部署流程

1. 确认网络分区、DCS/BPCS 类型、OPC Server、点位范围。
2. 部署数据采集服务、历史数据库、计算服务、应用服务和前端。
3. 配置 OPC DA、OPC UA、OPC AE 接入和冗余策略。
4. 配置可信质量码、采样周期和数据清洗规则。
5. 配置设备模板和位号后缀模板。
6. 自动扫描回路组态。
7. 人工校核回路台账、投用定义、回路级别、控制类型和统计范围。
8. 启动试运行评估。
9. 固化统计周期、公式版本、阈值、报告模板和权限。

### 9.2 周期评估流程

1. 系统按小时、日、周、月或自定义周期生成回路和装置 KPI。
2. 系统计算性能评分并进行性能定级。
3. 自动识别低自控率、低有效自控率、低平稳率、低性能评分和异常回路。
4. 仪表控制工程师确认诊断结论。
5. 工艺工程师确认工艺约束和优先级。
6. 系统生成标准报告、明细表和整改清单。
7. 工艺管理部门/安全管理人员跟踪整改闭环。
8. 评估结果进入内部审核和管理评审输入。

### 9.3 参数优化流程

1. 选择低性能且可优化回路。
2. 选择数据窗口、工况范围和整定策略。
3. 系统进行前置安全检查。
4. 系统进行过程模型辨识并评价数据激励指数和模型质量。
5. 系统基于智能控制算法、整定方法库或期望闭环响应搜索算法生成候选参数。
6. 系统进行闭环阶跃响应和频域响应仿真，输出整定可信度。
7. 系统给出预期效果、风险提示和回退参数。
8. 工艺、仪表、安全角色审核。
9. 仪表控制工程师在 DCS 中人工更新参数。
10. 系统进入观察期并自动复评。
11. 形成优化效果报告和变更记录。

### 9.4 变更管理流程

1. 发起控制回路变更申请。
2. 填写变更原因、类别、影响范围、风险和控制措施。
3. 工艺、仪表、安全、信息化按配置流程审核。
4. 变更实施前确认条件、培训、文件和回退方案。
5. 实施后记录实际参数和操作过程。
6. 系统自动复评变更效果。
7. 验收并关闭，未达目标则进入整改闭环。

### 9.5 交互式整定流程

1. 系统识别历史数据不足、激励不足或模型辨识质量不足的回路。
2. 用户选择专家经验库、趋势线法、特征点法或相似回路迁移建议。
3. 用户标注趋势线、特征点或填写回路特征评价。
4. 系统计算对象特征、候选 PID 参数、仿真结果和整定可信度。
5. 专家服务人员确认建议、风险和回退方案。
6. 如需实施，进入变更审核和人工实施流程。
7. 实施后系统复评并记录迭代效果。

### 9.6 项目实施与验收流程

1. 建立项目实施范围，导入 11 类装置和 1200 个控制回路清单。
2. 完成 OPC 数据接入、点位确认、回路台账校核和质量码配置。
3. 执行批量性能评估，形成装置、单元、回路三级评估结果。
4. 识别低性能回路，形成专家整定服务计划。
5. 按回路执行模型辨识、整定仿真、交互式整定、审核、实施和复评。
6. 完成用户培训并归档培训记录。
7. 输出项目验收包，包含部署记录、评估报告、整定服务报告、培训记录和验收指标。

## 11. 验收标准

### 11.1 功能验收

- 能接入至少一个真实或模拟 DCS/OPC 数据源。
- 能通过 OPC DA 和 OPC UA 获取 PV、SV/SP、OP/MV、MODE。
- 能自动识别一批 PID 回路并完成人工校核。
- 能配置投用定义、可信质量码、采样周期、控制类型和回路权重。
- 能按配置周期计算自控率、有效自控率、平稳率、准确率、快速率、性能评分和性能等级。
- 能识别振荡率、振荡周期、振荡幅值、非线性程度、阀门幅值、粘滞状况、黏滞系数、饱和率、稳态时间、输出值行程指数、好值率、相关性指数等诊断指标。
- 能识别阀门粘滞、过程扰动、回路耦合、分布式振荡等故障类型。
- 能生成 PID 参数建议、过程模型、闭环仿真结果、整定可信度和回退方案，并走完审核、实施记录、复评流程。
- 能在历史数据不足或激励不足时进入交互式整定流程，支持趋势线法、特征点法和专家经验库。
- 能生成标准评估报告、周期报告、单回路高级报告、维护建议、明细表和后 10 位排行。
- 能支持授权用户查询 5 年内任意时间段、任意单元、任意回路的自控率和平稳率，并可排序和评比。

### 11.2 合规验收

- 报表指标口径覆盖 `GB/T 44693.2-2024` 和 `DB32/T 4822-2024` 的关键定义。
- 报告最小内容集满足 `GB/T 44693.2-2024` 附录 H 的系统功能示例要求。
- 不参与统计回路必须有原因、有效期和审批记录。
- 长期因生产技术、电仪、设备等原因处于手动的回路不得无审批排除。
- 参数优化建议不得默认自动下写 DCS。
- 审核、实施、复评、变更记录必须可追溯。
- 支持项目实施后 5 年内在线历史查询和至少五年数据留存策略。
- 模型辨识、仿真、迁移学习和交互式整定的输入、算法版本、参数和输出必须可追溯。

### 11.3 招标验收

- 项目覆盖气化、变换及热回收、低温甲醇洗、液氮洗、氨合成、PSA 制氢、CO 分离及压缩、硫回收制酸、冷冻站、甲醇装置、醋酸装置等 11 类装置，共 1200 个控制回路。
- 项目实施后可查询 5 年内任意时间段、任意单元、任意回路的自控率和平稳率。
- 支持自控率、平稳率、报警次数、操作频次的实时统计、排序和评比。
- 单回路报告包含评级、雷达图、性能指标、振荡分析、非线性分析、粘滞分析和维护建议。
- PID 整定输出包含辨识模型、建议参数、整定可信度、数据激励指数、闭环阶跃响应曲线和闭环频域响应分析。
- 历史数据不足或激励不足回路可进入交互式整定流程，支持趋势线法、特征点法和专家经验库。
- 装置自控率达到 `>=95%`，仪表阀门异常和工艺原因除外，并可输出例外原因清单。
- 完成软件部署、培训记录和 PID 参数专家整定服务报告。

### 11.4 安全验收

- 默认部署不具备 DCS 写入权限。
- 关键配置修改需要授权并留痕。
- 账号权限遵循最小权限原则。
- 数据导出和报告下载可审计。
- 网络分区和防火墙策略有实施说明。
- OPC 账号、DCOM 权限、远程访问配置有安全实施说明。

## 13. 风险与约束

| 风险 | 影响 | 应对 |
|---|---|---|
| DCS 组态差异大 | 自动识别准确率不足 | 建立厂商适配模板、位号后缀模板和人工校核流程 |
| 投用定义不一致 | 自控率和有效自控率失真 | 投用定义可配置并版本化 |
| 历史数据质量差 | KPI 和整定结果不可信 | 引入质量位、可信质量码、缺失标记、数据窗口评分 |
| 采样周期不合理 | 动态性能评估失真 | 按回路类型和系统能力配置采样周期 |
| 企业担心控制安全 | 产品上线受阻 | 默认只读部署，不自动下写，提供安全评审材料 |
| 工艺工况频繁变化 | 单一参数建议失效 | 引入工况识别、多工况参数库 |
| 诊断结论不可解释 | 工程师不采纳 | 每条建议必须展示证据、公式、阈值和边界 |
| 标准持续更新 | 合规口径变化 | 指标公式、报告模板、术语字典、阈值版本化 |
| 1200 回路项目实施周期紧 | 交付范围失控 | 建立装置分批上线、回路交付清单、实施进度看板和验收包 |
| 模型辨识数据激励不足 | 整定结果不可信 | 引入数据激励指数、交互式整定、专家经验库和人工确认 |
| 迁移学习承诺过泛 | 验收口径不清 | 产品化为相似回路模型库、相似性依据、可信度和人工审核 |
| 5 年在线查询数据量大 | 查询慢、存储成本高 | 使用冷热分层、预聚合、异步报表和缓存策略 |
| 竞品功能范围较广 | 首版范围膨胀 | 保持 P0 聚焦招标硬性能力，高级扩展进入路线图 |
