# CLPM P0 原型规格包

日期：2026-06-16
版本：v0.1
范围：在正式视觉设计前，用一套可视化全景图 + P0 页面规格，冻结原型范围。

## 1. 规格包用途

本规格包用于三类讨论：

| 场景 | 用途 |
|---|---|
| 对内产品评审 | 统一 P0 主线、边界和样本验证目标 |
| 原型设计启动 | 明确先做哪些页面、每页先解决什么问题 |
| 前后端协同 | 把契约主干、页面骨架、状态和边界收敛到一套口径 |

## 3. 原型目标

P0 原型不是做整个平台，而是证明：

1. 产品不是报表工具。
2. 工程师能快速找到今天先处理哪条回路。
3. Sponsor 能快速判断本轮验证是否可信。
4. 闭环从发现、判断、处理到复评是可追溯的。

## 4. 原型范围冻结

### 4.1 必做页面

| 优先级 | 页面 | 第一问题 | 核心输出 |
|---|---|---|---|
| P0 | 工程师工作台 | 今天先处理哪条回路 | 低性能清单、数据雷达、待复评事项 |
| P0 | 数据可用性与可整定性雷达 | 这些结论靠不靠谱 | 可评估/可诊断/可整定/需现场核实/数据不足 |
| P0 | 低性能优先级清单 | 为什么先做它 | 排序、原因、建议动作、覆盖率 |
| P0 | 单回路证据链 | 为什么是它、下一步怎么做 | 趋势、MODE、事件、规则、阈值、建议动作 |
| P0 | 审核 / 实施 / 复评 | 谁来做、有没有改善 | 审核意见、人工实施记录、前后对比、回退方案 |
| P0 | Sponsor 证据视图 | 这次验证是否可信 | 样本验证仪表盘、证据包摘要、风险与结论 |
| P0 | EvidencePackage 摘要页 | 能不能汇报与导出 | 样本范围、可信度、闭环率、关键风险、导出入口 |

### 4.2 样例级页面

| 优先级 | 页面 | 范围限制 |
|---|---|---|
| P0-sample | 整定可信度样例页 | 仅 `1` 个专家确认可整定回路，用来证明方向 |

### 4.3 不进入 P0 原型的页面

| 页面 / 能力 | 原因 |
|---|---|
| 完整项目交付驾驶舱 | 属于 P2 |
| 专家服务工作台 | 属于 P2 |
| 批量整定工作台 | 属于 P1 |
| 交互式整定全套 | 属于 P1 |
| 5 年任意查询体验 | 属于 P2 平台能力 |
| 迁移学习与集团驾驶舱 | 属于 P3 |

## 5. 双入口原型结构

### 5.1 工程师工作台

```text
+-------------------+---------------------------+----------------------+
| 低性能清单        | 单回路证据/趋势/事件      | 动作与复评           |
| 优先级、状态      | MODE带、规则、阈值        | 审核、实施、回退     |
+-------------------+---------------------------+----------------------+
```

### 5.2 Sponsor 证据视图

```text
+-------------------------+---------------------------+
| 样本验证仪表盘          | 证据包摘要 / 关键样例     |
| 样本数、映射率、闭环率  | 风险说明、结论、导出      |
+-------------------------+---------------------------+
```

## 6. 页面规格

### 6.1 工程师工作台

| 层级 | 内容 |
|---|---|
| First | 低性能清单和待复评事项 |
| Second | 数据雷达和当前选中回路的状态 |
| Third | 次级趋势、补充说明、次要统计 |

### 6.2 数据雷达

| 层级 | 内容 |
|---|---|
| First | 状态分类：可评估 / 可诊断 / 可整定 / 数据不足 |
| Second | 缺失点位、好值率、自动时长、OP 饱和 |
| Third | 解释文案和跳转入口 |

### 6.3 低性能清单

| 层级 | 内容 |
|---|---|
| First | 优先级、位号、状态、下一步动作 |
| Second | 关键 KPI、诊断标签、证据完整度 |
| Third | 附加统计和次要属性 |

### 6.4 单回路证据链

| 层级 | 内容 |
|---|---|
| First | 趋势 + MODE 带 + 当前判断 |
| Second | 事件线、规则命中、阈值、建议动作 |
| Third | 深层解释和扩展证据 |

### 6.5 审核 / 实施 / 复评

| 层级 | 内容 |
|---|---|
| First | 当前审核状态、责任人、是否可实施 |
| Second | 风险、回退、观察期 |
| Third | 详细日志和对比历史 |

### 6.6 Sponsor 证据视图

| 层级 | 内容 |
|---|---|
| First | 样本可信度、闭环完成率、关键风险、结论 |
| Second | 证据包摘要、代表性样例 |
| Third | 完整导出入口和补充说明 |

## 7. 关键状态表

| 页面 | Loading | Empty | Error | Success | Partial |
|---|---|---|---|---|---|
| 样本验证仪表盘 | 正在校验样本与口径 | 还没有样本批次 | 样本解析失败 | 展示样本数、映射率、闭环率 | 缺专家评审时认可率暂不可用 |
| 数据雷达 | 正在计算可信度 | 当前没有可评估回路 | 质量码或 MODE 段无法解析 | 展示状态分组和原因 | 部分回路缺 OP/MODE/PID |
| 低性能清单 | 正在生成优先级 | 样本没有低性能回路 | 口径未固化 | 展示清单和建议动作 | 仅部分回路可排序 |
| 单回路证据链 | 正在加载趋势与规则 | 暂无足够证据窗口 | 证据窗口失效 | 展示趋势、规则、动作 | 缺某类证据时明确标注 |
| 证据包摘要 | 正在组装证据包 | 无完整闭环 | 存在过期结果 | 展示摘要和导出入口 | 缺实施或复评，仅桌面评审版 |

## 8. 原型验收点

| 验收点 | 标准 |
|---|---|
| 主路径清晰 | 工程师能在 10 秒内知道先看哪条回路 |
| 可信表达清晰 | 数据不足、需现场核实、不可判定不会被误解成系统坏了 |
| Sponsor 可汇报 | sponsor 证据视图第一屏能讲清样本可信度、闭环完成率、关键风险 |
| 工作台感成立 | 页面不是 KPI 卡片拼盘，而是列表 + 证据 + 动作的工作台 |
| 边界清楚 | P0 页面中不出现 P1/P2/P3 的重型能力误导 |
