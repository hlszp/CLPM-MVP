# CLPM 控制回路绩效治理与优化平台操作手册

适用读者：仪控工程师、DCS 自控工程师、工艺工程师、管理人员及系统管理员。

版本日期：2026 年 10 月 10 日

本手册说明如何从全厂巡检进入单回路分析，再完成评估、诊断、整定建议、处置记录和效果验证。使用时先确认回路位号、装置单元、分析时段及数据质量，再执行下一步。平台输出分析结果和参数建议；DCS 参数由现场授权人员按企业作业规程人工实施。

## 1 快速开始

### 1.1 登录系统

1. 使用管理员提供的站点地址和个人账号打开登录页。
2. 输入用户名、密码，点击登录。账号被禁用或密码错误时，按提示联系管理员处理，不要持续重复尝试。
3. 登录后查看驾驶舱。若进入已有页面，先核对当前回路和筛选条件。
4. 离开共享电脑前，通过账户菜单退出登录。

登录失败过多会触发临时限制；按页面提示等待后再试。手册不提供共用初始密码，现场账号由管理员分配。

### 1.2 一次典型巡检

1. 在驾驶舱选择近 24 小时，查看装置绩效、劣化情况、预警和处置待办。
2. 切到回路页，按等级、控制模式或劣化排序定位回路。
3. 打开回路工作台，核对位号，查看 PV、SP、OP 和 MODE 波形。
4. 在评估剖面查看失分原因及可信度；需要复查时发起评估。
5. 在评估历史中选择相关窗口，点击“诊断此窗”。
6. 阅读诊断结论与证据；适合调参的问题转入整定，仪表或阀门问题转入处置。
7. 授权人员线下实施后记录工单，完成前后对比及效果验证。

完成判断：分析窗口、结论、采用的建议、执行人和验证结论均有记录。仅保存整定方案不代表已实施；仅查看仿真不代表现场已改善。

菜单随账号角色和启用模块显示。DCS 自控工程师可由管理员按实际职责配置为仪控工程师角色；系统当前没有独立的 DCS 自控工程师角色。

| 角色 | 主要工作 | 操作边界 |
| --- | --- | --- |
| 系统管理员 ADMIN | 账号、工程配置、模块及业务维护 | 管理操作前核对对象和影响范围 |
| 仪控工程师 IC_ENGINEER | 巡检、评估、诊断、整定和处置 | 可整点回算；不可代替现场授权直接写 DCS |
| 工艺/设备工程师 PE_ENGINEER | 工况分析、专项评估、诊断整定和处置 | 可任意时段评估；整点回算仅管理员和仪控工程师 |
| 外部专家 EXPERT | 专业诊断、模型分析及整定建议 | 处置流转为只读；独立性能评估菜单和部分报告不可见 |

“系统管理 → 权限矩阵”用于查看预设权限说明，不能在该页自定义角色或配置菜单、页面、按钮权限。按钮可见不保证服务器允许执行；遇到“无权限”请记录页面和操作，联系管理员核对账号角色。

## 3 看懂数据与状态

### 3.1 常用过程变量

| 标识 | 含义 | 使用要点 |
| --- | --- | --- |
| PV | 过程测量值 | 核对工程单位及量程 |
| SP | 设定值 | 用于判断偏差和设定值变化 |
| OP | 控制器输出 | 结合阀门动作、限位和饱和情况分析 |
| MODE | 控制模式 | 手动、自动、串级等实际值由型号映射解释 |
| PID P I D | 控制器参数 | 来自关联测点，只读采集 |

历史数据导入从远端历史接口读取；评估、诊断和整定计算使用本地历史数据。实时波形来自实时数据链路。网络模式切换改变连接路径，不会把计算切换到另一套历史源。

### 3.2 评分 可信度和适用性

绩效评分回答“控制效果怎样”；数据可信度回答“数据是否足以支撑判断”；适用性回答“当前条件是否适合开展相应分析”。三者不能互相替代。

| 状态 | 含义 | 建议处理 |
| --- | --- | --- |
| 无数据或 — | 没有对应结果或不能计算 | 核对绑定、数据范围及任务状态，不视为零 |
| 数据不足或 INCONCLUSIVE | 无法给出可靠判定 | 补齐数据或调整工况时段后再分析 |
| 可信度 A 至 E | 数据充分程度或模块特定可信度等级 | 查看该模块的说明，不把不同模块的 A 等同 |
| 适用性 L0 | 数据严重不足 | 评估受限；手动诊断可给出数据不足结论；整定阻断 |
| 适用性 L1 | 手动主导或低自控 | 可诊断；整定阻断 |
| 适用性 L2 | 饱和或偏差等条件异常 | 诊断、整定带警告，先检查异常条件 |
| 适用性 L3 | 激励不足等受限条件 | 结合提示选择有代表性窗口，审慎采用模型 |
| 适用性 L4 | 条件适用 | 仍需核对数据和工况，不代表自动批准实施 |

列表中的等级可能是最新状态，报告中的指标可能对应已选历史窗口。比较时同时核对时间和统计范围。

## 4 使用驾驶舱

1. 从“驾驶舱”进入总览，在顶部选择“近 24h”“近 7 天”或“近 30 天”。
2. 按业务需要切换“总览、回路、性能、诊断、整定、处置”六个页签。
3. 查看装置、单元及治理统计。点击有下钻入口的评分、劣化、待办或预警卡片，打开对应清单。
4. 待办和预警清单中可选择记录查看详情；评分和劣化清单用于查看排名，需要继续分析时到回路页定位。核对下钻携带的时间和装置范围。
5. 需要立即更新时点击刷新；暂停自动刷新后可集中阅读，再恢复刷新。

回路页支持等级、控制模式和排序筛选；通过分页浏览卡片。筛选无匹配时显示“当前条件下无回路”，不代表所有回路都正常。

可切换深浅主题。具有后台访问权限时，“管理后台”进入回路监视。未显示该按钮的账号可在驾驶舱完成允许的查看操作。

完成判断：页面时间窗和筛选范围与本次巡检一致；对异常卡片已下钻查看明细，未仅凭颜色做结论。

## 5 回路监视与关注队列

### 5.1 从回路清单定位对象

1. 进入“回路监控 → 回路监视”。
2. 选择装置、类型、性能等级或控制模式，输入位号、描述等关键词，点击“查询”。
3. 核对表格中的位号、所属装置单元、量程、模式、SP、PV、OP、评分及适用性。
4. 点击位号、行或“详情”打开详情抽屉；点击“趋势”查看波形。
5. 在详情中点击“进入回路工作台”，对选中回路继续分析。

查看数值时同时核对页面数据刷新时间。当前回路监视不提供内嵌表格的导出和实时开关工具条；需要回路台账导出时，由有权限的人员到“参数配置 → 回路配置”操作。

### 5.2 处理关注队列

1. 进入“回路监控 → 关注队列”，选择来源、状态、关键词和排序，点击“查询”。
2. 一行对应一个回路，同回路的多个关注项合并展示；展开明细看具体来源。
3. 按优先级检查活跃预警、评分恶化、数据质量、适用性异常或在途工单。
4. 点击“进入工作台”，或使用明细抽屉中当前允许的操作。

聚合时间、来源不可用和截断提示都属于判断依据。按钮禁用时先查看原因；不要把空队列或部分来源为空解释为全厂没有问题。

## 6 回路工作台与波形

### 6.1 选中回路和分析剖面

1. 进入“工作台”，在左侧清单筛选并选择回路。
2. 核对页头位号、描述、模式和量程；再查看趋势。
3. 点击旅程状态条或下方缩略卡，打开评估、诊断、整定、处置剖面。
4. 按需要展开、最大化或收起工作区；可拖动分隔条调整布局。

某模块停用时，相应剖面不显示。切换回路后等待数据加载完成，并重新核对页头与弹窗对象再发起任务。

### 6.2 查看趋势

1. “历史”查看固定时间窗，“实时”接收当前回路最新推送。
2. 时间预设为 1H、2H、4H、8H、12H、24H、3D、7D；默认 24H。
3. 选择“自定义”，设置开始和结束时间，点击“应用”。自定义自动切换到历史模式，跨度不超过 30 天。
4. 点击 PV、SP、OP、MODE 图例隐藏或恢复对应内容。PV/SP 使用左轴工程值，OP 使用右轴；MODE 用于标记手动段。
5. 鼠标悬停查看时间、变量值和模式。

“SP±”输入正工程值后显示容差带，0 或留空不显示。此项只改变趋势展示，不修改 DCS 设定值，也不修改评估阈值。

### 6.3 放大 导出和检查异常

| 操作 | 作用 |
| --- | --- |
| 滚轮 | 缩放时间轴 |
| Shift 加滚轮 | 缩放纵轴 |
| 双击 | 复位视图 |
| 拖动滚动条 | 平移显示范围 |
| 拖动滑块两端 | 改变显示跨度 |
| PNG | 导出当前趋势画布 |
| CSV | 导出当前加载窗口内的趋势点 |

CSV 字段包括 timestamp、pv、sp、op、mode、quality；不是全部原始历史数据。BAD 数据以灰色虚线表示，UNCERTAIN 以琥珀色点划线表示。缺数据不能按数值零理解。

若刷新或切换后出现短暂波形、量程跳动或回路不一致，等待加载稳定并核对位号、时间轴和纵轴；仍不一致时保留画面、位号和发生时间，交管理员排查，暂不据此做工程判断。

## 7 单回路性能评估

### 7.1 查看已有结果

1. 在工作台打开“评估”剖面，查看最新得分、失分主因、可信度及数据血缘。
2. 通过“全部”“整点（自动/重算）”“手动”筛选评估历史。
3. 对目标记录打开详情，核对时间窗、指标结果、来源、有效数据及质量信息。
4. 对需要诊断的记录点击“诊断此窗”，带入相同时间窗口。

最新摘要以整点快照为主；任意时段专项结果在历史记录中查看，不应期待它直接替换装置聚合评分。

### 7.2 发起评估

1. 点击“发起评估”。
2. 选择“整点回算”或“任意时段”。
3. 设置开始和结束时间。整点回算会将分秒归零；时间跨度不超过 30 天。
4. 任意时段模式选择至少一个指标，点击“开始评估”；整点模式点击“开始回算”。
5. 等待任务进度。完成后历史和摘要自动刷新；失败时先读失败原因。

| 模式 | 结果用途 | 允许角色 |
| --- | --- | --- |
| 整点回算 | 覆盖对应整点评估，参与装置聚合 | 管理员、仪控工程师 |
| 任意时段 | 事故回溯、专项分析，不参与聚合 | 管理员、仪控工程师、工艺工程师 |

后台自动评估按每小时整点运行。任务提交成功不等于结果成功；离开页面不会自动取消后台任务。不要反复点击创建重复任务。

## 8 全厂与装置绩效分析

1. 进入“性能评估 → 装置性能”，选择需要分析的范围和时段，查看装置及单元绩效。
2. 进入“指标分析”，选择指标、窗口和装置范围，横向比较回路表现。
3. 进入“回路评估”，在排行、历史、矩阵三类视图中切换。
4. 在排行中定位低效回路；在历史中追溯评估记录；在矩阵中比较多个指标。
5. 下钻到回路工作台时核对位号与窗口，继续诊断或专项评估。

比较前核对参评状态、控制类型、重要等级、工况和可信度。不同窗口及不同参评范围下的评分不可直接等同。

评估任务页供有权限的账号跟踪任务状态、进度和失败信息。记录任务编号、目标回路数、时间窗及失败原因，便于管理员定位。待执行、执行中、成功、失败和已取消是任务执行状态，不是回路健康等级。

## 9 发起诊断与阅读结论

### 9.1 选择窗口和算子

1. 在工作台打开诊断剖面，点击“发起诊断”；或从评估记录点击“诊断此窗”。
2. 核对目标回路、适用性和近 24 小时快照预检。
3. 选择最近 24 小时、7 天、30 天或自定义窗口。自定义起点整点化，终点截到当前时刻，跨度不超过 31 天。
4. 选择“全量”、快速组或所需算子；算子目录加载失败时点击“重试”。
5. 点击“发起诊断”，等待进度完成，再查看最新结论和记录详情。

管理员、仪控工程师、工艺工程师和专家可发起诊断；管理人员只读。手动诊断对 L0 允许警告后发起，可能正式返回“数据不足”；不能将允许发起理解为允许可靠调参。

### 9.2 判断结论和下一步

1. 查看主分类、严重度、置信信息、复核状态和分析时间窗。
2. 展开证据，检查波形、特征值、规则阈值与负向指标是否支持结论。
3. 结合工况确认是否存在设定值调整、手自动切换、限位或数据缺口。
4. 有调参依据时进入整定；仪表故障、阀门粘滞等问题转处置建议。
5. 在“回路诊断 → 诊断记录/诊断任务”追溯历史及任务执行情况。

负向指标的 0 至 100 可视刻度不等于判定阈值。诊断置信度不是企业审批意见，也不等于现场已确认故障。

## 10 整定第一步 过程辨识

1. 在工作台打开整定剖面，检查当前 PID、适用性和已有模型。
2. 在“①过程辨识”选择历史数据自动辨识，设置包含代表性工况与有效激励的时段。
3. 如果从诊断带入时间窗，核对窗口后点击“用此窗口开始辨识”；也可清除带入条件后重新选择。
4. 发起辨识，等待任务完成，查看模型类型、参数、拟合度和可信度。
5. 必要时使用页面提供的模型修改功能；人工调整前核对对象类型及参数单位。

页面支持一阶滞后 FOPDT、二阶滞后 SOPDT 和积分对象 IPDT。历史路径默认近 7 天，阶跃路径默认近 6 小时。阶跃实验辨识应使用已有、经过现场批准的实验数据；页面不会替你向 DCS 发起阶跃。

L0、L1 阻断整定；L2 提示条件异常。辨识可信度 D、E 时，下游矩阵不可继续。拟合度好也不能替代对工况、数据质量和模型适用性的复核。

完成判断：模型参数及单位明确，选择窗口能够代表准备优化的工况，没有把手动切换、异常采样或阀门故障当作正常过程响应。

## 11 整定第二至四步

### 11.1 生成矩阵

1. 完成辨识后，在“②整定矩阵”生成可用算法的参数建议。
2. 对比 P（比例增益）、I（积分时间秒）、D（微分时间秒）、特性备注和算法参数。
3. 对支持的算法微调参数，确认结果有效；失败的计算行不能用于仿真。
4. 勾选 1 至 5 组参数进入仿真。

### 11.2 仿真对比

1. 点击“③仿真对比 → 开始仿真”。
2. 比较推荐组与当前 PID 的 SP 阶跃响应。
3. 综合查看超调量、调节时间、ITAE 等指标，而非只选择最快响应。
4. 结合工艺约束、输出限位及可接受风险选择方案。

当前 PID 缺失时，页面会提示无法提供对应对照；先检查参数测点绑定，不能把缺失参数当作零值。

### 11.3 确认和转处置

1. 在“④方案确认”选择最终方案，点击“保存方案”。
2. 保存后状态为“已仿真”，核对推荐值、算法和记录。
3. 点击“创建处置项”，核对回路、整定来源、处置类型、标题、执行人和计划时间，提交生成工单。
4. 由授权人员按现场规程实施，回到系统记录实施情况。

平台不会自动写 DCS。P、I、D 的定义及时间单位应与实际 DCS 型号一致；如现场使用比例带或不同 PID 形式，应由仪控人员完成换算与核对。

## 12 运维处置与闭环

### 12.1 审核建议

1. 在工作台处置剖面或“运维处置 → 诊断建议”查看建议。
2. 核对来源、回路、证据、内容和状态。
3. 选择“通过”“驳回”或“忽略”。驳回、忽略时填写原因。
4. 已通过建议点击“转工单”，填写处置类型、标题、执行人和计划实施时间。

建议通过不代表已经开工；驳回是终态，不可重新审核。管理员、仪控和工艺工程师可以流转处置；专家和管理人员只读。

### 12.2 实施与验证

1. 在处置工单中选择待实施或重开工单，核对执行人和计划，执行开工操作。
2. 授权人员线下实施，记录实际措施和参数变化。
3. 完成后提交验证，补充实际实施信息。
4. 结合前后 KPI、波形和必要的复诊，填写有效或无效及说明。
5. 有效后工单闭环；无效后重开，重新检查原因和措施。

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| PENDING | 待实施 | 核对计划后开工 |
| EXECUTING | 执行中 | 记录实际措施并提交验证 |
| VERIFYING | 待验证 | 对照证据提交验证结论 |
| CLOSED | 已闭环 | 到档案追溯 |
| REOPENED | 无效后重开 | 重新评估并安排实施 |
| CANCELLED | 已取消 | 保留取消原因，不视为闭环成功 |

系统中的“已回退”记录状态不等于 DCS 已自动回滚。现场回退也由授权人员完成并记录实际参数。

## 13 效果验证

1. 从“参数整定 → 效果验证”或工作台中的验证详情进入对比。
2. 选择“对比时点”，应为真实参数实施时刻；核对页面显示的时点来源，默认或回退时点不可直接当作实施时间。
3. 选择窗口：1、2、4、8、24、72 或 168 小时。时点前后分别取该长度窗口。
4. 点击“对比”，查看前后波形和 KPI。
5. 核对前后产量、负荷、设定值、模式和数据完整性，再判断改善。
6. 需要正式闭环时，在工单中提交验证结论并保留实施和验证说明。

工作台效果对比用于查询，不自动落库；工单验证会固化对应前后 KPI。两种结果不要混用。刚实施时，后窗尚不完整，建议等待有足够的代表性数据后验证。

完成判断：实施时间可靠、前后窗口一致、工况可比较；结论说明改善、未改善或需要继续观察的依据。

## 14 预警事件

1. 进入“回路监控 → 预警事件”。“实时预警”查看未确认事件，“历史预警”查看已确认、已解决、已归档等记录。
2. 按装置、状态、等级、规则、时间范围筛选，点击“查询”；“重置”清空筛选。
3. 点击“详情”查看触发快照；点击“检查”进入该回路工作台。
4. 管理员和仪控工程师可确认、批量确认、标记误报或撤销误报。
5. 仅管理员可归档已解决事件。导出 CSV 或 Excel 也仅管理员和仪控工程师允许。

“标记已读”只重置未读提醒，不等于业务确认或问题解决。批量确认可能跳过已不处于待确认状态的事件，以页面实际成功数量为准。

出现预警先核对触发时刻和快照；确认表示已受理，不能据此认为过程风险已解除。应按现场制度安排检查和处置。

## 15 统计报告与管理复盘

### 15.1 绩效和数据质量

绩效报告：进入“统计分析 → 绩效报告”，选择日、周、月及对应日期，选择综合报表或回路报表，并设置工厂、装置或单元。综合报表是节点聚合；回路报表是窗口内评估聚合并展示可信度。可导出 CSV 或 Excel。

数据质量：选择时间和装置，检查参评率、数据健康率、无法判定率、趋势和回路明细。底部“位号级数据质量体检”有独立时间窗口，需要单独设置；明细中的适用性和可信度可能是最新状态。

### 15.2 治理和收益

| 报告 | 重点查看 | 口径提醒 |
| --- | --- | --- |
| 预警统计 | 总量、活跃、MTTA、MTTR、误报率、TOP10 | MTTA 触发至确认；MTTR 触发至解决；活跃抑制是当前全量 |
| 诊断报告 | 分类、置信度、趋势、异常回路和记录 | CSV 导出存在条数上限，检查导出范围 |
| 处置报告 | 漏斗、闭环效率、责任看板、问题回路 | 人员工作量为全量口径，不随时段和装置筛选 |
| 收益报告 | 技术 KPI 前后对比、月趋势和装置标杆 | 当前是技术收益，没有经济收益金额计算 |

处置报告导出对象为 Top 问题回路；收益报告导出对象为装置标杆。不要把一次导出理解为该报告所有数据。

### 15.3 订阅配置

管理员可维护报表名称、班/日/周/月周期、每行一个收件人邮箱及启停。当前“立即生成”禁用，自动生成与周期推送尚未开放；保存订阅配置不会自动发送邮件。

## 16 工程投用准备

建议由管理员和仪控人员按“工厂结构 → 数据链路与型号 → 测点 → 回路 → 历史数据 → 计算配置 → 试运行”的顺序投用。批量导入前先选择少量有代表性的回路核对。

### 16.1 工厂结构

1. 进入“参数配置 → 工厂配置”，按工厂、装置、单元顺序新增节点。
2. 填写名称、节点类型、父节点和排序，保存后核对树和列表。
3. 用导出文件作为 Excel 模板，维护名称、类型、父节点名称和参评字段后导入。
4. 检查新增、更新及失败数量，修正失败行再导入。

管理员可新增、编辑、删除和导入；仪控与工艺工程师可查看及导出。存在子节点或关联回路时不能删除节点。

工厂模型需要 AAS 同步时，管理员在“同步设置”维护地址、路径及账号，保存测试后“立即同步”，检查同步日志。AAS 来源节点的名称和层级可能被后续同步覆盖；本地维护节点不受该同步覆盖。

### 16.2 测点

进入“参数配置 → 测点配置”，新建或导入测点，填写位号、名称、类型、量程上下限、单位、参数类型和原始 ID。保存后通过详情核对实时值、质量、关联回路和最后同步时间。管理员和仪控工程师可维护；删除仅管理员。

## 17 配置回路

1. 进入“参数配置 → 回路配置 → 新建回路”。
2. “基础信息”填写位号、描述、所属单元、回路类型、控制类型、重要等级、是否参评、DCS 型号和 OP 输出限位。
3. “Tag关联”关联 PV、SP、OP、MODE，按需关联 PID_P、PID_I、PID_D。
4. “投用定义”核对并保存 MODE 映射。
5. 检查完成摘要，点击“完成创建”，再核对实时值和状态。

PV/SP/OP/MODE 为必填关联；PID 参数测点选填且只读。已建回路位号不可编辑。控制类型可选稳定、慢速、快速或逻辑，重要等级为 1、2、3。

关闭“是否参与评估”不等于停止单回路 KPI 计算；该选项控制综合评分、装置聚合及低效排行等参评行为。OP 限位默认来自 OP 测点量程，自定义限位应处于量程内。

| 维护操作 | 允许角色 |
| --- | --- |
| 新建、编辑和 Tag 关联 | 管理员、仪控、工艺工程师 |
| 回路导入和分组 | 管理员、仪控工程师 |
| 回路导出 | 管理员、仪控、工艺工程师 |
| 批量配置、删除 | 管理员 |

删除回路会解绑测点并清理关联数据，测点本体保留。删除前按现场流程确认影响，不用删除来处理暂时不参评或数据不足。

## 18 配置链路和导入历史数据

### 18.1 链路及 DCS 型号

管理员进入“参数配置 → 链路配置”。当前三个页签为“数据源”“DCS 系统”“DCS 型号映射”。

1. 在数据源页维护实时地址、订阅、回写，以及历史接口地址、Token、超时等。
2. 分别保存并测试连接。测试连接会先保存当前表单，执行前确认修改内容。
3. Token 留空保留原值，输入会覆盖；需要删除时使用明确的清空选项。
4. 在 DCS 系统页维护品牌和型号，在型号映射页设置对应标准 MODE 的实际编码。
5. 回路选用正确型号；新建测点或变更绑定后刷新实时订阅并核对值。

### 18.2 历史数据导入

1. 进入“参数配置 → 数据导入”，按装置单元和关键词筛选，勾选回路。
2. 设置起止时间，结束时间必须至少为当前时间 5 分钟以前。页面默认结束时间可能是现在，应主动修改。
3. 选择采样间隔 1s、5s、10s 或 1m，根据回路动态和分析目的决定。
4. 需要导入后重算时勾选“触发KPI”；一般操作不要默认勾选“仅写位号表”。
5. 点击“开始导入”并确认；到任务列表跟踪待执行、执行中、成功或失败。
6. 导入成功后检查目标时段波形和质量，再开展计算。

管理员、仪控和工艺工程师可导入。全选覆盖当前筛选的全部分页，确认时检查回路数。执行中任务可取消，但可能留下不完整数据；终态任务删除不可恢复，不会等同于补齐历史数据。仅成功任务可再回算。

## 19 指标 诊断和预警配置

### 19.1 指标配置

管理员进入“参数配置 → 指标配置”，按需维护指标定义、权重、定级阈值、可信度、适用性、异常值检测和 KPI 算法参数。

1. 选择对应页签，查看当前值和适用范围。
2. 修改参数并保存；在支持版本的页签核对生成的版本。
3. 使用少量回路、明确时间窗检查结果变化。
4. 需要恢复时，通过页面提供的版本记录及回滚功能恢复配置。

内置指标代码、类别和公式锁定；可编辑项按页面开放范围维护。自定义指标的公式编辑不代表支持任意新增计算引擎。修改阈值后，历史已存结果不会因表单保存而自动全部重算。

### 19.2 诊断配置

管理员维护诊断代码、名称、算法类型、计算方法、启用状态、参数和阈值。JSON 字段须为有效对象；关联算子为已注册项，不能自由编写任意算子。阈值优先级为回路、装置、类型模板、全局；全局修改不会覆盖更细层级配置。

### 19.3 预警规则

管理员在“参数配置 → 预警规则”维护预制规则阈值、三级等级及启停，检查全局开关。当前不是任意表达式规则编辑器。变更前确认适用对象和单位，变更后关注误报及漏报情况。

## 20 系统管理

### 20.1 账号与基础信息

管理员在“用户管理”新增账号，填写用户名、初始密码、姓名、角色和邮箱；编辑或启用、禁用账号时核对目标。密码遗失可重置并通过企业规定渠道交付用户。不要共享管理员账号作为多人日常入口。

“基础信息”维护公司名称、地址、联系人、封面及 LOGO。核对登录页和侧边栏显示。界面显示的授权回路数不是购买或扩容操作入口。

### 20.2 字典和审计

字典管理维护编码、显示名、排序和启用状态。编码是实际存储值，慎改已使用项；保存后核对业务下拉和导入校验。

审计日志可按操作类型、时间、资源等筛选，查看操作者、IP、资源和记录。导出时区分当前页 CSV/Excel 和当前筛选全量 CSV。

### 20.3 模块管理

1. 管理员进入“模块管理”，查看固定模块、可选模块和依赖关系。
2. 勾选需要启用的模块；禁用时填写原因并确认。
3. 点击“应用更改”，联系运维安排后端重启。
4. 重启后重新登录或刷新，核对菜单、工作台剖面及任务。

基础模块不可禁用；处置依赖诊断。禁用保留数据，但不代表仍允许所有页面访问；部分报表可查看历史归档。不要按“约一分钟”理解为无需重启的自动生效。

## 21 常见问题与处理

### 找不到菜单或按钮

核对角色、模块开关和任务状态。权限矩阵为说明页，不能自行开通权限。向管理员提供账号角色、页面名称和操作，不提供密码。

### 波形为空或数据不足

核对位号、绑定、实时连接、查询窗口和历史导入。检查数据质量及最后更新时间。切换到确有数据的时段；缺口由数据导入补齐，计算不会自动从远端历史接口兜底取数。

### 图表变化但现场参数没有改变

确认历史/实时模式、时间窗、图例和纵轴范围。SP±仅为展示容差带；图表缩放不改变 DCS。若短暂显示其他回路或曲线异常，保留截图、位号、窗口和发生时间，待排查后使用。

### 任务一直待执行或失败

记录任务编号、目标回路、窗口和错误。避免重复发起；请管理员核对执行服务及数据来源。离开页面或停止显示进度不等于取消后台任务。

### 整定下一步不可点击

检查是否 L0/L1、模型是否完成、可信度是否 D/E、是否选择有效矩阵行。解决原因后重做，不通过改标签或空填参数绕过限制。

### 导入提示时间太近

将结束时间设为至少当前时间 5 分钟以前，再核对起止顺序与回路数。执行中任务取消后检查已导入范围。

### 报告数字与下钻不一致

核对时段、装置范围、参评状态、数据刷新时间及是否仅导出当前页。出现来源不可用、截断或独立窗口说明时按其实际范围理解；仍不一致时同时保存两个页面的条件。

### 订阅保存后未收到邮件

当前自动生成和周期推送尚未开放。保存配置不等于已发送，按需使用各报告页的导出功能。

## 22 日常检查与交接

### 每班或每日巡检

1. 确认实时连接、数据更新时间和质量。
2. 查看驾驶舱与活跃预警，筛选重点装置。
3. 在关注队列检查评分恶化、适用性异常和在途工单。
4. 对重要回路检查波形、评估可信度和诊断证据。
5. 跟踪待实施、待验证和重开工单；记录本班采取的措施。

### 一项优化工作的交接内容

记录回路位号、装置单元、工况、分析时间窗、数据完整性、评估及诊断记录、模型来源、采用算法、原 PID、建议 PID、单位、风险及现场回退方案。实施后追加真实实施时间、执行人、实际参数和验证窗口。

最终判断以工况、数据和现场证据共同支撑。结果不充分时写清缺失数据和下一步，不将“未见异常”“无法判定”或空值记作“已验证正常”。
