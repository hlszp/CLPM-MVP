## 简介
本指南面向首次接触 CLPM-MVP 的开发者，目标是在最短时间内完成开发环境搭建、启动基础设施、运行后端与前端，并访问界面。MVP 采用端口隔离策略，避免与原项目冲突；同时提供本地模拟远端数据服务，便于离线联调。

## 环境要求
- Node.js ≥ 22.18.0（推荐 pnpm ≥ 10.0.0）
- Python 3.12 + uv ≥ 0.4
- Docker 24+（推荐使用 Orbstack 作为容器运行时）

上述要求来自项目根 README 的环境说明与前后端工程配置。

## 端口与隔离说明
MVP 使用独立端口与容器命名空间，避免与原 CLPM 项目冲突：
- 后端 API：17101
- 前端开发服务器：15666
- 模拟远端数据服务（Docker）：17106
- PostgreSQL：17102
- Redis：17103
- TDengine：17104/17115

这些端口在开发编排文件中定义，并在 README 中明确标注 MVP 端口隔离策略。

## 一键启动基础设施
执行以下命令拉起 PostgreSQL、TDengine、Redis（以及可选的 mock 数据服务）：
```bash
docker compose -f deploy/docker/docker-compose.dev.yml up -d
```
如需启用 mock 数据服务，可追加 profile：
```bash
docker compose -f deploy/docker/docker-compose.dev.yml --profile mock up -d
```

该编排文件定义了各服务的镜像、端口映射、健康检查与依赖关系，确保基础设施就绪后再启动上层服务。

## 启动后端服务
步骤：
1. 进入后端目录并复制环境变量模板：
   ```bash
   cd backend && cp .env.example .env
   ```
2. 安装依赖：
   ```bash
   uv sync
   ```
3. 执行数据库迁移：
   ```bash
   uv run alembic upgrade head
   ```
4. 启动后端（监听 17101）：
   ```bash
   uv run uvicorn app.main:app --host 0.0.0.0 --port 17101 --reload
   ```

说明：
- 后端启动时会通过生命周期自动拉起 Celery Beat 与 Worker（开发模式），无需手动启动。
- 生产环境由 Compose 中的 celery-beat/celery-worker 容器接管。

## 默认账号与权限
系统内置 5 个种子用户，初始密码统一为 admin123：
- admin：ADMIN 角色，拥有全部模块权限
- ic_engineer：IC_ENGINEER 角色，拥有全部业务模块权限
- pe_engineer：PE_ENGINEER 角色，可访问监控/评估/工作台
- expert：EXPERT 角色，可访问监控工作台（只读）、诊断、整定
- sponsor：SPONSOR 角色，工作台只读

注意：全新部署的种子用户首次登录强制改密，改密前写操作受限。

## 数据源配置
架构决策：计算类历史数据一律走本地 TDengine；远端历史数据接口仅用于“历史数据导入”任务；实时数据通过 SignalR Hub 订阅，写入 Redis 缓存并可回写本地 TDengine。

- 历史数据导入接口（remote_api）
  - 在 UI「链路配置」页（/loop/aas-sync）配置一次即持久化到 sys_config
  - 支持配置历史数据 API 地址、鉴权 Token、请求超时
  - 仅在手工启动历史数据导入任务时调用

- 实时数据订阅（SignalR/WebSocket）
  - 在「链路配置」页配置 SignalR Hub URL、断线重连间隔等
  - 实时值查询 API：GET /api/v1/realtime?tagCodes=...

- 网络链路切换
  - 局域网/公网切换仅影响网络链路（是否经 Tailscale 子网路由转发），不改变数据源

## 模拟远端数据服务
开发环境提供模拟远端数据服务，完全模拟工程场景的数据链路：

方式一：Docker（推荐，随基础设施一起启动）
```bash
docker compose -f deploy/docker/docker-compose.dev.yml up -d mock-data-server
```

方式二：本地运行
```bash
cd mock_data_server
pip install -r requirements.txt
PYTHONPATH=/path/to/CLPM-MVP python -m uvicorn mock_data_server.main:app --host 0.0.0.0 --port 7106
```

服务启动后（Docker 宿主端口 17106，本地运行端口 7106）：
- 历史数据 API：POST http://localhost:17106/api/services/v1/HistoryData/Get
- 实时数据 Hub：WS ws://localhost:17106/signalr/realValueForClpmHub
- 健康检查：GET http://localhost:17106/health

## 常见问题排查
- 无法连接数据库或时序库
  - 确认 docker compose 已启动且健康检查通过
  - 核对 .env 中的 POSTGRES/TDENGINE/REDIS 主机与端口是否与开发编排一致
- 后端启动失败
  - 检查 alembic 迁移是否成功执行
  - 查看日志确认 Celery Beat/Worker 是否正常拉起
- 前端无法访问
  - 确认前端开发服务器已启动且端口为 15666
  - 检查浏览器控制台是否有跨域或 API 连接错误
- 模拟数据服务不可用
  - 确认 mock-data-server 容器已启动（必要时使用 --profile mock）
  - 访问 /health 验证服务状态
