- 每个性能用例对应一个独立函数（如 `perf_db_001`、`perf_cache_001`、`perf_fe_001`），并通过 `argparse` 的 `--case` 参数在 `main()` 中按需调度。
- 外部依赖采用运行时 `import` 包裹并在 `ImportError` 时打印提示后返回 False，使脚本在无依赖环境下仍可执行而不中断其他用例。
- 所有配置（主机、端口、用户名、密码、用户池）均通过 `os.environ.get(..., 默认值)` 读取，便于 CI 与本地环境切换。
- API 压测统一在 `on_start` 中调用 `/api/v1/auth/login` 获取 `accessToken` 并写入 `self.client.headers['Authorization']`，再对业务接口发起带 Bearer Token 的请求。
- 请求参数使用随机扰动（如 `random.random() < 0.3` 附加筛选条件、从预置 ID 池随机取值）模拟真实流量分布，避免单一 key 导致的缓存/索引偏差。
- 结果输出统一打印平均/P95/P99/最小最大耗时与 PASS/FAIL 判定，并以 `sys.exit(0/1)` 反映整体用例是否全部通过。
