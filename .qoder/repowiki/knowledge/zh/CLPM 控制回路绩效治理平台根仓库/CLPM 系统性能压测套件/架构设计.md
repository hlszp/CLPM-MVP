模块以 `locustfile.py` 作为统一入口（PERF-API-001~006），通过 `HttpUser` + `@tag` 将登录、回路列表、监控、诊断、波形查询、工作台聚合等接口压测场景组织为可标签筛选的任务；`scenarios/` 下按被测目标拆分为独立脚本：`api_load.py` 提供每个 API 用例独立的 `HttpUser`+`TaskSet` 组合以便单独运行；`db_perf.py` 直接连接 TDengine（taosws）和 PostgreSQL（psycopg2）执行 SQL 并统计 P95/P99；`cache_perf.py` 通过 Redis INFO 统计命中率并用 httpx 并发请求触发后端缓存，同时通过 import backend 的 Celery app 提交 KPI 计算任务进行并发验收；`frontend_perf.py` 使用 Playwright 无头浏览器测量首屏加载与 ECharts 渲染耗时。所有脚本通过统一的 `CLPM_PERF_*`、`POSTGRES_*`、`TDENGINE_*`、`REDIS_*` 环境变量注入配置，依赖版本由根级 `requirements.txt` 集中声明。
