- 所有 spec 通过 `import { test, expect } from '../fixtures/auth.js'` 引入自定义 fixture，而非直接使用 `@playwright/test` 的 base，从而统一获得 `loginAs` / `logout` 能力。
- 每个 spec 的 `beforeEach` 中调用 `clearAccessToken(page)` 清除 localStorage/sessionStorage，确保用例从干净状态开始且避免跨用例 token 污染。
- 页面元素选择优先使用语义化定位器（`getByPlaceholder`、`getByText({ exact: true })`、`getByRole`），仅在必要时回退到 CSS class（如 `.ant-table`、`.clpm-pid-dashboard__gauge-card`）。
- 网络等待统一使用 `waitForLoadState('domcontentloaded')` 或 `networkidle`，登录跳转使用 `waitForURL((url) => !url.pathname.includes('/auth/login'))` 配合 30s 超时容忍后端冷启动。
- 涉及后端 API 的登录/鉴权路径均实现 429 速率限制重试（最多 3 次，429 等待 5s，其他错误等待 2s）并通过 Map 缓存同一用户名 25 分钟的 JWT，避免触发后端限流。
- 视觉相关用例将截图输出到固定目录（`visual-inspection/`、`screenshots/`、`visual-baseline/`），文件名遵循 `{mode}-{page}-{resolution}.png` 命名约定以便人工比对。
