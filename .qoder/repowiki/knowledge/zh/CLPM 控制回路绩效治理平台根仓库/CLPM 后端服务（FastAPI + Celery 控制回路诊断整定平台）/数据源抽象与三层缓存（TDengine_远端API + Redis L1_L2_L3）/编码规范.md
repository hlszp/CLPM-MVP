- 数据源实现统一遵循 `HistoryDataProvider` Protocol，通过 `make_query_fn(db)` 返回与 DataPlanner 兼容的 `QueryFn` 闭包，而非直接暴露数据库会话。
- Redis 缓存统一采用 `pdb*` 前缀 + 短哈希 Key（loopId、metrics_hash、window_hash、op_limits_hash），并通过 `build_key` 静态方法集中生成，禁止拼接散落的字符串。
- 序列化链路固定为「对象→dict→JSON(utf-8)→zstd(level=3)→base64→str」，反序列化异常时记录 WARNING 并主动删除脏键，保证缓存一致性。
- CPU 密集型操作（zstd 压缩/解压、COV 前向填充、RawTimeSeries 转换）通过 `asyncio.to_thread` 放入线程池执行，避免阻塞事件循环。
- 模块级缓存使用 `time.monotonic()` 驱动的 TTL 字典（如 `_subtable_cache`），不使用 `asyncio.Lock` 以避免跨 Celery worker 事件循环绑定问题。
- ORM 模型统一继承 `Base`，主键为 `UUID(as_uuid=False)` 字符串，使用 `mapped_column` + `Index`/`CheckConstraint`/`UniqueConstraint` 在 schema 层表达业务约束。
