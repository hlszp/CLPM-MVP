- 模型继承 `Base` 并使用 `Mapped[T] = mapped_column(...)` 声明字段，主键 UUID 采用 `default=lambda: str(uuid4())` 生成字符串形式 UUID。
- 时间戳字段通过 `TimestampMixin` 的 `created_at`/`updated_at` 复用，或直接在模型中以 `func.now()` 作为默认值并配合 `onupdate=func.now()`。
- 枚举型字段在 `__table_args__` 中以 `CheckConstraint` 约束取值范围（如 `status IN (...)`、`loop_type IN (...)`、`tag_role IN (...)`）。
- 端点函数统一通过 `Depends(get_db)` 注入 `AsyncSession`，并通过 `Depends(require_roles/require_perms)` 进行角色/权限校验，再调用 `app.services.*` 完成业务逻辑。
- 所有端点返回值经 `app.schemas.common.success(data=...)` 包装为 `ApiResponse` 统一结构，错误通过 `app.core.exceptions.BizError` 抛出。
- 路由文件顶部用 docstring 列出完整 HTTP 方法映射，且固定路径（如 `/batch-config`、`/monitor`）必须在 `{id}` 动态路径之前声明。
