模块由两层组成：
- `app/models/`：SQLAlchemy 2.0 声明式模型层，以 `base.py` 中的 `Base(DeclarativeBase)` 和 `TimestampMixin` 为基类，所有实体（如 `LoopLedger`、`LoopTagMapping`、`SysUser`、`PlantNode` 等）通过 `Mapped[...]` + `mapped_column` 定义字段，使用 PostgreSQL 方言类型（UUID、JSONB）并在 `__table_args__` 中集中声明 CheckConstraint、UniqueConstraint、Index。
- `app/api/v1/endpoints/`：按业务域拆分的 FastAPI `APIRouter` 文件（如 `loops.py`、`diagnosis.py`、`tuning.py`、`system/modules.py` 等），每个文件暴露一个 `router = APIRouter(prefix=..., tags=[...])`，路由顺序遵循“固定路径优先于动态路径”约定（注释明确说明 `/monitor`、`/export`、`/{id}` 的声明顺序）。
依赖方向单向：endpoints → services/schemas → models；端点仅负责参数校验、权限注入（`Depends(require_roles/require_perms)`）、调用服务层并返回 `app.schemas.common.ApiResponse` 统一包装，不直接写 SQL。`models/__init__.py` 显式 import 全部模型以填充 `Base.metadata`，供 Alembic 自动迁移使用。
