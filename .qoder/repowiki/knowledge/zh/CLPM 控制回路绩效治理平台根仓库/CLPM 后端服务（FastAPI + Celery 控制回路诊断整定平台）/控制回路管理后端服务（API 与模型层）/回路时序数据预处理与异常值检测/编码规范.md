- 每个异常值检测以独立函数实现（detect_nan/detect_frozen/detect_jump 等），返回 (index, OutlierReason) 列表，再由 `OutlierDetector.detect_all` 汇总并受 `is_detector_enabled` 开关控制。
- 仅标记不置 invalid 的异常原因（TS_ANOMALY、HF_NOISE、FROZEN）集中在 `_MARK_ONLY` 集合中，通过 `OutlierDetector.should_invalidate` 统一判断是否将 valid 置 False。
- 阈值按 `ControlType` 枚举在 `_THRESHOLDS` 字典中集中声明，运行时覆盖通过 `dataclasses.replace` 合并到 `_merged_cache`，热路径仅读 `_merged_cache`。
- 所有步骤方法均通过 docstring 引用算法说明章节（如“设计依据：算法说明 §3.4.2 步骤④”）与 PRD/FDS 条款，形成规范追溯。
- 信号名约定：有效性数组 key 统一为 `{tag}_valid`（如 pv_valid、sp_valid），异常原因以 tag 名为键聚合，便于下游 DataBlock 组装。
- 对不可信输入（NaN/Inf/None、非数值）统一通过 `is_nan_or_inf` 或 try/except float 转换进行防御性处理，避免异常传播到上层。
