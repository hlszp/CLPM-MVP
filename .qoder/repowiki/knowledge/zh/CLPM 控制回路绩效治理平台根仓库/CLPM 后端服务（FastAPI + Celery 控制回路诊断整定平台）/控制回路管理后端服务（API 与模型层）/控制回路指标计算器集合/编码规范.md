- 每个指标计算器继承 `MetricCalculatorBase`，仅暴露 `metric_code` 属性与 `calculate(bundle)` 方法，其余信号提取、结果构造、INCONCLUSIVE 判定全部复用基类。
- 计算器通过 `self._make_result(bundle, value, details, precision)` 输出正常结果，通过 `self._make_inconclusive(bundle, reason, details)` 输出 data_insufficient/signal_missing 等不可计算情形。
- 指标代码在 `__init__.py` 的 `CALCULATOR_REGISTRY` 中集中注册，新增计算器必须在此字典添加映射条目才能被编排层发现。
- 配置参数优先从 `bundle.data_block.signals` 中以单元素列表形式读取（使用 `_read_config_scalar`），再回退到数据驱动或默认值，保持 CONFIG 覆盖语义一致。
- 数值结果统一经 `_clamp(value, low=0.0, high=100.0)` 限制到合理区间，并通过 `_round2` 或 `round(..., precision)` 控制小数位数后写入 `MetricResult.value`。
- 日志记录遵循 `[指标名] key=value` 格式，关键分支（如零偏差、恒定余差退化、扰动检测）均附带调试日志以便审计追溯。
