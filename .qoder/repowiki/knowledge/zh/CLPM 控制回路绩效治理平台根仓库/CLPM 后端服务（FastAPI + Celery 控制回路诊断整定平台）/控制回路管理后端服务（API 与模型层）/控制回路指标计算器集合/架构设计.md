模块以 `base.py` 中的 `MetricCalculatorBase`（继承自 `app.contracts.metric_calculator.MetricCalculator`）为抽象基类，封装信号提取（`_get_masked_values/_get_masked_pair`）、有效数据率判定（`valid_rate < 0.20 → INCONCLUSIVE`）、可信度等级（统一采用回路级 `loop_confidence_level`）、数据血缘构建（委托 `ConfidenceEvaluator`）以及时间/数值辅助方法；每个指标一个独立文件（如 `accuracy.py`、`stability.py`、`oscillation.py`、`valve_diagnosis.py` 等），仅实现 `metric_code` 属性与 `calculate(bundle) -> MetricResult` 方法。

`__init__.py` 充当注册中心：集中 import 所有计算器类并维护 `CALCULATOR_REGISTRY: dict[str, type[MetricCalculator]]`，同时声明 `CORE_METRIC_CODES`（参与综合评分加权的核心指标）、`DISCOUNT_METRIC_CODE`（折扣因子）、`AUXILIARY_METRIC_CODES`（辅助诊断指标）三类元数据，并提供 `get_calculator(metric_code)` 与 `get_all_calculators()` 供编排层按 metric_code 动态实例化。

依赖方向单向向下：具体计算器 → `MetricCalculatorBase` → `app.contracts.*` 数据契约与 `app.services.confidence_evaluator`；`disturbance.py` 为纯函数模块（不继承基类），被 `fast_rate.py` 等调用，便于独立单元测试。统计类指标在 `statistics.py` 中通过 `_SingleTagMeanCalculator` / `_SingleTagStdCalculator` 两个私有基类复用 PV/SP/OP/Error 的均值与标准差计算逻辑。
