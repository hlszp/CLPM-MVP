- API 路由统一放在 `app/api/v1/endpoints/<domain>.py`，并通过 `create_app` 中的 `v1_router.include_router` 集中挂载，新增模块需在此显式注册。
- 数据库模型集中在 `app/models/`，字段变更必须配套 Alembic 迁移文件置于 `alembic/versions/`，禁止直接修改表结构。
- 请求/响应体使用 `app/schemas/` 下的 Pydantic 模型定义，端点函数签名直接引用 schema 完成入参校验与出参序列化。
- 业务逻辑封装在 `app/services/*` 中，endpoint 仅做参数解析与调用，数据库访问通过 services 层间接完成。
- 可配置项优先从 `sys_config` 预载到进程缓存（如数据源、算法参数、异常值阈值、可信度阈值），失败时回落 .env 或算法默认值，不阻塞启动。
- Celery 任务统一在 `app/tasks/` 下定义并通过 `celery_app` 注册，由 main lifespan 自动拉起 worker/beat，生产环境由外部容器接管。
