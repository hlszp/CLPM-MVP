- 所有外部服务连接（DB/Redis/HTTP/TDengine）均通过 `app.core.config.settings` 读取配置，禁止硬编码连接参数。
- 异步资源（httpx.AsyncClient、Redis 客户端）采用模块级单例 + event loop 检测机制，在 Celery 新任务创建新 loop 时自动重建，避免 'Event loop is closed' 错误。
- 对外部输入进行 SQL 注入防护：tag_name 使用正则白名单校验，子表名通过 _ILLEGAL_SUBTABLE_CHAR 归一化非法字符后再拼接。
- 中间件统一继承 Starlette BaseHTTPMiddleware，并在 dispatch 中 try/except 捕获底层依赖异常后降级放行（如 Redis 不可用时幂等/限流降级）。
- 全局异常统一通过 exceptions.register_exception_handlers 注册，所有错误响应遵循 `{code, message, data}` 三字段结构，并自动附加 CORS 头。
- 日志通过 logging.setup_logging() 初始化，DEBUG 下输出人类可读行，生产下输出 JSON 并自动脱敏 password/token/Bearer/JWT 等敏感字段。
