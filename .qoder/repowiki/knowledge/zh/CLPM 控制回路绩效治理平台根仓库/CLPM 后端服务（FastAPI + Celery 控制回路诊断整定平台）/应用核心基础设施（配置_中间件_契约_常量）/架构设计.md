本模块按职责划分为四个子包，构成 FastAPI 应用的横切基础设施层：
- `core/`：应用启动期与运行期核心能力。`config.py` 基于 pydantic-settings 集中管理所有环境变量（PostgreSQL/TDengine/Redis/JWT/Celery/AAS/SignalR 等），并提供 DSN URL 构造与安全校验；`db.py` 暴露 SQLAlchemy 2.0 异步引擎与 `get_db` 依赖；`redis.py` 通过 `_RedisProxy` 代理实现 Celery 多 event loop 下的 Redis 客户端自动重建；`tdengine.py` 封装 TDengine REST API 查询、SQL 注入防护与 DataPlanner 适配器；`security.py` 提供 JWT 签发/校验与 bcrypt 密码哈希；`exceptions.py` 注册全局异常处理器，统一输出 `{code,message,data}` 响应并附加 CORS；`logging.py` 提供 JSON/可读双格式 logger，集成 request_id 上下文变量与敏感信息脱敏；`metrics.py` 基于 prometheus_client 暴露 `/metrics` 并通过内网 IP 白名单保护；`modules.py` 维护可热插拔的模块启用状态（持久化至 sys_config）；`system.py` 封装 Tailscale 子网路由切换命令。
- `middleware/`：三个独立的 Starlette BaseHTTPMiddleware——`idempotency.py` 基于 Idempotency-Key 头 + Redis 缓存实现写操作幂等；`rate_limit.py` 基于 Redis INCR+EXPIRE 对登录/改密等敏感端点做滑动窗口限流；`request_id.py` 注入 X-Request-ID 到 contextvar 供日志追踪。
- `contracts/`：定义跨模块共享的数据契约，`data_types.py` 用 dataclass 描述 RawTimeSeries/DataBlock/MetricDataBundle/MetricResult 等预处理管线数据结构，`metric_calculator.py` 定义 MetricCalculator 抽象接口，强制指标计算器只消费 bundle 不直连 DB，实现算法层与数据层解耦。
- `constants/`：集中业务常量，`mode.py` 定义 StandardMode 枚举及 MODE 标签、配色、自控率集合等，作为各子系统统一控制模式来源。
依赖方向：middleware → core（redis/security/logging）；core 内部 config 被其他 core 文件唯一引用；contracts 无外部依赖，仅被上层 services 消费。
