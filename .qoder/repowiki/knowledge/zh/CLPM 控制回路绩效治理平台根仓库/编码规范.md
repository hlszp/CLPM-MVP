- 所有服务通过 Docker Compose 的 healthcheck 声明健康状态，并以 depends_on condition: service_healthy 建立启动依赖链
- 非对外暴露的服务（backend/postgres/tdengine/redis/prometheus/grafana）统一使用 expose 而非 ports，仅通过 clpm-net 内部互通
- 生产环境资源限制统一通过 deploy.resources.limits 在 Compose 中声明 CPU/内存上限
- 日志统一使用 json-file 驱动并配置 max-size/max-file 轮转策略
- 环境变量集中通过 .env.prod 文件注入，敏感项（密码、JWT_SECRET_KEY）由 .env.prod.example 模板引导填写
- 版本信息通过 APP_VERSION 构建参数注入镜像 ENV，发布版本以 git tag 管理，二者解耦
