- API 处理器遵循 Nitro 文件系统路由约定，按资源目录（auth/menu/timezone/user）+ 文件名.method.ts 组织，每个处理器导出一个 `defineEventHandler` 默认函数。
- 所有响应统一通过 `utils/response.ts` 的 `useResponseSuccess` / `useResponseError` / `forbiddenResponse` / `unAuthorizedResponse` 封装，保持 `{code,data,error,message}` 结构一致。
- 鉴权相关逻辑集中在 `utils/jwt-utils.ts`，通过 `verifyAccessToken` / `verifyRefreshToken` 从请求头解析 Bearer Token 并反查 `MOCK_USERS`，handler 中不直接操作 jwt。
- Mock 数据（用户、菜单、权限码、时区选项）集中定义在 `utils/mock-data.ts` 的常量中，由多个 handler 复用，避免硬编码分散在各处。
- 敏感配置（JWT 密钥）通过环境变量 `MOCK_ACCESS_TOKEN_SECRET` / `MOCK_REFRESH_TOKEN_SECRET` 注入，未设置时使用开发默认值。
