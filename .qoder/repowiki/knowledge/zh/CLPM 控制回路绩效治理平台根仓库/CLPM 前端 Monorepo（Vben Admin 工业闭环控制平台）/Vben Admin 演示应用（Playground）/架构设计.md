应用以 `src/main.ts` 为入口，先初始化偏好设置（`initPreferences` + `preferencesExtension`/`overridesPreferences`），再异步加载 `bootstrap.ts` 完成插件注册：组件适配器（`adapter/component`）、表单适配器（`adapter/form`）、i18n（`locales`）、Pinia store（`store/auth.ts` 等）、时区、路由守卫（`router/guard.ts`、`access.ts`）、Tippy、Vue Query、Motion 插件，最后挂载 `App.vue`。
- 路由按模块拆分到 `router/routes/modules/*`（dashboard、demos、examples、system、vben），核心路由在 `core.ts`，通过 `index.ts` 聚合。
- API 层按领域划分：`api/core`（认证、菜单、用户、时区）、`api/system`（部门/菜单/角色/用户）、`api/examples`（下载、上传、表格等示例接口），统一由 `request.ts` 封装请求。
- 视图按功能组织：`views/_core`（登录、404、个人资料等基础页）、`views/dashboard`、`views/demos`（权限、图标、面包屑、特性演示等）、`views/examples`（各组件用法示例）、`views/system`（CRUD 列表+表单）。每个系统页面遵循 `list.vue` + `modules/form.vue` + `data.ts` 的统一结构。
- 构建使用 `@vben/vite-config` 的 `defineConfig`，开发时通过 Vite proxy 将 `/api` 转发到本地 mock 服务 `http://localhost:5320/api`。
- E2E 测试位于 `__tests__/e2e/`，使用 Playwright，包含登录流程用例及公共 auth 工具。
