- 应用初始化采用延迟加载模式：`main.ts` 仅负责偏好设置，真正的 bootstrap 逻辑通过动态 import 在 `initApplication` 中加载，以减少首屏体积。
- API 文件按业务域（core/system/examples）分目录组织，每个文件暴露对应模块的接口函数，并通过 `index.ts` 统一 re-export。
- 系统管理页面统一采用 `list.vue`（表格/操作）+ `modules/form.vue`（新增/编辑弹窗）+ `data.ts`（列定义/表单 schema）的三段式结构。
- 路由按功能模块拆分为 `router/routes/modules/*.ts`，再通过 `routes/index.ts` 聚合注册，便于按业务域维护路由表。
- 国际化文案按页面或模块拆分为独立的 JSON 文件（如 `page.json`、`system.json`、`examples.json`），通过 `$t` 函数调用。
- 组件与指令通过适配器模式集中注册：`adapter/component.ts`、`adapter/form.ts` 在 `bootstrap.ts` 中统一初始化，避免在各处重复引入。
