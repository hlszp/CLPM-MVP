- 所有子模块通过 pnpm workspace 引用 internal/* 与 packages/* 中的共享包，避免重复实现构建、类型与样式配置。
- 应用级项目统一采用 vite.config.ts + tsconfig.json + vitest.config.ts 的三件套结构，并通过 @vben/vite-config 与 @vben/tsconfig 继承公共配置。
- API 调用集中在 src/api 目录下按业务域拆分文件，并通过统一的 request.ts 封装请求拦截与错误处理。
- 路由、布局、store、locales 在各应用中遵循相同目录约定，便于在 web-antd、playground、docs 之间复用与迁移。
- 代码质量由 lefthook 在提交前统一触发 oxlint、stylelint、commitlint、cspell 等检查，保持全仓库一致风格。
- 变更通过 @changesets 管理，version 脚本自动生成 changelog 并更新依赖锁定文件。
