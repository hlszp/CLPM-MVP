- 每个子包遵循统一的目录结构：`src/` 存放源码、`__tests__/` 放测试、`package.json` + `tsconfig.json` + `tsdown.config.ts` 描述构建元信息，便于独立发布。
- 公共 API 通过 barrel 文件（`src/index.ts`）集中 re-export，调用方仅依赖包名而非内部路径。
- 内部工具包（node-utils、vite-config、eslint-config 等）在 `src/` 下按功能域拆分文件（如 configs/*.ts、plugins/*.ts），再通过 index 聚合导出。
- 偏好设置与全局状态通过单例类（如 `PreferenceManager`）+ `reactive`/`readonly` 暴露只读视图，变更经 `updateXxx` 方法触发并 debounce 落盘。
- Vite 插件以独立文件组织并按功能分类（plugins/ 下每个文件一个插件），由 `plugins/index.ts` 汇总注册。
- TypeScript 项目统一继承 `internal/tsconfig` 下的 base/library/node/web 等共享配置，保证跨包编译一致性。
