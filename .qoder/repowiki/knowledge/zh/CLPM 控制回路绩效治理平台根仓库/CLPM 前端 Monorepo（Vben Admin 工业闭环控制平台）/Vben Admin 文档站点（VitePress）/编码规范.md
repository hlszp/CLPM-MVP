- 多语言文档通过 `src/`（中文根）与 `src/en/`（英文子目录）镜像结构组织，配置侧以 `zh.mts`/`en.mts` 分别定义各语言的导航与文案。
- 组件文档统一放在 `src/components/<component>/xxx.md`，对应示例代码放置在 `src/demos/<component>/<scenario>/index.vue`，形成文档与示例一一对应的目录约定。
- 通过 `package.json` 的 `imports` 字段配合 `#node/adapter/*` 别名，在 Node 端与浏览器端加载不同的适配器实现，实现同构文档代码的环境隔离。
- VitePress 配置拆分为 `shared.mts`（通用配置）、`zh.mts`/`en.mts`（语言配置）、`index.mts`（组装入口），避免单文件臃肿。
- 自定义功能以 VitePress 插件形式扩展：Markdown 层使用 `groupIconMdPlugin` 与自定义 `demo-preview-plugin`，应用层通过 `enhanceApp` 注册全局组件与第三方插件。
