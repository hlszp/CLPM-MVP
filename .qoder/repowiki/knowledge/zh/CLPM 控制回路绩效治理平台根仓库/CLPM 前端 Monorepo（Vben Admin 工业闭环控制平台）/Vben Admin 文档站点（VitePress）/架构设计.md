站点以 VitePress 为核心框架，入口配置位于 `.vitepress/config/index.mts`，通过 `shared.mts` 聚合 Tailwind CSS、PWA、Git Changelog、Group Icons、Demo Preview 等 Vite 插件，并按语言拆分 `zh.mts`/`en.mts` 配置，最终在 `index.mts` 中以 `locales` 形式合并。

内容组织遵循 VitePress 约定：`src/` 下按 `guide/`、`components/`、`commercial/`、`sponsor/`、`friend-links/` 等目录存放 Markdown，同时存在 `src/en/` 镜像英文版本；`src/demos/` 按组件名分组存放 Vue 示例代码，由自定义 MD 插件 `demo-preview.vue` 渲染为可交互预览。

主题层位于 `.vitepress/theme/index.ts`，继承 VitePress 默认主题并注册 `SiteLayout`、`VbenContributors`、`DemoPreview` 全局组件，以及 Nolebase Git Changelog 和百度统计插件；样式集中在 `.vitepress/theme/styles/`。

运行时适配层 `src/_env/adapter/*` 将 Ant Design Vue (`antdv-next`) 组件桥接到 `@vben/common-ui` 的 `globalShareState`，并通过 `package.json` 的 `imports` 字段以 `#node/adapter/*` 区分 Node 端与浏览器端的表单/VXE-Table 适配器实现，使同一份文档代码可在不同环境加载不同依赖。
