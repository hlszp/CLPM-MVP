- 每个业务域以 workbench.vue 作为根容器，复杂交互拆分为 `components/` 下的独立 .vue 子组件（如 drawer/modal/card），保持根文件聚焦编排与状态管理。
- 异步请求统一包裹在 `requestGuard.run` 中，并通过 `requestGuard.guard(loopId, capturedEpoch)` 丢弃切换回路后过期的响应，避免竞态覆盖。
- 列表分页采用“服务端分页 + 无限滚动”模式：维护 currentPage/hasMorePages，滚动接近底部时追加下一页，搜索/筛选变化时重置至第 1 页。
- URL query 作为跨组件状态真相源（plantNodeId/loopId/tab/focus），通过 `monitorCtx.update` 或 `route.query` 同步，确保浏览器前进后退可恢复状态。
- 业务常量（状态颜色、标签映射、选项枚举）集中放在域内 `constants.ts`，模板中通过映射表渲染而非硬编码字符串。
- 长列表使用 `useVirtualList` 组合式函数实现虚拟滚动（itemHeight 固定），保证大数量回路列表滚动性能。
- 抽屉/弹窗类交互通过 v-model:open 双向绑定 + 独立组件封装，根页面只负责 open/close 状态与传入 id。
