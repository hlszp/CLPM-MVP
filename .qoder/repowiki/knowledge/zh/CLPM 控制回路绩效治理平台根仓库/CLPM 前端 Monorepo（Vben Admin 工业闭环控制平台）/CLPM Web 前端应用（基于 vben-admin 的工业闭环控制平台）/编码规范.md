- 业务视图按领域拆分为 `views/<domain>/` 目录，每个领域在 `router/routes/modules/` 下提供独立路由文件并由 index 聚合注册。
- 跨页面可复用逻辑抽取为 `composables/use-*.ts`，并通过 Pinia store（如 `store/auth.ts`）共享全局状态。
- 对外 API 按领域拆分到 `api/*.ts`，统一经 `api/request.ts` 发起请求并集中处理错误与鉴权。
- UI 组件按领域归入 `components/clpm|loop|monitor|plant-node` 子目录，并在各自 `index.ts` 中再导出。
- 多语言文案集中放在 `locales/langs/{zh-CN,en-US}/page.json`，通过 i18n 插件按需加载。
- 权限控制统一通过 `directives/permission.ts` 提供的 `v-permission` 指令在模板中声明式校验。
