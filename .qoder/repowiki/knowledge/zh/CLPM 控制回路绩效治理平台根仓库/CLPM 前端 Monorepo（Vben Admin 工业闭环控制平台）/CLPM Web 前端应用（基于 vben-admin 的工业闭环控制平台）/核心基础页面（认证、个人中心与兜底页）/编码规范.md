- 每个页面通过 `defineOptions({ name: '...' })` 显式声明组件名，便于调试与路由匹配。
- 表单统一采用 `computed(() => VbenFormSchema[])` 返回 Schema 数组，字段通过 `component`、`fieldName`、`label`、`rules`、`componentProps` 描述，而非手写模板。
- 认证相关页面通过 props 控制子功能开关（如 `show-code-login`、`show-register`、`show-third-party-login`），在 `login.vue` 中全部设为 `false` 以收敛入口。
- 国际化文案统一通过 `@vben/locales` 的 `$t('authentication.*')` 获取，避免硬编码中文。
- 兜底页统一复用 `@vben/common-ui` 的 `Fallback` 组件并以 `status` 区分 403/404/500 等场景。
- 个人中心各子页以独立 `.vue` 文件拆分，由 `profile/index.vue` 通过 `v-if` 按 tab value 条件渲染，保持职责单一。
