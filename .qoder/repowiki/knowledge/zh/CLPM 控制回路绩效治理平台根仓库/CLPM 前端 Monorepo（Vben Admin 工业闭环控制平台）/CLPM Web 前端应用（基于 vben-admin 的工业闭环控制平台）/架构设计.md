本模块是 CLPM 平台的唯一 Web 入口，通过 `src/bootstrap.ts`/`main.ts` 启动并注册路由、HTTP 拦截器、Pinia Store、i18n 与主题偏好；各业务域（monitoring_features、operations_features、system_management、content_and_reports、dashboard_and_core_pages）按领域拆分到 `views/<domain>/` 下的独立路由模块，由 `router/routes/modules/*.ts` 统一挂载，共享同一套 `api/*` 请求层、`composables/*` 组合式逻辑、`components/clpm|loop|monitor|plant-node` 通用组件以及 `store/auth.ts` 认证状态。跨子模块的协作通过 Pinia store、`use-operational-context`/`use-loop-context` 等 composables 以及 `adapter/form.ts`、`adapter/vxe-table.ts` 对第三方库的统一适配完成，所有页面均复用同一份 i18n 资源与权限指令 `v-permission`。
