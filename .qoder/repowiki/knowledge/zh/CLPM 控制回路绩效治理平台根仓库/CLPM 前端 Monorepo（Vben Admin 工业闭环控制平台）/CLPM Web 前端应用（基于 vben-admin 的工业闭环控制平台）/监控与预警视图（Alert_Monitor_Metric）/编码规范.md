- 每个页面文件顶部通过 `defineOptions({ name: '...' })` 声明组件名，便于调试与错误追踪。
- 页面统一使用 `ClpmPageToolbar` + `usePageToolbar` 组合生成标准工具栏（刷新/筛选/列设置/帮助），并通过 `showPageHelp` 注入帮助内容。
- 表格列定义集中声明为 `TableColumnsType`，并通过 `useTableDensity` 暴露 `tableSize/densityLabel/cycleDensity` 实现紧凑/标准/宽松三档密度切换。
- 枚举型字段（严重度、状态、优先级、来源等）采用本地 `Record<..., string>` 映射中文标签与颜色，避免硬编码字符串散落模板。
- Tab 容器页使用 `defineAsyncComponent` 懒加载子 Tab 组件，并通过 ref Map + `nextTick` 调用子组件暴露的 `refresh()` 方法实现刷新，而非用 `:key` 强制重建。
- 行内写操作（确认/处置/归档/误报标记等）统一使用 `actingXxxId` 或 `loading` 标志位防止重复提交，并在 try/catch 中通过 `message.success/error` 反馈结果。
