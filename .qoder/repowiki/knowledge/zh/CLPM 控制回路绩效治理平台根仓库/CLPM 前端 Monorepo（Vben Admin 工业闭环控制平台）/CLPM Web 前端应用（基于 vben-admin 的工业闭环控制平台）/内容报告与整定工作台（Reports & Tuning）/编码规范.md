- 页面统一通过 `ClpmPageToolbar` + `ClpmDataCanvas` 组合 vben Page 与自定义容器来组织标题、工具栏与内容区块。
- 成熟度 S1/S2/S3 三阶段能力通过常量映射（如 `STAGE_ORDER`、`KPI_SLOTS.stage`）在前端条件渲染列、图表 Tab 与升级引导，避免硬编码分支。
- 所有数据加载函数遵循 `loading = true → try/catch → loading = false` 的模板，错误交由全局拦截器处理，页面侧只做空数组兜底。
- 权限控制集中在入口处：管理员操作通过 `localStorage` 角色判断或 `v-permission="['ADMIN']"` 指令控制按钮显隐，非管理员降级为只读展示。
- 子组件通过 props 注入共享上下文对象（如 `ctx` from `use-tuning-workbench`），而非直接访问父组件 state，保持工作流状态集中。
- 表格列定义与导出列定义共用同一份字段映射（如 TOP 回路表与 Excel 导出列），保证前后端字段一致性。
