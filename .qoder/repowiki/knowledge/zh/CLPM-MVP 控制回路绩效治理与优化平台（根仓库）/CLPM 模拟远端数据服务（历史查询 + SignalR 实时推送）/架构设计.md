模块以 `main.py` 为应用入口，通过 `create_app()` 构建 FastAPI 实例并挂载 CORS、两个 API Router（`api/history.py` 与 `api/realtime_hub.py`），在 `lifespan` 中启动后台广播任务并在关闭时释放 TDengine 客户端。

- 配置层：`config.py` 定义 `Config` 类，统一从环境变量读取 TDengine 连接、端口、实时间隔与质量异常比例，并提供 REST URL 与 BasicAuth 属性。
- 数据模型层：`schemas.py` 使用 Pydantic v2 定义 HisDATA/RealDATA 协议对应的请求/响应 DTO。
- 接口层：`api/history.py` 暴露 `POST /api/services/v1/HistoryData/Get`；`api/realtime_hub.py` 暴露 `WS /signalr/realValueForClpmHub`，实现 `ConnectionManager` 维护 WebSocket 订阅关系，并通过 `start_broadcast_task` 定时向所有订阅者推送 `updateRealValues` 事件，兼容 SignalR JSON 协议握手。
- 服务层：`services/tdengine_query.py` 通过 httpx 调用 TDengine REST `/rest/sql`，将 tag 名解析为子表与列名（PV/SP/OP/MODE/PID_*），聚合多 tag 时间轴并注入质量码异常；`services/realtime_generator.py` 提供 `RealtimeGenerator` 单例，按 tag_code 确定性种子生成正弦波+噪声的实时值，MODE 角色每 4 小时切换一次离散模式。
- 依赖方向：api → services → config/schemas，services 之间无耦合；TDengine 客户端与 generator 均以模块级单例复用。
