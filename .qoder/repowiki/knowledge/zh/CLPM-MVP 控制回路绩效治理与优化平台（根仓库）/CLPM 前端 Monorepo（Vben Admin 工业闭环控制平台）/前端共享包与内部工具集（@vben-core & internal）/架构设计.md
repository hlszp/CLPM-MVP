本模块由两大子树组成：
- `frontend/packages/@core`：核心基础层，按职责拆分为 `base/*`（design 设计系统、icons 图标、shared 通用工具与缓存、typings 类型声明）、`composables` Vue3 组合式函数、`preferences` 基于 `PreferenceManager` 单例的主题/语言/布局偏好持久化、`ui-kit/*`（form-ui、layout-ui、menu-ui、popup-ui、shadcn-ui、tabs-ui 等可复用 UI 子包），各子包独立 `package.json` + `tsdown.config.ts` 单独打包。
- `frontend/packages/{constants,effects,icons,locales,preferences,stores,styles,types,utils}`：面向上层应用的共享能力，其中 `effects/*` 进一步细分为 `access`、`common-ui`、`hooks`、`layouts`、`plugins`、`request` 等业务效果包；`stores` 基于 `@tanstack/vue-store` 暴露全局 store 能力。
- `frontend/internal/*`：不对外发布的工程化工具，包括 `vite-config`（通过 `defineConfig` 自动识别 application/library 并聚合 plugins 与 config）、`node-utils`（封装 fs/git/path/hash/spinner 等 Node 侧工具）、`eslint-config`/`oxlint-config`/`stylelint-config`/`commitlint-config`/`oxfmt-config` 统一代码规范、`tailwind-config` 主题 CSS 变量注入、`tsconfig` 共享 tsconfig 基线（base/library/node/web/web-app）。
依赖方向自下而上：internal → @core/base → @core/ui-kit/effects → 上层应用；@core 内部子包之间通过 npm 包名（如 `@vben-core/shared`、`@vben-core/preferences`）相互引用，避免相对路径耦合。
