本模块按业务域划分为四个子目录：`authentication/` 实现多种登录方式（密码登录、验证码登录、二维码登录、忘记密码、注册），均通过 `@vben/common-ui` 提供的 `Authentication*` 组件 + 声明式 `VbenFormSchema` 配置表单；`profile/` 以 `index.vue` 作为 Tab 容器，组合 `base-setting`、`security-setting`、`password-setting`、`notification-setting` 四个独立设置子页；`fallback/` 集中处理路由级异常状态（coming-soon、forbidden、internal-error、not-found、offline），其中 `not-found.vue` 借助 `isKnownRoutePath` 区分权限拦截的 403 与真实 404；`about/` 为纯展示型页面。所有页面均为无状态 Vue SFC，仅依赖 `#/store`、`#/api`、`#/router/routes` 等顶层模块，不互相耦合，由上层路由系统挂载。
