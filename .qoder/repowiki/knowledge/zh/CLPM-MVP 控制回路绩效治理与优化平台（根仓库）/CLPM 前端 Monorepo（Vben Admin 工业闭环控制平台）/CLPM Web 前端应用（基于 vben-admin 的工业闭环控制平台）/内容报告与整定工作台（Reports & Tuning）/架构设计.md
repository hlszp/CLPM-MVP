模块由三个并列的视图目录组成，均基于 Vue 3 `<script setup>` + Ant Design Vue：
- `views/reports/`：以 `overview.vue` 为入口，通过固定 12 格 KPI 骨架（S1/S2/S3 三阶段按成熟度填充）+ ECharts 趋势图 + TOP 回路表格组织数据；PDF 导出采用「触发任务 → 轮询状态 → 下载」异步模式，Excel 导出复用 `#/utils/export`。
- `views/tuning/`：`workbench.vue` 作为整定主入口，左侧脊柱承载装置树/回路清单/整定建议列表，右侧主区按锚点顺序渲染四个子组件（`identify-section`、`matrix-section`、`simulate-section`、`confirm-section`），并通过 `composables/use-tuning-workbench.ts` 共享选中回路与步骤状态；P/I/D 实时值经 `useLoopRealtime` WebSocket 推送更新。
- `views/factory/config.vue`：左侧 `PlantNodeTree` 树 + 右侧分页列表的双栏布局，支持节点 CRUD、批量删除、行内参评开关、Excel 导入/导出，以及独立的 AAS 工厂模型同步配置区（连接测试/全量同步/日志）。
依赖方向：各页面仅向上依赖 `#/api/*`、`#/components/clpm`、`#/composables/*` 与 `@vben/common-ui`，不互相引用；跨模块跳转通过路由 query（如 `?loopId=&from=diagnosis`）传递上下文。
