模块按业务域划分为三个并列子目录：`alert/` 承载规则引擎产生的预警事件查看与处置（events.vue、rules.vue），通过 `#/api/alert` 调用确认/归档/误报等接口；`monitor/` 提供关注队列（attention.vue，按回路合并分组的多来源问题分诊）和回路列表（loops.vue，复用 `#/components/monitor/loop-fleet-view.vue` 并借助 `useMonitorContext` 共享筛选上下文）；`metric/` 以 config.vue 为入口，用 Tabs + `defineAsyncComponent` 懒加载定义/权重/定级阈值/可信度/适用性阈值/异常值参数/KPI 算法参数等子 Tab，tasks.vue 则聚合手动重算、自动任务、历史快照与策略配置四个 Tab。所有页面统一使用 `@vben/common-ui` 的 `Page`、`ClpmPageToolbar`、`ClpmStandardActions`、`ClpmEmptyState`、`ClpmDangerConfirmModal` 等共享 UI 组件，并通过 `#/composables/use-page-toolbar`、`useTableDensity`、`usePolling`、`use-monitor-context` 等组合式函数实现工具栏、表格密度、轮询刷新与跨页面上下文同步。依赖方向单向向下：views → composables/components → api → constants/utils，无跨 view 直接引用。
