- 每个页面顶部以 JSDoc 注释声明需求编号（如 S5-SYS-004、P2-07、A-07）并简述功能对齐的 IDS/PRD/UI/UX 章节。
- 列表页统一采用「ClpmPageToolbar + ClpmDataCanvas + Table」三段式布局，查询参数集中在 reactive query 对象中，分页变化通过 handleTableChange 同步 page/pageSize。
- 危险操作（禁用用户、删除测点、取消/删除任务）一律通过 ClpmDangerConfirmModal 或自定义 Modal 二次确认，并在 impact-scope / rollback-tip 中说明影响范围与可回滚性。
- 批量操作使用 selectedRowKeys + computed 计算可选目标数量，提交时通过 Promise.allSettled 或 runWithConcurrency 并行执行，分别统计成功/失败条数并给出聚合 message 反馈。
- 角色/状态/类型等枚举值统一从 `#/api/auth` 的 CLPM_ROLES、ROLE_LABELS 或 `#/constants/clpm-ui` 的 TASK_STATUS_* 映射获取，避免硬编码字符串。
- 列渲染通过 Table 的 bodyCell 插槽按 column.key 分支，数值字段使用 ClpmNumeric 或 formatTime 格式化，状态字段使用 statusTokenToAntdColor 映射 Ant Design Tag 颜色。
