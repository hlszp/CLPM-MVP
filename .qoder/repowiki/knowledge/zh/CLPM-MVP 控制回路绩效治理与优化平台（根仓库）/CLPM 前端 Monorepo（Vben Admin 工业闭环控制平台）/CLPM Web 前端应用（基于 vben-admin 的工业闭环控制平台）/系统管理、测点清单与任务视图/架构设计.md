本模块由三个并列的业务视图子目录组成，均基于 Vue 3 `<script setup>` + Ant Design Vue 的单文件组件：
- `system/`：纯展示型或轻量 CRUD 页面（users.vue 用户管理、permissions.vue 权限矩阵、dict.vue 字典管理、audit.vue 审计日志、llm-config.vue LLM 配置、modules.vue 模块开关），通过 `#/api/system`、`#/api/auth` 调用后端接口，使用 `@vben/common-ui` 的 `Page` 作为页面外壳。
- `tag/list.vue`：测点清单主视图，采用「筛选栏 + ClpmDataCanvas + Table」的标准数据页布局，集成字典下拉（measureType/tagType）、工厂节点树筛选、Excel 导入导出、WebSocket 实时值推送（realtime-ws）。
- `task/list.vue` 与 `task/detail.vue`：自动评估任务列表与详情抽屉，使用 `usePolling` 在存在 RUNNING/PENDING 任务时轮询刷新，并通过 `defineExpose({ refresh })` 暴露给父级 metric/tasks.vue 触发刷新。
所有页面统一依赖共享基础设施：`#/components/clpm`（ClpmPageToolbar、ClpmDataCanvas、ClpmDangerConfirmModal、ClpmStandardActions 等）、`#/composables/use-page-toolbar`、`#/composables/use-table-density`、`#/constants/clpm-ui`（状态→颜色映射、TASK_STATUS_LABEL）以及 `#/utils/format`、`#/utils/export`。业务 API 全部通过 `#/api/*` 命名空间下的 typed client 访问，错误处理委托全局拦截器，页面仅负责 loading/error 态切换与消息提示。
