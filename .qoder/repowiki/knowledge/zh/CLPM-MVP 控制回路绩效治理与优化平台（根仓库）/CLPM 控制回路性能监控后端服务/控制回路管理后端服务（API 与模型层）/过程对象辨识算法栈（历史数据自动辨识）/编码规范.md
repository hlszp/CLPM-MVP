- 每个算法子模块以独立 dataclass 作为结果载体（如 ARXResult、NonparametricEstimate、PhysicalFeasibilityResult），并通过函数签名明确输入输出类型。
- Pipeline 中各阶段失败均 try/except 捕获并记录 debug 日志后跳过，保证单一路径异常不影响整体流程继续执行其他候选方法。
- 可信度评估采用“封顶”策略：启发式 theta、物理不可行、低相干、非参数不一致等情形将置信度 cap 至 C 级而非直接拒绝模型。
- 所有数值阈值（延迟搜索范围、相干阈值、插值缺口上限、R² 轨阈值等）集中在 pipeline 顶部以模块级常量 `_XXX` 形式声明，便于调参与追踪 P2-xxx 需求编号。
- 对外 API 序列化统一通过 dataclass 的 `to_dict()` 方法完成，字段名使用驼峰命名（如 r2Val、confidenceLevel）以对齐前端契约。
