模块以 pipeline.py 为编排入口 `identify_from_history`，按层 1→6 串联：excitation（激励检测）→ nonparametric（相关分析/Welch 谱粗估）→ arx/armax/iv（参数化辨识）→ order_selection（AIC/BIC/Ljung-Box）→ discrete_to_continuous（离散→连续 K/tau/theta 转换）→ physical_feasibility + 可信度评估。types.py 集中定义共享数据结构（ModelParams、CandidateModel、IdentificationResult、AlgorithmConfidenceLevel、ThetaSource 等），各子模块仅依赖 types 与本模块内其他子模块，不反向被上层业务代码直接调用；pipeline 是唯一对外暴露的入口（__init__.py 仅 re-export）。识别方法通过 IdentifyMethod 枚举区分 HISTORICAL_ARX/HISTORICAL_ARMAX/HISTORICAL_IV，并在 pipeline 中并行跑 ARX+ARMAX，当存在 SP 激励时额外加入 CLIVC（闭环一致工具变量），最终由 Occam 准则（R²_val 相对提升 >5% 且 BIC 下降）在 FOPDT/SOPDT 间择优。所有中间结果（训练/验证/留出集分割、自由仿真 R²、残差检验、数据快照哈希、参数不确定度 Monte Carlo CI）统一封装进 ModelEvidence 随候选模型输出，保证可审计追溯。
