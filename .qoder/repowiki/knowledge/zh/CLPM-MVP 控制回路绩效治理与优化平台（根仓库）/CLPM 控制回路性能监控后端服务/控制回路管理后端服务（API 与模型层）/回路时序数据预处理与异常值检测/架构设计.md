模块以 `pipeline.py` 中的 `PreprocessingPipeline` 为编排入口，按算法说明 §3.4.2 的 8 步顺序（①质量码识别→③量程归一化→④异常值检测→②有效性标记→⑥连续性检查→⑧QualitySummary）串联各子模块；同时提供 `data_quality_assessor.py` 中的 `DataQualityAssessor` 作为共享内核，供 KPI/诊断/整定三链路复用同一套 validity 与 valid_rate 口径。

- 异常值检测：`outlier_detection.py` 定义 8 个独立检测函数（NaN、超量程、冻结、跳变、尖峰、时间戳异常、质量码异常、高频噪声），由 `OutlierDetector.detect_all` 统一调度，并通过 `thresholds.py` 中 `ControlTypeThreshold` 按控制类型（流量/压力/温度/液位/成分）选择阈值。
- 配置层：`thresholds.py` 维护默认阈值表与进程内合并缓存 `_merged_cache`，支持运行时覆盖（`set_threshold_overrides` / `set_detector_switches`）；`outlier_params.py` 负责 sys_config 存储（`outlier_params.current` JSON）与预载到进程缓存，实现热更新。
- 辅助工具：`quality_code.py` 统一多来源质量码映射为 Good/Bad/Unknown 三态；`validity_mask.py` 实现指标级掩码表达式求值（`pv_valid && sp_valid` 等布尔语法，递归下降解析器）；`quality_summary.py` 计算块级 valid/bad/missing 率与连续有效段。

依赖方向单向：pipeline → outlier_detection + quality_code + thresholds + validity_mask + quality_summary；`data_quality_assessor` 与 pipeline 相互独立但共享相同检测逻辑，避免重复实现。
