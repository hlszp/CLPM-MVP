本模块以 `backend/app/api/v1/endpoints/` 下的多个 FastAPI Router 为统一入口，由 `backend/app/main.py` 在启动时通过 `v1_router.include_router(...)` 逐一挂载：核心回路 CRUD（loops、loop_data、tags、handling）、权重与映射配置（loop_type_weight、loop_level_weight、loop_mode_mapping、weight_config）、各类阈值与评分配置（outlier_config、fitness_threshold_config、grading_config、confidence_config）、算法与算法配置（algorithms、algorithm_config、configs、dicts），以及系统模块枚举（system/modules）。所有端点共享同一套 SQLAlchemy 2.0 ORM 模型（`models/loop.py`、`models/loop_action_item.py`、`models/loop_config.py`）作为数据契约；业务计算则委托给同仓库的四个子模块——`preprocessing`（时序预处理）、`metric_calculator`（指标计算）、`tuning_identification`（过程对象辨识）、`diagnosis_operators`（无状态诊断元算子注册表），形成“API 层 → 领域服务 → 纯函数算子库”的分层调用链。各端点之间不直接互相 import，仅通过共享模型与上游 service 模块解耦。
