模块以 base.py 定义的契约为核心：OperatorMeta/OperatorInput/OperatorResult/EvidenceItem 描述算子的自描述元数据、输入输出与证据；@operator 装饰器将无状态纯函数连同阈值 schema 注册到全局 OPERATOR_REGISTRY，并由 list_operators/get_operator/default_thresholds 暴露查询能力。各故障族（oscillation/disturbance/saturation/sensor/stiction/tuning/gate/classification）各自一个文件，仅依赖 base 与外部纯计算库（numpy/scipy），禁止访问 DB/Redis/session，保证同输入同输出的确定性。fusion.py 提供 Dempster-Shafer 族内融合函数，仅对同一 symptom_tag 的已执行且命中的算子置信度做融合，跨族融合被明确禁止。__init__.py 在包导入时触发 disturbance/oscillation/saturation/sensor/stiction/tuning 等子模块加载以完成注册，gate/fusion/classification 作为工具不自动注册。
