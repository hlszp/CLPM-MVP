本模块按“设计阶段 + 产物类型”双维度组织：
- `docs/设计文档/` 采用标准软件设计文档分层（00-BASELINE 实现契约 → 01-PRD → 02-FDS → 03-ADS → 04-DDS → 05-IDS → 06-UIUX → 07-DEPLOYMENT → 08-TECHSTACK → 09-DEVPLAN → 10-API），其中 `00-BASELINE/implementation-contract.md` 作为当前 v2.11 的权威基线，统一约束 IA、路由、API、权限、状态机与 ORM 表清单，后续所有 PRD/UI/UX/测试均以该文件为派生基线。
- `docs/MVP设计/` 记录从信息架构到各模块（诊断/处置/整定/驾驶舱）的分阶段改造方案与实施计划，配合 `11-驾驶舱线框图.html` 等可交互原型。
- `docs/归档文档/` 保存历史版本 PRD、原型规范、算法设计草稿与供应商对比；`docs/过程文档/` 记录迭代过程中的评审报告、任务清单、ADR、E2E 报告与 Phase 进度追踪。
- `diagrams/` 使用 Mermaid（`.mmd`）描述 CLPM 全景、能力分层、角色视图、版本路线图等系统级架构图，供文档引用。
- `ZL-MES-UI-Design-Kit/` 是独立的工业 UI/UX 设计系统规范（冷静界面、防呆、扫视性、色彩/字体/组件/交互约定），并附带 HTML 原型页面与 Agent Skill 说明。
- `docs/设计文档/prototype/` 是一个可独立运行的 React+Vite 前端原型工程（含 mock、pages、components、routes），用于验证 IA 与页面布局。
依赖方向单向：MVP 设计 → 设计文档分层 → 过程文档记录执行；架构图与原型服务于设计文档，不反向依赖代码。
