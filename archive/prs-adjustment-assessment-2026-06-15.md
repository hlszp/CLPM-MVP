# PRS 调整评估：基于新增标准与竞品手册

日期：2026-06-15
评估对象：`product-requirements-specification-2026-06-15.md` v0.1
新增材料：

- `GBT44693.1-2024危险化学品企业工艺平稳性第1部分：管理导则上传.pdf`
- `GBT44693.2-2024危险化学品企业工艺平稳性第2部分：控制回路性能评估与优化技术规范上传.pdf`
- `PID性能监控评估软件3.1使用手册.pdf`
- `控制回路性能评估分析软件使用手册.pdf`

## 1. 结论

当前 PRS 方向正确，但需要调整。主要原因是：v0.1 基本覆盖了“自控率、平稳率、诊断、PID 参数建议、审核闭环、报表”的主线，但对 `GB/T 44693.2-2024` 中更完整的指标体系、性能评分、性能定级、控制回路权重、有效自控率、准确率、快速率、好值率、相关性指数、多工况判断、数据采样周期、控制回路属性采集等要求覆盖不足。

建议升级为 v0.2。调整重点不是推翻产品定位，而是把产品从“DB32/T 4822 口径的自控率/平稳率平台”提升为“GB/T 44693.2 原生指标体系 + DB32 考核口径 + 危化工艺平稳性管理闭环”的产品。

优先级判断：

- 必须调整：指标体系、OPC UA、有效自控率、性能评分/定级、回路权重、投用定义、数据质量、三年历史查询、标准报告内容。
- 建议调整：竞品已有的回路组、我的关注、雷达图、偏差分布、PV/MV 散点图、闭环频率响应、回路相关性报告、配置导入导出。
- 暂不建议首版强化：自动在线下写、自适应闭环参数修改、复杂 APC/RTO 全平台化。

## 2. 标准带来的关键变化

### 2.1 GB/T 44693.1 对产品边界的影响

`GB/T 44693.1-2024` 不只是控制回路技术标准，它把工艺平稳性定义为管理体系。对 PRS 的影响是：产品不应只服务仪表控制工程师，还应支持企业层面的管理目标、绩效监测、内部审核、管理评审和持续改进。

当前 PRS 已有整改闭环和安全风险联动，但还不够明确：

- 应补充“工艺平稳性管理目标/年度计划/管理评审”支撑能力。
- 应补充“内部审核、专项检查、整改项跟踪”的管理视图。
- 应把报警管理、联锁投用、工艺参数波动纳入后续联动指标，不只是作为扩展项泛泛提到。
- 应在角色中强化“工艺管理部门/生产技术部门”角色，而不仅是工艺工程师。

### 2.2 GB/T 44693.2 对指标体系的影响

`GB/T 44693.2-2024` 明确要求企业按照控制回路特性及投用状态，通过有效自控率、平稳率、准确率、快速率等性能指标进行单回路评估，并计算控制回路性能评分。

当前 PRS 的缺口：

- 只有自控率、平稳率、周期自控率、周期平稳率，缺少有效自控率、准确率、快速率、性能评分。
- 诊断指标有振荡、饱和、偏差、频谱，但缺少标准附录中的好值率、输出值行程指数、相关性指数等。
- 有“问题排序”，但没有“一级到五级”的性能定级。
- 有“关键回路标识”，但没有“一级/二级/三级回路权重”和加权平均指标。

### 2.3 系统功能要求的影响

`GB/T 44693.2` 附录 H 提到的系统能力包括：

- 通过 OPC DA/UA 采集 PV、SV、OP、MODE 等数据。
- 建立控制回路台账。
- 建立标准所列各项评估指标。
- 支持在线统计、分析、监测。
- 性能评估结果支持一级、二级、三级、四级、五级分级。
- 较差控制回路应有醒目提示，并给出初步诊断结果与合理意见。
- 报告至少包括装置名、统计时间、装置总回路个数、参与统计回路数量、未投用原因分析与统计、装置整体自控率、装置整体性能评分、性能评分较差后 10 位、自控率较差后 10 位。
- 具有近三年各项评估指标历史查询功能。

当前 PRS 已覆盖台账、在线监测、报告、历史留存，但报告字段、性能评分、性能定级、后 10 位排名、近三年历史查询需要补齐。

## 3. 竞品手册带来的关键变化

### 3.1 `PID 性能监控评估软件 3.1` 手册

该手册显示竞品已具备较完整的工程化能力：

- B/S 架构，IIS/.NET 后台服务。
- OPC 配通、AE 报警事件、权限配置、加密狗/授权。
- 标准评估计划、自定义评估计划、回路相关性分析计划。
- 设备模板管理，用于自动识别回路位号后缀。
- 可信质量码设置。
- 总览、评估、统计报告模块。
- 装置实时统计：装置自控率、平稳率、操作次数、报警次数，每 2 分钟刷新。
- 回路实时状态：实时自控、平稳、操作次数、报警次数、最长无报警时间。
- 回路等级：优、良、中、差、开环、条件剔除。
- 单回路报告：雷达图、评估建议、PV/SV/MV 趋势、控制性能、控制偏差分布、PV/MV 散点图、闭环频率响应。
- 统计报告：日报、周报、月报、自定义报告、回路相关性报告。

对 PRS 的影响：

- v0.1 中“页面需求”和“报表需求”偏概括，需要补竞品已验证的交互和报表细节。
- “设备模板/位号后缀模板”“可信质量码”“评估计划管理”“回路关注”应纳入 P0/P1。
- “报警次数、操作次数、最长无报警时间”应作为控制回路运行画像指标加入 P1，至少不要遗漏。

### 3.2 `控制回路性能评估分析软件` 手册

该手册更贴近 `GB/T 44693.2` 指标体系，明确列出：

- 故障诊断指标：振荡率、黏滞系数、饱和率、稳态时间、输出值行程指数、好值率、投用率。
- 性能评估指标：自控率、有效自控率、准确率、快速率、稳定率。
- 装置关键绩效指标：实时自控率、自控率、平稳率、性能评分。
- 四级视图：厂级、装置级、回路组、单回路。
- OPC UA 和 OPC DA，支持冗余配置。
- 监控模式可配置，可通过位号决定是否监控。
- 回路配置支持批量导入导出。
- 回路基础信息包括控制类型、回路权重、采集周期、是否启用 MDDEATTR。
- 支持投用定义、数据存储周期、指标阈值配置。
- 单回路性能评分公式：`P = [(A*a) + (F*f) + (S*s)] / (a + f + s) * R`。

对 PRS 的影响：

- `FR-201` 到 `FR-209` 需要扩展为完整指标体系。
- `FR-101` 到 `FR-106` 需要增加回路组、控制类型、回路权重、投用定义、MDDEATTR/APC 控制状态等配置。
- `FR-001` 到 `FR-007` 需要把 OPC UA 从 P1 调整为 P0，并新增 OPC 冗余配置。
- 需要新增“性能评分公式配置”和“权重系数配置”，否则难以支撑不同控制类型。

## 6. 当前 PRS 中可以保留的判断

以下判断仍然成立，不建议因竞品功能而改变：

- 首版不做自动批量下写 DCS 参数。
- 首版不做无人工审核的在线闭环自整定。
- 首版不把全量 APC/RTO/MPC 建模平台纳入核心范围。
- 产品定位仍应是“危化企业控制回路性能评估与优化平台”，不是单机 PID 调参软件。
- 审核、实施记录、复评、回退和审计留痕仍是核心差异化能力。

## 7. 建议的 v0.2 调整路径

1. 先更新 PRS 的“指标计算、问题诊断、台账配置、报表内容”四个章节。
2. 再补充“工艺平稳性管理闭环”章节，承接 `GB/T 44693.1` 的绩效评价、内部审核、管理评审、持续改进。
3. 最后调整版本路线：把“GB/T 44693.2 完整指标体系”放入 MVP，把“竞品高级图表/相关性报告/大屏”放入 V1.0。

`数据接入 -> 台账/投用定义 -> 指标计算 -> 评分定级 -> 诊断排行 -> 优化建议 -> 变更审核 -> 实施复评 -> 管理评审`
