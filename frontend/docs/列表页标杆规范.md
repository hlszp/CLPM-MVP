# 列表页标杆规范（CLPM 前端）

> 版本：v1.0（2026-08-24）· 标杆页：关注队列 `views/monitor/attention.vue`
> 适用范围：全系统列表类页面（台账、事件流、队列、任务清单等）

## 1. 页面结构（五段式，自上而下）

1. **工具栏**：`ClpmPageToolbar` + `usePageToolbar` 声明标准工具（刷新/筛选/列设置/帮助，按需启用），经 `ClpmStandardActions` 渲染；页面特有工具（如密度切换）以 `ClpmToolbarButton` 追加。
2. **摘要条**（可选）：页面级统计数字（待处理/总数等）+ 右侧聚合时间与异常提示小图标；数字为页面级信息，允许大字号。
3. **速览/分组筛选**（可选）：如优先级速览卡、来源 chips，既是统计也是快捷筛选。
4. **筛选区**：全局样式类 `clpm-filter-bar`（`styles/industrial-light.css`），经工具栏「筛选」工具折叠（`clpm-filter-bar--collapsed`）。控件用 `FormItem + label` 排列，右侧 `ml-auto` 放「查询 / 重置」。
5. **主表 + 分页**：`Card` 包裹 antd `Table`；分页条左侧展示双口径计数（已加载/共），右侧 `Pagination`。

## 2. 筛选区约定

- 工厂模型范围筛选统一使用 `ClpmPlantNodeTreeSelect`（value=plantNodeId），不要各页自建树。
- 枚举筛选（来源/状态/等级等）用 `Select`（多选场景 `mode="multiple"` + `max-tag-count`），选项 label 用中文并可附计数。
- 搜索用 `Input` + 回车或「查询」按钮触发；筛选项变更即时生效（重置 `page=1` 后加载）。
- 「重置」清空全部筛选（含 URL 深链带入的隐藏筛选如 loopId）。

## 3. 详情交互

- **详情一律右侧抽屉**（Drawer），不用行内展开、不用跳页；主表行点击打开抽屉，操作列提供图标按钮（`@click.stop` 防止与行点击叠加）。
- 抽屉内子项列表用浅色分隔线（`divide-y divide-gray-100`），不做底色卡片化。
- 写操作（确认/处置/误报等）就地执行并刷新列表；抽屉若仍打开需同步刷新其数据，目标对象消失则关闭。

## 4. 清爽视觉约束（红线）

- **单元格不加底色**：禁止行级高亮背景（如紧急红底）、禁止单元格背景色块；优先级/状态差异只靠小号 `Tag` 徽章与文字色阶表达。
- **不加粗字体**：表格单元格内禁用 `font-semibold`/`font-bold`；等宽字体（位号/数字）保留但用常规字重。
- 数据墨水比优先：少边框、浅分隔、次要信息用 `text-gray-400/500` 色阶降级。
- 空态区分「无数据（正面信号）」与「筛选无结果（提供清除筛选动作）」，统一用 `ClpmEmptyState`。

## 5. 通用能力

- 表格密度三档：`useTableDensity('<page-key>')` + 工具栏密度按钮。
- 枚举映射：中文标签/颜色用页面顶部 `Record<..., string>` 常量或 `#/constants/clpm-ui`（优先级 `PRIORITY_LABEL`/`PRIORITY_TO_STATUS`、fitness 标签 `FITNESS_TAG_LABEL` 等共享映射禁止在页面内重复定义）。
- 相对时间：dayjs relativeTime + `normalizeUtcTimestamp`，绝对时间放 Tooltip。
- 防重复提交：行内写操作用 `actingXxxId` 标志位 + `loading`。

## 6. 推广计划

- 已达标：关注队列（attention.vue，v2.0 重构）。
- 待推广：预警事件（alert/events.vue）、回路监视（loop-fleet-view）、回路台账、测点清单、任务列表、处置工单等——按本规范分批对齐，不改交互语义、只统一壳层与视觉。
