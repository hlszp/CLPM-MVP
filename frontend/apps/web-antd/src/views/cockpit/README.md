# 驾驶舱回路详情的评估窗口

回路卡片与右侧单回路面板的综合评分、六维雷达和可信度，统一取监控列表返回的最新小时 `kpiSummary`。`LoopCardModel` 保留该快照的可信度与 `calculatedAt`，面板显示“最新小时快照”及截止时间；后端无时区后缀的 UTC 时间通过 `formatLocalTime` 转换显示。

`getLoopMonitorDetailApi(loopId, 'last_24_hours')` 仍用于实时值、PID 参数及近 24 小时趋势。该响应中的 KPI 是窗口汇总，不能覆盖小时快照的雷达或可信度。同一回路刷新列表快照时，面板同步更新评分与分项，无须重复请求详情；详情读取失败也保留已有小时评估。缺少小时快照时，雷达保持缺数据并显示“暂无小时快照”。节点聚合视图保持原有口径。

回归测试：`src/__tests__/cockpit-loop-snapshot.test.ts`。用不同的小时值和 24 小时汇总值验证窗口隔离、同回路快照刷新、详情失败及无快照四种情况。此次只修改前端展示，不修改评分公式、阈值或历史结果，也不追溯重算已有小时快照。
